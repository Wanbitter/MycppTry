## 快速开始

### 1. 装编译器（Windows）

1. 下载 **MinGW-w64**（推荐 <https://www.mingw-w64.org/downloads/> 的 UCRT 版）并解压到 `C:\mingw64`
2. 把 `C:\mingw64\bin` 加进系统环境变量 `Path`
3. 打开终端（PowerShell），输入：

```powershell
g++ --version
```

看到类似 `g++.exe (MinGW-W64 x86_64-ucrt-posix-seh) 15.2.0` 就成功了。

### 2. 装 VS Code 插件

- **C/C++**（Microsoft 官方，提供补全和调试）

### 3. 用本手册自带的现成配置

本手册 **`studyself/.vscode/`** 里已经放好了配置，**开箱即用**：

| 文件 | 作用 |
|---|---|
| `.vscode/tasks.json` | 按 `Ctrl+Shift+B` 一键编译当前文件 |
| `.vscode/launch.json` | 按 `F5` 编译并启动 gdb 调试 |
| `.vscode/c_cpp_properties.json` | 指定 C++17 标准和编译器路径 |

**怎么用**：在 VS Code 里选「文件 → 打开文件夹」，
**打开 `studyself` 这个文件夹**（不是它的上层目录），配置就会自动生效。

> ⚠️ 如果你的 MinGW 不在 `C:\mingw64`，把上面三个文件里的
> `C:\\mingw64\\bin\\g++.exe` 和 `C:\\mingw64\\bin\\gdb.exe` 改成你的实际路径。

### 4. 命令行编译（不用 IDE 也行）

```bash
g++ -std=c++17 -O2 -Wall main.cpp -o main.exe
./main.exe
```

| 参数 | 含义 |
|---|---|
| `-std=c++17` | 使用 C++17 标准（竞赛主流） |
| `-O2` | 开启优化，交题时必开，本地调试建议 `-O0` |
| `-Wall` | 打开所有警告，**新手靠它抓 bug** |
| `-o main.exe` | 指定输出文件名 |

## 三种用法

**用法一：按顺序自学（推荐新手）**
从 [第 01 章](docs/01-环境搭建与HelloWorld.md) 开始，一章一章往下读，每章末尾的练习都动手写一遍。

**用法二：当字典查（推荐已有基础者）**
比赛时忘了 KMP 怎么写 → 第 11 章 → 直接复制模板。

**用法三：当题库刷**
`solutions/` 里每道题都有「题意 → 思路 → 复杂度 → 代码 → 踩坑」，
先自己写，卡住了再看思路。

## 关于 `WIDA-XCPC` 这个文件

上层目录的 `WIDA-XCPC-v1.8.8-2024.11.19.md` 是一个 **1.3 万行的竞赛模板大全**，
覆盖 14 大板块（图论 / 网络流 / 数论 / 几何 / 数据结构 / DP / 字符串 / 博弈论 / …）。

它是**「字典」不是「教材」**：内容几乎全是代码，**没学过的人直接看会看不懂**。
所以 `docs/` 才是入口——
先看 `docs/` 建立理解，需要细节时再回 `WIDA` 里查。

**找不到那个文件怎么办？**
[第 13 章](docs/13-高级模板速查索引.md) 已经把它 **195 个章节整理成了索引表**，
按问题类型分类。你可以照索引去别处搜「算法名 + 模板」，
或者直接看 `docs/` 里对应的章节。
