# 第 08 章　动态规划（DP）

> **本章目标**：这是全书**最重要**的一章，也是「会不会做算法题」的分水岭。
>
> DP 不是某个具体算法，而是**一种思维方式**：
> 把大问题拆成小问题，**把算过的答案存起来**，以后直接用，不再重算。

---

## 8.1　DP 的三要素

任何一道 DP 题，你必须回答三个问题：

| 要素 | 含义 | 怎么问自己 |
|---|---|---|
| **状态** | `dp[...]` 这个数组**代表什么**？ | 「我关心哪些信息？」 |
| **转移** | `dp[...]` 怎么由**更小的状态**算出来？ | 「最后一步做了什么选择？」 |
| **边界** | 最小的那些状态，值是多少？ | 「什么都没选 / 一个都没有时是什么？」 |

> 🎯 **90% 的 DP 卡壳，都是卡在「状态定义」上。**
> 状态定义对了，转移方程往往自然而然就出来了。

### 8.1.1　一个例子：爬楼梯

**题目**：楼梯有 n 级，每次可以走 1 级或 2 级，问有多少种走法。

**三要素分析**：

1. **状态**：`dp[i]` = 「走到第 i 级台阶的方案数」
2. **转移**：到第 i 级，**最后一步**只能是从 `i-1` 走 1 级上来，或从 `i-2` 走 2 级上来
   → `dp[i] = dp[i-1] + dp[i-2]`
3. **边界**：`dp[0] = 1`（不动也是一种方案），`dp[1] = 1`

```cpp
dp[0] = 1;
dp[1] = 1;
for (int i = 2; i <= n; i++) {
    dp[i] = dp[i-1] + dp[i-2];
}
cout << dp[n] << '\n';
```

**关键思维**：**只看「最后一步」**——这是所有 DP 转移的推导起点。

## 8.2　从搜索到 DP（记忆化搜索）

### 8.2.1　先写暴力递归

爬楼梯的暴力写法：

```cpp
int f(int n) {
    if (n == 0 || n == 1) return 1;
    return f(n - 1) + f(n - 2);
}
```

**问题**：`f(5)` 会调用 `f(4)` 和 `f(3)`；
`f(4)` 又会调用 `f(3)` 和 `f(2)`……**`f(3)` 被算了两遍**。

**复杂度是 `O(2ⁿ)`** —— 指数级爆炸！

```
                f(5)
              /      \
          f(4)        f(3)
         /    \      /    \
      f(3)   f(2)  f(2)   f(1)     ← f(3)、f(2) 重复计算
```

### 8.2.2　加缓存（记忆化搜索）

```cpp
int memo[1000];
bool vis[1000];

int f(int n) {
    if (n == 0 || n == 1) return 1;      // 边界
    if (vis[n]) return memo[n];          // ← 算过了，直接用

    vis[n] = true;
    return memo[n] = f(n - 1) + f(n - 2);   // ← 存下来
}
```

**复杂度变成 `O(n)`** ——每个 `n` 只算一次。

### 8.2.3　改成递推（循环）

```cpp
dp[0] = 1;
dp[1] = 1;
for (int i = 2; i <= n; i++) dp[i] = dp[i-1] + dp[i-2];
```

**这就是「DP」**：把「记忆化搜索」的递归展开成循环。

### 8.2.4　两种写法的取舍

| | 记忆化搜索（递归） | 递推（循环） |
|---|---|---|
| 思路 | 自然，好想 | 需要自己安排顺序 |
| 效率 | 有递归开销 | **更快** |
| 适用 | 状态访问**稀疏**、转移复杂 | 状态**稠密** |
| 缺点 | 可能爆栈、常数大 | 顺序想错就全错 |

> 🎯 **强烈建议**：
> **先写记忆化搜索（好想），过了再考虑改递推（卡常时）。**
> 「能记忆化就别硬推递推」—— 这是竞赛里省时间的重要策略。

### 8.2.5　什么时候能用 DP？

两个条件：

1. **最优子结构**：大问题的最优解，由**子问题的最优解**构成
2. **无后效性**：一旦状态确定，**后面的决策与「怎么到达这个状态」无关**

> ⚠️ **「无后效性」是 DP 的命门。**
> 如果状态里缺少了「影响后续决策的信息」，DP 就会出错。
>
> **例**：背包问题里，`dp[j]` 只记「容量 j 的最大价值」够不够？
> **够**——因为我们不需要知道具体装了哪些东西，只需要知道「还能装多少」。
>
> **反例**：如果题目要求「打印具体方案」，
> 那就需要额外记录「每个状态是从哪来的」（记录前驱），表变大了。

## 8.3　线性 DP（一维/二维数组上的 DP）

### 8.3.1　LIS 最长上升子序列

**题目**：给一个数组，求**最长的、严格递增的**子序列长度
（子序列不要求连续）。

**O(n²) 做法**：

```cpp
// dp[i] = 以 a[i] 结尾的最长上升子序列长度
int dp[N], ans = 1;
for (int i = 1; i <= n; i++) {
    dp[i] = 1;                           // 至少是它自己
    for (int j = 1; j < i; j++) {
        if (a[j] < a[i]) {
            dp[i] = max(dp[i], dp[j] + 1);   // 接在 j 后面
        }
    }
    ans = max(ans, dp[i]);
}
```

**O(n log n) 做法（贪心 + 二分，必须会）**：

```cpp
// tail[k] = 「长度为 k+1 的上升子序列」的最小结尾值
int LIS(vector<int> &a) {
    vector<int> tail;
    for (int x : a) {
        // 找第一个 >= x 的位置
        auto it = lower_bound(tail.begin(), tail.end(), x);
        if (it == tail.end()) tail.push_back(x);   // 更长的新序列
        else *it = x;                              // 替换成更小的结尾
    }
    return tail.size();
}
```

**为什么对？** 维护「每个长度的最小结尾」——
结尾越小，后面越容易接上。
`tail` 本身是**严格递增**的，所以可以二分。

**变体（注意区别！）**：

```cpp
// 最长非降子序列（允许相等）
auto it = upper_bound(tail.begin(), tail.end(), x);

// 最长下降子序列：把 a 取负，或把比较反过来
// 最长严格递减：对 -a[i] 求 LIS
```

> ⚠️ **最常见的错误**：把「严格上升」和「非降」的 `lower_bound`/`upper_bound` 用反。
> **记忆法**：求「严格」用 `lower_bound`（找第一个 `>= x`）；
> 求「非降」用 `upper_bound`（找第一个 `> x`）。

### 8.3.2　LCS 最长公共子序列

**题目**：给两个字符串，求**最长的公共子序列**（不要求连续）。

**状态**：`dp[i][j]` = 「`a` 的前 i 个字符」和「`b` 的前 j 个字符」的 LCS 长度。

**转移（分三种情况）**：

```cpp
if (a[i] == b[j]) {
    dp[i][j] = dp[i-1][j-1] + 1;          // 这个字符匹配上了
} else {
    dp[i][j] = max(dp[i-1][j], dp[i][j-1]);   // 丢掉一边
}
```

**完整代码**：

```cpp
int n = a.size(), m = b.size();
vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        if (a[i-1] == b[j-1]) dp[i][j] = dp[i-1][j-1] + 1;
        else dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
    }
}
cout << dp[n][m] << '\n';
```

**复杂度 `O(nm)`，空间 `O(nm)`**。

> ⚠️ **注意下标**：`dp` 的 `i` 从 1 开始，而字符串从 0 开始，
> 所以要用 `a[i-1]` 和 `b[j-1]`。**这是 LCS 最容易写错的地方。**

**如果想输出具体方案**：额外开一个 `pre` 数组记录每步的来源，最后回溯。

### 8.3.3　最大子段和

**题目**：给一个数组（可能有负数），求**和最大的连续子数组**。

**状态**：`dp[i]` = 「以 `a[i]` **结尾**的最大子段和」。

**转移**：

```cpp
dp[i] = max(a[i], dp[i-1] + a[i]);
// 要么自己单干，要么接在前面后面
```

**完整代码（还能省掉数组）**：

```cpp
int ans = INT_MIN, cur = 0;
for (int i = 0; i < n; i++) {
    cur = max(a[i], cur + a[i]);
    ans = max(ans, cur);
}
```

**复杂度 `O(n)`，空间 `O(1)`。**

> 🎯 **「以 a[i] 结尾」这个状态定义是经典套路**。
> 很多「子数组 / 子串」类问题都用它——因为这样能让「连续」这个约束自然满足。

**变体：最大子矩阵和**
枚举上下边界（`O(n²)` 对），把中间压成一维，用最大子段和 → `O(n³)`。

### 8.3.4　其他线性 DP

| 问题 | 状态 | 转移 |
|---|---|---|
| 数字三角形 | `dp[i][j]` 从顶到 `(i,j)` 的最大和 | `dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + a[i][j]` |
| 编辑距离 | `dp[i][j]` 前 i 转成前 j 的最少操作 | 匹配 / 替换 / 插入 / 删除，取 min |
| 最长回文子序列 | `dp[i][j]` 区间 `[i,j]` 的最长回文子序列 | 两端相等则 `+2`，否则取 max |
| 股票买卖 | `dp[i][0/1]` 第 i 天持股/不持股的最大收益 | 按「买/卖/不动」转移 |

## 8.4　背包问题（DP 的入门必修）

背包是 DP 最经典的模型。**把这一节吃透，`80%` 的 DP 题都能上手。**

---

### 8.4.1　01 背包

**题目**：有 `n` 件物品，第 `i` 件**重量 `w[i]`、价值 `v[i]`**。
背包容量 `W`。**每件物品最多选一次**。求能获得的最大总价值。

`n, W ≤ 1000`（或 `n ≤ 100, W ≤ 1e5`，视题目而定）

#### 第一步：二维状态

**状态**：`dp[i][j]` = 「考虑**前 `i` 件**物品，容量为 `j` 时的最大价值」。

**转移（对第 i 件物品：选 or 不选）**：

```cpp
dp[i][j] = max(
    dp[i-1][j],                    // 不选第 i 件
    dp[i-1][j - w[i]] + v[i]       // 选第 i 件（前提是 j >= w[i]）
);
```

**边界**：`dp[0][j] = 0`（一件都不考虑，价值当然是 0）。
（全局数组默认全 0，所以不用特别写。）

**完整代码（二维版，好理解）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1005, W_MAX = 1005;
int w[N], v[N];
int dp[N][W_MAX];

int main() {
    int n, W;
    cin >> n >> W;
    for (int i = 1; i <= n; i++) cin >> w[i] >> v[i];

    for (int i = 1; i <= n; i++) {
        for (int j = 0; j <= W; j++) {
            dp[i][j] = dp[i-1][j];                  // 不选
            if (j >= w[i])
                dp[i][j] = max(dp[i][j], dp[i-1][j - w[i]] + v[i]);  // 选
        }
    }
    cout << dp[n][W] << '\n';
    return 0;
}
```

#### 第二步：滚动数组压成一维

观察转移式：`dp[i][*]` **只依赖 `dp[i-1][*]`**。
所以可以把第一维**丢掉**，直接在同一个数组上更新。

**⚠️ 关键：容量必须「倒序」枚举！**

```cpp
int dp[W_MAX] = {0};          // dp[j] = 容量为 j 时的最大价值

for (int i = 1; i <= n; i++) {
    for (int j = W; j >= w[i]; j--) {          // ← 倒序！
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
cout << dp[W] << '\n';
```

**为什么必须倒序？（必考理解题）**

设想正序（`j` 从 `w[i]` 到 `W`）：

```
当 j = 3、w[i] = 2 时：
    dp[3] = max(dp[3], dp[1] + v[i])

当 j = 5、w[i] = 2 时：
    dp[5] = max(dp[5], dp[3] + v[i])
                      ↑ 这个 dp[3] 是本轮【刚更新过】的！
```

也就是说，**第 i 件物品被用了两次**（在 `dp[3]` 里用了一次，又在 `dp[5]` 里用了一次）。
这就变成了**完全背包**（每件可用无限次）。

**倒序**时，`j` 从大到小，`dp[j - w[i]]` 一定是**上一轮（`i-1`）的值**，
保证每件物品只被选一次。✅

> 🎯 **一句话记住**：
> **01 背包倒序（用「旧的」小容量），完全背包正序（用「新的」小容量）。**

#### 一维版的完整模板（背下来）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int W_MAX = 100005;
int w[1005], v[1005];
long long dp[W_MAX];          // ⚠️ 价值之和可能很大，用 long long

int main() {
    int n, W;
    cin >> n >> W;
    for (int i = 1; i <= n; i++) cin >> w[i] >> v[i];

    for (int i = 1; i <= n; i++) {
        for (int j = W; j >= w[i]; j--) {        // 倒序
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    cout << dp[W] << '\n';
    return 0;
}
```

### 8.4.2　完全背包

**区别**：**每件物品可以选无限次**。

```cpp
for (int i = 1; i <= n; i++) {
    for (int j = w[i]; j <= W; j++) {            // ← 正序！
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

**为什么正序就对？**
正序时 `dp[j - w[i]]` 是**本轮已更新过的**值（已经考虑了「再拿一件 i」），
所以天然允许无限次取用。

**实测对比**（`w = {2}`，`v = {3}`，`W = 6`）：

| | 01 背包 | 完全背包 |
|---|---|---|
| 结果 | `3`（只能拿 1 件） | `9`（拿 3 件） |

> 🎯 **一个超好用的判断法**：
> **看题目里物品能不能重复拿。**
> - 「每件最多选一次」→ 倒序
> - 「可以选无限次」→ 正序
>
> **只有这一个字的区别，但答错就是 0 分。**

### 8.4.3　多重背包

**区别**：第 `i` 件物品有 `c[i]` 个（有限个，不是 1 个也不是无限个）。

#### 做法一：拆成 01 背包（最直观）

把 `c[i]` 个相同的物品，当成 `c[i]` 个**独立的**物品，跑 01 背包。
复杂度 `O(W · Σc[i])`，`c[i]` 大时会超时。

#### 做法二：二进制拆分（推荐，必会！）

**核心思想**：把 `c` 个相同的物品，拆成 `1, 2, 4, 8, ..., 剩余` 个一组。

**为什么可行？**
`1, 2, 4, ..., 2^k` 可以组合出 `0 ~ 2^(k+1) - 1` 的**任何**数量。
所以「拆成 `log c` 组」和「拆成 `c` 个」在**效果上是等价的**。

**例**：`c = 13`，拆成 `1, 2, 4, 6`。
这四个数可以组合出 `0~13` 的任何值（比如 11 = 1+4+6，9 = 1+2+6）。

```cpp
// 二进制拆分 + 01 背包
int idx = 0;
for (int i = 1; i <= n; i++) {
    int c;
    cin >> c;
    for (int k = 1; c > 0; k <<= 1) {
        int take = min(k, c);            // 这一组取多少个
        w[++idx] = w[i] * take;
        v[idx]  = v[i] * take;
        c -= take;
    }
}
// 然后对 idx 个「新物品」跑 01 背包
```

**复杂度 `O(W · Σlog c[i])`**，快得多。

#### 做法三：单调队列优化

`O(nW)`。进阶内容，见 `WIDA` 模板库。

### 8.4.4　分组背包

**区别**：物品分成若干**组**，每组里**最多选一个**。

```cpp
for (int g = 1; g <= G; g++) {                 // 枚举组
    for (int j = W; j >= 0; j--) {             // ← 倒序（组内只能选一个）
        for (int i = 0; i < group[g].size(); i++) {   // 枚举组内物品
            int wi = w[group[g][i]], vi = v[group[g][i]];
            if (j >= wi)
                dp[j] = max(dp[j], dp[j - wi] + vi);
        }
    }
}
```

**⚠️ 三层循环的顺序不能换！**
`组` 在最外，`容量` 在中间，`组内物品` 在最内。

**为什么？** 因为「组内最多选一个」要求在**同一个容量 `j`** 上
比较「选组内哪一个」，而不是让它们互相叠加。
如果把「组内物品」放到外层，就会变成「同组物品可以都选」。

---

### 8.4.5　二维费用背包

**区别**：每件物品有**两个**代价（比如「重量」和「体积」），两个都不能超。

**做法**：`dp` 多加一维。

```cpp
// dp[j][k] = 重量 j、体积 k 时的最大价值
for (int i = 1; i <= n; i++) {
    for (int j = W1; j >= w1[i]; j--) {
        for (int k = W2; k >= w2[i]; k--) {        // 两维都倒序
            dp[j][k] = max(dp[j][k], dp[j - w1[i]][k - w2[i]] + v[i]);
        }
    }
}
```

**「最多选 M 件物品」也可以这样处理**：把「件数」当成第二维代价。

---

### 8.4.6　背包的几个变体

**① 求方案数**

把 `max` 改成「加法」：

```cpp
dp[0] = 1;                     // 容量 0 有 1 种方案（什么都不装）
for (int i = 1; i <= n; i++) {
    for (int j = W; j >= w[i]; j--) {
        dp[j] = (dp[j] + dp[j - w[i]]) % MOD;   // ← 累加
    }
}
cout << dp[W] << '\n';
```

**② 要求「恰好装满」**

初始化要改：

```cpp
// 求最大价值且恰好装满：
fill(dp, dp + W + 1, -INF);
dp[0] = 0;                    // 只有容量 0 是「合法」的初始状态
// 最后如果 dp[W] < 0，说明无法恰好装满
```

**为什么？** 因为「不选任何物品、容量为 0」是唯一的合法起点。
其它容量在不放物品时是**非法状态**，用 `-INF` 表示。

**对比**：「不超过容量」的题初始化为 `0`（因为「不装」是合法的）。

**③ 求具体方案**

开一个 `pre[i][j]` 记录「`dp[i][j]` 是从哪来的」，最后从 `dp[n][W]` 往回回溯。

**④ 输出字典序最小的最优方案**

从后往前做 01 背包，最后从前往后贪心选择。

### 8.4.7 背包问题总结表（建议截图保存）

| 类型 | 物品数量 | 第二层循环 | 关键点 |
|---|---|---|---|
| **01 背包** | 每件 1 个 | `j: W → w[i]`（**倒序**） | 每件只能用一次 |
| **完全背包** | 每件无限个 | `j: w[i] → W`（**正序**） | 可以重复拿 |
| **多重背包** | 每件 `c[i]` 个 | 拆成 01 背包（**二进制拆分**） | `1,2,4,...,余数` |
| **分组背包** | 每组选 1 个 | 组 → 容量倒序 → 组内物品 | **三层顺序不能换** |
| **二维费用** | — | 两个维度都倒序 | 两个代价都不能超 |
| **方案数** | — | 把 `max` 换成 `+` | `dp[0] = 1` |
| **恰好装满** | — | 初始化 `-INF`，`dp[0]=0` | 判断可行性 |

> 🎯 **解题时的判断流程**：
> ```
> 有「容量」和「价值」 → 是背包
>   ├── 每件最多一次？ → 01（倒序）
>   ├── 每件无限次？   → 完全（正序）
>   ├── 每件有限个？   → 多重（二进制拆分）
>   ├── 分组选一个？   → 分组
>   ├── 两个代价？     → 二维费用
>   └── 问方案数？     → 加法 + dp[0]=1
> ```

## 8.5　区间 DP

### 8.5.1　特征

**状态是「一个区间」** `dp[l][r]`，表示「区间 `[l, r]` 上的最优解」。

**典型信号**：
- 题目描述「合并相邻的…」「从中间切开…」
- 字符串 / 序列上，问「某个区间能不能…」

**枚举顺序**：**先枚举区间长度**（从小到大），
因为长的区间要用短的区间的结果。

### 8.5.2　模板

```cpp
// 一般形式
for (int len = 1; len <= n; len++) {              // ① 枚举长度
    for (int l = 1; l + len - 1 <= n; l++) {      // ② 枚举左端点
        int r = l + len - 1;                      // ③ 算出右端点
        // dp[l][r] = 从 dp[l][k] 和 dp[k+1][r] 转移
        for (int k = l; k < r; k++) {             // ④ 枚举断点
            dp[l][r] = max(dp[l][r], dp[l][k] + dp[k+1][r] + cost);
        }
    }
}
```

> 🎯 **为什么按长度枚举？**
> `dp[l][r]` 依赖 `dp[l][k]`（长度更小的左半段）和 `dp[k+1][r]`（右半段）。
> 按长度从小到大算，保证用到的子区间**都已经算好了**。

### 8.5.3　经典题：石子合并

**题目**：n 堆石子排成一排，每次可以合并**相邻的**两堆，
代价是两堆石子数之和。求合并成一堆的**最小总代价**。

**状态**：`dp[l][r]` = 「把 `[l, r]` 合并成一堆的最小代价」。

**转移**：

```cpp
// 把 [l, r] 分成 [l, k] 和 [k+1, r] 两堆，各自合并后再合并（代价 = 区间和）
dp[l][r] = min over k of ( dp[l][k] + dp[k+1][r] + sum(l..r) )
```

`sum(l..r)` 用**前缀和** `O(1)` 求出。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 305;         // n <= 300 时 O(n^3) ≈ 2.7e7，可以
int a[MAXN];
int pre[MAXN];                // 前缀和
int dp[MAXN][MAXN];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        pre[i] = pre[i - 1] + a[i];
    }

    // dp 初始为 0，长度为 1 时不需要合并（代价 0）
    for (int len = 2; len <= n; len++) {                  // 从长度 2 开始
        for (int l = 1; l + len - 1 <= n; l++) {
            int r = l + len - 1;
            dp[l][r] = INT_MAX;                           // 求 min，先设成很大
            int sum = pre[r] - pre[l - 1];                // 这段的石子总数
            for (int k = l; k < r; k++) {
                dp[l][r] = min(dp[l][r], dp[l][k] + dp[k + 1][r] + sum);
            }
        }
    }
    cout << dp[1][n] << '\n';
    return 0;
}
```

**复杂度 `O(n³)`**（三层循环），`n ≤ 300` 可用。

> ⚠️ **注意和「合并果子」的区别！**
> | 题目 | 能不能随便选 | 做法 | 复杂度 |
> |---|---|---|---|
> | **合并果子** | 任意两堆 | **贪心**（小根堆） | `O(n log n)` |
> | **石子合并** | **只能相邻** | **区间 DP** | `O(n³)` |
>
> **「相邻」两个字直接把贪心堵死了。**

**进阶（环形石子合并）**：把数组复制一份接到末尾，长度 `2n`，
最后答案取 `min(dp[i][i+n-1])`。

### 8.5.4　其他区间 DP 题

| 题目 | 状态 | 转移要点 |
|---|---|---|
| 括号匹配 | `dp[l][r]` 区间内最多匹配对数 | 两端匹配则 `dp[l+1][r-1]+1`，否则枚举断点 |
| 最长回文子序列 | `dp[l][r]` 最长回文子序列长度 | 两端相等 `+2`，否则 `max(去左, 去右)` |
| 涂色问题 | `dp[l][r]` 涂成目标的最少次数 | 按「能不能顺便涂」分类 |
| 矩阵连乘 | `dp[l][r]` 最少乘法次数 | 枚举断点 |
| 能量项链 | 环形 + 矩阵连乘 | 断环成链 |

## 8.6　状压 DP

### 8.6.1　特征与信号

**看到数据范围里有 `≤ 20` 左右的小范围** → 强烈怀疑是**状压**。

**核心**：把「一个集合」用**二进制掩码**表示，作为 DP 的一维下标。

| 信号 | 说明 |
|---|---|
| `n ≤ 20`（还要「选/不选」） | 子集状压 |
| `n ≤ 16` 且要「排列顺序」 | 状压 + 最后一个元素 |
| 棋盘上「不能相邻放」 | 轮廓线/行状压 |
| 元素是「字符/口味/关卡」等小集合 | 集合覆盖状压 |

### 8.6.2　经典模型一：TSP（旅行商问题）

**题目**：n 个城市（`n ≤ 18`），从 1 号出发，
每个城市**恰好访问一次**，最后回到 1 号，求最短总路程。

**状态**：`dp[mask][i]` = 「已经访问了集合 `mask`，**当前在第 `i` 个城市**」的最短路程。

**为什么要记「当前在城市 i」？**
因为下一步的路程取决于**从哪里出发**——
这就是「无后效性」要求我们补充的信息。

**转移**：从 `(mask, i)` 走到「未访问的城市 j」

```cpp
dp[mask | (1 << j)][j] = min(dp[mask | (1 << j)][j], dp[mask][i] + dist[i][j]);
```

**完整代码骨架**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;
int dist[20][20];
int dp[1 << 18][18];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            cin >> dist[i][j];

    memset(dp, 0x3f, sizeof(dp));
    dp[1][0] = 0;                     // 只访问了城市 0，当前在 0

    for (int mask = 1; mask < (1 << n); mask++) {
        for (int i = 0; i < n; i++) {
            if (dp[mask][i] == INF) continue;
            if (!((mask >> i) & 1)) continue;          // i 必须在集合里
            for (int j = 0; j < n; j++) {
                if ((mask >> j) & 1) continue;         // j 已经访问过
                int nxt = mask | (1 << j);
                dp[nxt][j] = min(dp[nxt][j], dp[mask][i] + dist[i][j]);
            }
        }
    }

    int full = (1 << n) - 1, ans = INF;
    for (int i = 1; i < n; i++) {
        ans = min(ans, dp[full][i] + dist[i][0]);      // 别忘了回起点
    }
    cout << ans << '\n';
    return 0;
}
```

**复杂度**：状态数 `2ⁿ × n`，转移 `O(n)` → **`O(2ⁿ · n²)`**。
`n = 18` 时 `2^18 × 324 ≈ 8.5e7`，勉强能过。

### 8.6.3　经典模型二：棋盘放棋子

**题目**：`n × m` 的棋盘上放棋子，要求**任意两个不能相邻**（上下左右）。
求方案数。`n, m ≤ 10`。

**思路**：
- **逐行放**，`mask` 表示**这一行**哪些位置放了棋子
- 行内的合法掩码必须先筛出来（不能有相邻的 1）

```cpp
// ① 预处理：行内合法的掩码（没有相邻的 1）
// 判断方法：(mask & (mask << 1)) == 0
vector<int> okMasks;
for (int mask = 0; mask < (1 << m); mask++) {
    if ((mask & (mask << 1)) == 0) okMasks.push_back(mask);
}

// ② dp[i][mask] = 前 i 行，第 i 行的状态是 mask 的方案数
for (int mask : okMasks) dp[1][mask] = 1;

for (int i = 2; i <= n; i++) {
    for (int cur : okMasks) {
        for (int prev : okMasks) {
            // 上下两行不能同一列都有棋子
            if (cur & prev) continue;
            dp[i][cur] = (dp[i][cur] + dp[i-1][prev]) % MOD;
        }
    }
}
```

**复杂度 `O(n · 2^m · 2^m)`**。`m = 10` 时 `10 × 1024 × 1024 ≈ 1e7`，可以过。

**可以预先筛掉不合法的 `prev`**（用 `((cur << 1) | (cur >> 1) | cur)` 取反）
把复杂度降到 `O(n · 3^m)` 级别。

### 8.6.4　状压 DP 的常见操作速查

```cpp
// 判断第 i 位是否为 1
if (mask >> i & 1)

// 把第 i 位置 1
mask | (1 << i)

// 把第 i 位置 0
mask & ~(1 << i)

// 翻转第 i 位
mask ^ (1 << i)

// 全 1（n 个元素全选）
(1 << n) - 1

// 判断 mask 里有没有相邻的 1
(mask & (mask << 1)) == 0

// 求补集（在 n 位范围内）
full ^ mask        // full = (1 << n) - 1

// 枚举 mask 的所有子集
for (int sub = mask; sub; sub = (sub - 1) & mask)

// 去掉最低位的 1
mask & (mask - 1)

// 取出最低位的 1
mask & (-mask)
```

> ⚠️ **`1 << n` 的溢出问题**：
> `n ≥ 31` 时 `1 << n` 在 `int` 里是**未定义行为**。
> 用 `1LL << n`，数组类型也要跟着改。

> 📎 本仓库对应代码：
> - `z状压dp/蓝桥2019省A _糖果` （集合覆盖状压）
> - 第 07 章 例题 2 也是这题的详解

## 8.7　树形 DP

### 8.7.1　特征

**在树上做 DP**，通常用 **DFS 递归**实现：
先递归处理所有儿子，再把儿子的结果**合并**到父亲。

**固定框架**：

```cpp
void dfs(int u, int fa) {         // u 是当前节点，fa 是父亲（避免走回去）
    // ① 初始化 dp[u]
    for (int v : g[u]) {
        if (v == fa) continue;    // 不走回头路
        dfs(v, u);                // ② 先处理儿子
        // ③ 把儿子的信息合并到 u
    }
}
```

> 🎯 **树形 DP 的难点是「合并」这一步**（背包合并、取 max/min 等）。
> 而 **DFS 的骨架本身是固定的**。

### 8.7.2　经典题：没有上司的舞会

**题目**：n 个人构成一棵树（上下级关系）。
每个人有一个「快乐值」。不能**同时**选一个上司和他的直接下属。
求能获得的最大快乐值之和。

**状态**：

```cpp
dp[u][0]   // 不选 u 时，以 u 为根的子树能得到的最大快乐值
dp[u][1]   // 选了 u 时，……
```

**转移**：

```cpp
// 不选 u：儿子可以选也可以不选，取 max
dp[u][0] = Σ max(dp[v][0], dp[v][1]);

// 选了 u：儿子都不能选
dp[u][1] = a[u] + Σ dp[v][0];
```

**完整代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 6005;
vector<int> g[MAXN];
int a[MAXN];
int dp[MAXN][2];
bool hasParent[MAXN];

void dfs(int u) {
    dp[u][1] = a[u];                  // 选 u，先加上自己的快乐值
    dp[u][0] = 0;                     // 不选 u
    for (int v : g[u]) {
        dfs(v);
        dp[u][0] += max(dp[v][0], dp[v][1]);   // 儿子随意
        dp[u][1] += dp[v][0];                  // 儿子不能选
    }
}

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];

    for (int i = 1; i < n; i++) {
        int u, v;                     // u 是 v 的上级（u 是父亲）
        cin >> u >> v;
        g[u].push_back(v);
        hasParent[v] = true;
    }

    int root = 1;
    while (hasParent[root]) root++;   // 找根（没有父亲的节点）

    dfs(root);
    cout << max(dp[root][0], dp[root][1]) << '\n';
    return 0;
}
```

**复杂度 `O(n)`**。

### 8.7.3　经典题：树形背包

**题目**：选一些课程（有先修关系，树形），每门课有学分，总共选 `m` 门，
选了儿子必须先选父亲，求最大学分。

**状态**：`dp[u][j]` = 「以 u 为根的子树里选 j 门课的最大收益」。

**转移**（本质是分组背包）：

```cpp
void dfs(int u) {
    dp[u][1] = val[u];                       // 选 u 自己
    for (int v : g[u]) {
        dfs(v);
        // 背包合并：在「已处理的儿子」和「新儿子 v」之间分配名额
        for (int j = m; j >= 1; j--) {
            for (int k = 0; k <= j - 1; k++) {
                dp[u][j] = max(dp[u][j], dp[u][j - k] + dp[v][k]);
            }
        }
    }
}
```

**复杂度 `O(n · m²)`**。
（可以优化到 `O(nm)`，见「树形背包优化」）

> 📎 本仓库相关代码：`text_dp.cpp` 里有树形 DP 的 `siz[]`（子树大小）写法，
> `gp_text/newcode3.cpp` 是「换根 / 前缀和遍历子女」的树形 DP。

### 8.7.4　树形 DP 常用套路

```cpp
// 子树大小
void dfs_size(int u, int fa) {
    siz[u] = 1;
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs_size(v, u);
        siz[u] += siz[v];
    }
}

// 子树内的最大值 / 和
void dfs_sum(int u, int fa) {
    sum[u] = val[u];
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs_sum(v, u);
        sum[u] += sum[v];
    }
}
```

**换根 DP**：需要「以每个点为根」的答案时，
先跑一次求出「以 1 为根」的结果，再用儿子和父亲的差值推出其它根的结果。

> 📎 参考 `gp_text/newcode3.cpp`：它先算子树和 `sub[]`，
> 再用 `dfs_ans` 把「来自父亲方向的贡献」`cur` 传下去。

## 8.8　数位 DP

### 8.8.1　它解决什么问题

**题目**：求 `[0, n]` 中有多少个数的十进制表示满足某种条件
（比如「不含 49」「数位和是 k 的倍数」「相邻位不相等」）。

**特点**：`n` 可能很大（`1e18`），**不可能枚举**。
但**数位只有 18 位**，可以「按位 DP」。

**核心思想**：

> 从**最高位**开始一位一位地填，
> 用 `limit` 表示「前面的位是否贴着上界」。

### 8.8.2 两个关键标记

| 标记 | 含义 |
|---|---|
| **`limit`** | 前面的位是不是「全部贴住了 n 的对应位」。<br>如果是，当前位**最多只能填 `digits[pos]`**；否则可以填 `0~9` 任意。 |
| **`lead`** | 前面是不是全是前导零。有些题要区分「0」和「前导零」。 |

### 8.8.3 模板（统计 `[0, n]` 中不含 `49` 的数）

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll dp[20][2];          // dp[pos][pre_is_4] 记忆化
int digits[20];        // n 的每一位（低位在前）

// pos: 当前填到第几位（从高位往低位，这里用低位索引）
// pre_is_4: 上一位是不是 4
// limit: 是否贴着上界
ll dfs(int pos, bool pre_is4, bool limit) {
    if (pos < 0) return 1;                     // 所有位填完，方案数 +1

    // 只在「不受 limit 限制」时才能用记忆化
    if (!limit && dp[pos][pre_is4] != -1) return dp[pos][pre_is4];

    int up = limit ? digits[pos] : 9;          // 这一位能填的最大值
    ll res = 0;
    for (int d = 0; d <= up; d++) {
        if (pre_is4 && d == 9) continue;       // 出现 "49"，不合法
        res += dfs(pos - 1, d == 4, limit && d == up);
    }

    if (!limit) dp[pos][pre_is4] = res;
    return res;
}

ll solve(ll n) {
    if (n < 0) return 0;
    int len = 0;
    while (n) { digits[len++] = n % 10; n /= 10; }
    memset(dp, -1, sizeof(dp));
    return dfs(len - 1, false, true);
}

int main() {
    ll l, r;
    cin >> l >> r;
    cout << solve(r) - solve(l - 1) << '\n';   // 区间 [l, r]
    return 0;
}
```

### 8.8.4 数位 DP 的四个关键点

**① 为什么 `limit == true` 时不能记忆化？**

因为 `limit == true` 的状态**只会出现一次**（就是沿着 n 的那条路径）。
存了也用不上，而且会污染「不受限」时的结果。

**② 为什么 `dp` 的维度里没有 `limit`？**

同上，`limit` 不进状态，只影响「上界」和「能不能用缓存」。

**③ 求区间 `[l, r]` 用前缀和思想**

```cpp
answer = solve(r) - solve(l - 1);
```

因为 `solve(x)` 求的是 `[0, x]` 的答案，两者相减就是 `[l, r]`。

**④ `dp` 数组的维度由「需要的额外信息」决定**

| 题目 | 状态 |
|---|---|
| 不含 49 | `dp[pos][pre_is_4]` |
| 数位和 | `dp[pos][sum]` |
| 相邻位不同 | `dp[pos][pre_digit]` |
| 数字出现次数 | `dp[pos][cnt]` |

> ⚠️ **数位 DP 最容易出的两个 bug**：
> 1. **忘记 `limit` 判断就记忆化** → 答案错误
> 2. **`memset(dp, -1, ...)` 写在 `solve` 外面** → 多组数据出错
>    （因为 `dp` 的含义依赖「有没有 `limit`」，必须每次清）
>
> 不过如果题目条件**与 `n` 无关**（如「不含 49」），
> 其实可以**只算一次**再复用。安全起见，**每次清空最稳**。

## 8.9　例题精讲

### 例题 1：飞扬的小鸟（背包思想的混合应用）⭐⭐

> 本题代码见 `newcode_dp/dp1.cpp`（文件里带了完整题面）。

**题意**（简化）：
游戏画面是 `n × m` 的网格。小鸟从最左边任意高度出发，要飞到最右边。
在横坐标 `i` 处：
- **点击屏幕**：上升 `up[i]` 高度（一个单位时间内可以点**多次**，效果叠加）
- **不点击**：下降 `down[i]` 高度
- 高度为 `0` 或碰到管道 → 失败；高度为 `m` 时**不能再上升**

求：能否通关；若能，最少的点击次数。

**状态定义**：

```cpp
dp[i][j] = 「到达横坐标 i、高度 j 时的最少点击数」
```

**为什么这题是「背包」？**

| 操作 | 可否重复 | 对应的背包 |
|---|---|---|
| **点击上升** | ✅ 一次时间内可点**多次** | **完全背包**（正序） |
| **不点下降** | ❌ 只能下降一次 | **01 背包**（倒序） |

**一次转移要跑两种背包**，这是本题最精妙的地方。

**核心代码**：

```cpp
const int N = 10010, M = 2010, INF = 0x3f3f3f3f;
int n, m, k;
int up[N], down[N];
int low[N], high[N];      // 管道缝隙的下/上边沿
int dp[N][M];

memset(dp, 0x3f, sizeof(dp));
for (int j = 1; j <= m; ++j) dp[0][j] = 0;      // 最左边任意高度，0 次点击

for (int i = 1; i <= n; ++i) {
    // ---------- 上升：完全背包（正序） ----------
    int limit = m + up[i];
    for (int j = up[i] + 1; j <= limit; ++j) {
        dp[i][j] = min(dp[i][j], dp[i-1][j - up[i]] + 1);   // 从上一位置上升
        dp[i][j] = min(dp[i][j], dp[i][j - up[i]] + 1);     // 在本位置再点一次
                    // ↑ 这一行是「完全背包」的标志：用【本轮】的值
    }

    // ---------- 顶部压缩：超过 m 的全部压到 m ----------
    for (int j = m + 1; j <= limit; ++j)
        dp[i][m] = min(dp[i][m], dp[i][j]);

    // ---------- 下降：01 背包（倒序） ----------
    for (int j = 1; j <= m - down[i]; ++j)
        dp[i][j] = min(dp[i][j], dp[i-1][j + down[i]]);
                    // ↑ 用【上一轮】的值，因为只能下降一次

    // ---------- 管道障碍：被挡住的高度设为不可达 ----------
    for (int j = 1; j <= low[i]; ++j)  dp[i][j] = INF;
    for (int j = high[i]; j <= m; ++j) dp[i][j] = INF;

    // ---------- 判断是否全部不可达 ----------
    bool ok = false;
    for (int j = 1; j <= m; ++j)
        if (dp[i][j] < INF) { ok = true; break; }
    if (!ok) {
        cout << "0\n" << passed << '\n';    // 输出最多通过的管道数
        return 0;
    }
    if (low[i] > 0 || high[i] < m + 1) passed++;
}
```

**这道题要学到的四件事**：

**① 上升用正序、下降用倒序 —— 同一个 DP 里混用两种背包**

看代码里这两个关键行：
```cpp
dp[i][j] = min(dp[i][j], dp[i][j - up[i]] + 1);     // 本层 → 正序（可重复）
dp[i][j] = min(dp[i][j], dp[i-1][j + down[i]]);      // 上层 → 倒序（只一次）
```

**② 「顶部压缩」是一个常见技巧**

高度超过 `m` 的会被「压」到 `m`（撞到天花板）。
写法是把 `dp[i][m+1] ~ dp[i][m+up[i]]` 的最小值合并进 `dp[i][m]`。

**③ 边界高度的处理**

高度 `0` 和碰到管道都是失败。代码里用 `INF` 表示不可达，
并通过「整列全是 `INF`」来判定游戏结束。

**④ 数组大小的取舍**

```cpp
int dp[N][M];        // 10010 × 2010 × 4B ≈ 80 MB
```

**这个数组偏大**（`80MB`，如果内存限制是 `128MB` 就很危险）。

> 💡 **优化方向**：观察转移，`dp[i][*]` **只依赖 `dp[i-1][*]`** → 可以**滚动数组**：
> ```cpp
> int dp[2][M];        // 只留两层，2 × 2010 × 4B ≈ 16 KB
> ```
> 用 `i & 1` 和 `(i-1) & 1` 交替使用即可。**这是空间优化的通用手段。**

> 🎯 **「状态只依赖上一层 → 滚动数组」**：
> 0/1 背包其实就是 01 背包二维版滚到一维的极端情况（只保留容量维，用倒序保证正确）。
> 看到 `dp[i]` 只依赖 `dp[i-1]`，就该想到滚动。

### 例题 2：完全背包 + 整除分块

> 本题代码见 `nk_zhou_sai_147/nk_147_F.cpp`。

**题型**：给定 `n, x, k`，构造一个长度 `n` 的数组 `a`，
使得 `Σ ⌊x / a_i⌋ = k`，输出任意一组合法解。

**这道题的两个关键点**：

**① 先算答案的可行范围**

```cpp
// a_i 取 x 时，floor(x/x) = 1     → 总和最小 = n
// a_i 取 1 时，floor(x/1) = x     → 总和最大 = n * x
if (k < n || k > 1LL * n * x) { cout << "NO\n"; return; }
```

**② 用「增量」做完全背包**

设 `d = k - n`（需要额外增加的权值）。
枚举所有**不同的** `⌊x / v⌋` 值（只有 `O(√x)` 种），
每种对应一个「增量」`c - 1`：

```cpp
vector<pair<int,int>> val_inc;      // {增量, 对应的 v}
for (int v = 1; v <= x; ) {
    int c = x / v;                  // 当前块的 floor 值
    int nxt_v = x / c + 1;          // 下一块的起点（整除分块技巧）
    if (c > 1) val_inc.push_back({c - 1, v});
    v = nxt_v;                      // 跳到下一块
}
```

然后跑**完全背包**，求「凑出 `d` 所需的最少元素个数」，
剩余位置全填 `x`（增量 0）。

**这道题的价值**：
- 展示了「用 DP 求**最少个数**」（而不是最大价值）的写法
- 展示了**整除分块**如何把 `O(x)` 的枚举压到 `O(√x)`
- 展示了**构造题**的标准套路：先判可行性范围，再用 DP 构造

> 📎 整除分块（数论分块）的完整讲解见 [第 10 章](10-数论与组合数学.md)。

## 8.10　本章常见坑

| # | 坑 | 说明 |
|:---:|---|---|
| 1 | 01 背包写成正序 | 变成完全背包，答案偏大 |
| 2 | 完全背包写成倒序 | 变成 01 背包，答案偏小 |
| 3 | 分组背包三层循环顺序换了 | 组内物品会互相叠加 |
| 4 | DP 数组没初始化 | 求 `min` 时要设为 `INF` |
| 5 | 「恰好装满」用了 `0` 初始化 | 应该有 `-INF`/`INF`，只有 `dp[0]=0` |
| 6 | 状态定义漏了信息 | 违反「无后效性」，答案错 |
| 7 | 区间 DP 按左端点枚举 | **必须先按长度** |
| 8 | 状压 `1 << n` 溢出 | `n ≥ 31` 要用 `1LL << n` |
| 9 | 状压数组开太大 | `2^25 × 4B = 134MB` ⚠️ |
| 10 | 数位 DP 在 `limit==true` 时记忆化 | 会污染结果 |
| 11 | 多组数据 `dp` 没清空 | 上一组数据污染这一组 |
| 12 | DP 值溢出 `int` | 方案数、代价和都要看范围 |

**最容易混淆的三组对比（一定要分清）：**

| 对比 | 区别 | 记忆法 |
|---|---|---|
| 01 背包 vs 完全背包 | 倒序 vs **正序** | 「只能选一次」→ 倒序 |
| 合并果子 vs 石子合并 | **贪心** vs **区间 DP** | 「相邻」→ 区间 DP |
| 记忆化搜索 vs 递推 | 递归+缓存 vs 循环 | 先写记忆化，卡常再改递推 |

## 本章小结

**DP 三要素（必须能脱口而出）：**

1. **状态**：`dp[...]` 代表什么？
2. **转移**：最后一步做了什么选择？
3. **边界**：最小的状态是什么？

**六个必经模型：**

| 模型 | 状态形状 | 关键点 |
|---|---|---|
| **线性 DP** | `dp[i]` / `dp[i][j]` | 「以 i 结尾」是经典套路 |
| **背包** | `dp[容量]` | 01 倒序、完全正序 |
| **区间 DP** | `dp[l][r]` | **按长度枚举** |
| **状压 DP** | `dp[mask][...]` | `n ≤ 20` 的信号 |
| **树形 DP** | `dp[u][...]` | DFS 递归 + 合并儿子 |
| **数位 DP** | `dp[pos][...]` | `limit` 标记 |

**三条救命的经验：**

1. **想不出转移方程 → 先写暴力递归 → 加缓存 → 就变成 DP 了**
2. **状态定义别漏信息**，问自己「这个状态够不够推出下一步」
3. **01 背包和完全背包只差一个循环方向**，写之前先确认物品能不能重复拿
