# 第 07 章　搜索与回溯

> **本章目标**：掌握「暴力 + 优化」这套最可靠的解题方法。
>
> **搜索是竞赛的地基**：
> - 图论（第 09 章）里 Dijkstra、Tarjan 都是「带优先级的 BFS/DFS」
> - DP（第 08 章）的转移顺序，本质上是在一张 DAG 上做「记忆化搜索」
> - 想不出正解时，**能写出搜索 = 能拿部分分**

---

## 7.1　DFS 与 BFS 怎么选

| | DFS（深度优先） | BFS（广度优先） |
|---|---|---|
| 数据结构 | **栈**（递归就是栈） | **队列** |
| 走法 | 一条路走到黑，再回头 | 一层一层扩散 |
| 擅长 | 枚举所有方案、回溯、连通性、拓扑 | **求最短路（边权全为 1）**、分层 |
| 空间 | 与**深度**有关 | 与**每层宽度**有关 |
| 缺点 | 深度大时**爆栈** | 队列可能**很大** |

**选型口诀**：

```
问「有没有 / 有多少种方案」 → DFS + 回溯
问「最少几步 / 最短距离」   → BFS
求「所有路径」              → DFS
```

> ⚠️ **BFS 求最短路的条件：边权必须全部相同**（通常都是 1）。
> 边权不同要用 Dijkstra（第 09 章）。

## 7.2　DFS 深度优先搜索

### 7.2.1　递归框架

```cpp
// 图的邻接表
vector<vector<int>> g;
vector<bool> vis;

void dfs(int u) {
    vis[u] = true;                  // ① 标记已访问
    // 现在处理节点 u ...
    for (int v : g[u]) {            // ② 遍历所有邻居
        if (!vis[v]) {              // ③ 没访问过的才递归
            dfs(v);
        }
    }
}
```

**这个框架要记到骨子里**，图论、树、DP 到处都是它的影子。

### 7.2.2　连通块计数

```cpp
int cnt = 0;
for (int i = 1; i <= n; i++) {
    if (!vis[i]) {
        cnt++;          // 发现一个新的连通块
        dfs(i);         // 把整个块标记完
    }
}
```

**复杂度 `O(n + m)`**（每个点访问一次，每条边看两次）。

### 7.2.3　用栈实现 DFS（防爆栈）

递归深度超过约 `1e5` 就可能爆栈。**改成手动开栈**：

```cpp
vector<int> dfsStack(int start, vector<vector<int>> &g, int n) {
    vector<bool> visited(n + 1, false);
    vector<int> order;
    stack<int> st;

    st.push(start);
    visited[start] = true;

    while (!st.empty()) {
        int u = st.top();
        st.pop();
        order.push_back(u);

        for (int v : g[u]) {
            if (!visited[v]) {
                visited[v] = true;      // ← 【重要】入栈时就标记！
                st.push(v);
            }
        }
    }
    return order;
}
```

> ⚠️ **「入栈时标记」还是「出栈时标记」？**
> 用**入栈时标记**。否则同一个点可能被**多次入栈**，效率极差。
> （这一点也是 BFS 里必须注意的。）

> 📎 本仓库对应代码：`templates/03_graph/dfs_stack.cpp`
> （原始文件 `ban_zi/stack_dfs.cpp`，演示了城市连通的遍历顺序）

### 7.2.4　DFS 的应用清单

| 用途 | 说明 |
|---|---|
| 连通性判断 | 从一个点能不能走到另一个 |
| 连通块计数 | 上面例子 |
| 拓扑排序 | 后序遍历的逆序（也可以用入度为 0 的队列） |
| 树的遍历 | 前序/中序/后序、求子树大小、树形 DP |
| 找环 | 记录「正在访问」的点，遇到就是环 |
| 二分图判定 | 染色法（相邻点不同色） |
| 枚举所有方案 | 见 7.4 回溯 |
| 记忆化搜索 | DFS + 缓存，本质就是 DP |

## 7.3　BFS 广度优先搜索

### 7.3.1　核心框架（求最短路）

```cpp
#include <bits/stdc++.h>
using namespace std;

int bfs(int start, int target, vector<vector<int>> &g, int n) {
    vector<int> dist(n + 1, -1);      // -1 表示没访问过
    queue<int> q;

    dist[start] = 0;                  // 起点距离 0
    q.push(start);                    // ← 【重要】入队时就设 dist

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        if (u == target) return dist[u];   // 到达终点

        for (int v : g[u]) {
            if (dist[v] == -1) {           // 没访问过
                dist[v] = dist[u] + 1;     // 距离 = 上一层的距离 + 1
                q.push(v);
            }
        }
    }
    return -1;                        // 走不到
}
```

> 🎯 **BFS 求最短路为什么是对的？**
> BFS 按「距离起点的步数」**从小到大**访问节点。
> 第一次访问到某点时，走的**一定是最少步数**（否则更短的路径会先访问到它）。
>
> 这就是「层序遍历」，用**队列**天然实现了「先访问距离近的」。

### 7.3.2　网格（迷宫）BFS

网格题是 BFS 出现最多的地方。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int dx[4] = {-1, 1, 0, 0};
const int dy[4] = { 0, 0,-1, 1};

int n, m;
char mp[1005][1005];
int dist[1005][1005];

int bfsGrid(int sx, int sy, int tx, int ty) {
    memset(dist, -1, sizeof(dist));
    queue<pair<int,int>> q;

    dist[sx][sy] = 0;
    q.push({sx, sy});

    while (!q.empty()) {
        auto [x, y] = q.front();
        q.pop();

        if (x == tx && y == ty) return dist[x][y];

        for (int d = 0; d < 4; d++) {
            int nx = x + dx[d], ny = y + dy[d];
            // ① 越界检查  ② 是墙  ③ 已访问
            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            if (mp[nx][ny] == '#') continue;
            if (dist[nx][ny] != -1) continue;

            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
    return -1;
}
```

**四面方向的数组（背下来）**：

```cpp
// 上下左右
const int dx[4] = {-1, 1, 0, 0};
const int dy[4] = { 0, 0,-1, 1};

// 八方向（含对角线）
const int dx8[8] = {-1, -1, -1, 0, 0, 1, 1, 1};
const int dy8[8] = {-1,  0,  1,-1, 1,-1, 0, 1};
```

**用方向数组的好处**：不用写四遍 `if`，`for` 循环 4 次就搞定。

### 7.3.3　多源 BFS

**问题**：有多个起点，求每个点到「最近的起点」的距离。

**技巧**：**把所有起点一次性全部入队**（初始 `dist = 0`），
然后正常 BFS。

```cpp
queue<pair<int,int>> q;
for (auto [x, y] : sources) {
    dist[x][y] = 0;
    q.push({x, y});
}
// 之后正常 BFS
```

**为什么对？** 相当于加了一个「超级源点」连向所有起点，跑普通 BFS。

### 7.3.4　0-1 BFS

**问题**：图的边权只有 **0 和 1**，求最短路。

**技巧**：用 **双端队列 `deque`**：
- 边权为 **0** → 推到**队首**（`push_front`）
- 边权为 **1** → 推到**队尾**（`push_back`）

```cpp
deque<int> dq;
dist[s] = 0;
dq.push_front(s);

while (!dq.empty()) {
    int u = dq.front(); dq.pop_front();
    for (auto [v, w] : g[u]) {           // w 只能是 0 或 1
        if (dist[v] > dist[u] + w) {
            dist[v] = dist[u] + w;
            if (w == 0) dq.push_front(v);
            else        dq.push_back(v);
        }
    }
}
```

**复杂度 `O(n + m)`**，比 Dijkstra 的 `O(m log n)` 快。

> 💡 这就是「最短路算法大家族」的第一个成员。更通用的见第 09 章。

### 7.3.5　双向 BFS

**问题**：起点到终点状态空间巨大，但**答案步数很少**。

**技巧**：**从起点和终点同时 BFS**，两边相遇就停止。

```
单向：1 层 → 分支数 b 的 d 次方
双向：两棵深度 d/2 的树 → 约 2 × b^(d/2)  ← 快得多
```

**例子**：八数码（3×3 滑块）问题，单向 BFS 状态数 `9! = 362880`，
双向 BFS 只需处理 `9!/2` 的一半深度。

**实现要点**：
- 开两个 `dist` 数组（或一个记录「哪边访问过」）
- 每次选**队列元素较少**的一边扩展
- 某点被两边都访问到时 → 答案 = `dist1 + dist2`

## 7.4　回溯（DFS 枚举所有方案）

### 7.4.1　核心思想

**回溯 = DFS + 撤销**。

```
选择一个候选
   ↓
递归进去继续选
   ↓
回来后【撤销】刚才的选择，试试下一个候选
```

**固定模板**：

```cpp
void dfs(状态) {
    if (到达终点 / 满足条件) {
        记录答案;
        return;
    }
    for (每个候选 c) {
        if (c 不合法) continue;       // 剪枝
        做出选择(应用 c);
        dfs(新状态);                  // 递归
        撤销选择(恢复 c);              // ← 回溯！最关键的一步
    }
}
```

> 🎯 **「做选择 → 递归 → 撤销」**，这三步是回溯的全部。
> **忘记撤销 = 后面所有分支都被污染**，是回溯最经典的 bug。

### 7.4.2　例 1：全排列

**题目**：输出 `1..n` 的所有排列。

```cpp
int n;
vector<int> path;                 // 当前正在构造的排列
bool used[15];                    // used[i] = 数字 i 是否已使用

void dfs() {
    if ((int)path.size() == n) {              // 已经选满 n 个
        for (int x : path) cout << x << ' ';
        cout << '\n';
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (used[i]) continue;                // ① 剪枝：已经用过
        used[i] = true;                       // ② 做出选择
        path.push_back(i);
        dfs();                                // ③ 递归
        path.pop_back();                      // ④ 撤销选择
        used[i] = false;
    }
}
```

**复杂度 `O(n! · n)`**，`n ≤ 10` 可用。

> 💡 **`next_permutation` 也能做全排列**（第 02 章 2.8），
> 但**回溯是通用方法**，能解决 `next_permutation` 解决不了的问题（如八皇后）。

### 7.4.3　例 2：N 皇后 ⭐

**题目**：在 `n × n` 的棋盘上放 n 个皇后，
要求**任意两个皇后不在同一行、同一列、同一条斜线**，求方案数（及前 3 个方案）。

**思路**：
- **逐行放置**：第 `step` 行放一个皇后 → 自然满足「不在同一行」
- 用三个数组记录冲突：
  - `col[y]`：第 y 列有没有皇后
  - `diag1[x + y]`：主对角线（`↘`方向，`x + y` 相同）
  - `diag2[x - y + n]`：副对角线（`↙`方向，`x - y` 相同，加 n 避免负数下标）

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
int m1[30], m2[30], m3[30];   // col / diag1 / diag2
int ans[15];                  // 记录每行皇后所在的列
int mark = 0;                 // 方案总数

// 在第 x 行的第 y 列放置（k=1 放置，k=0 撤销）
void setvalue(int x, int y, int k) {
    ans[x] = y;
    m1[y] = k;
    m2[x + y] = k;
    m3[x - y + n] = k;
}

void dfs(int step) {
    if (step > n) {                  // 所有行都放好了
        mark++;
        if (mark <= 3) {             // 题目只要前 3 个方案
            for (int i = 1; i <= n; i++) cout << ans[i] << ' ';
            cout << '\n';
        }
        return;
    }
    for (int j = 1; j <= n; j++) {
        // 冲突检查（剪枝）
        if (m1[j] == 1 || m2[step + j] == 1 || m3[step - j + n] == 1) continue;
        setvalue(step, j, 1);
        dfs(step + 1);
        setvalue(step, j, 0);        // ← 回溯
    }
}
```

> 📎 本仓库对应代码：`N_que.cpp`

**关键点**：
1. **斜线用下标映射**表示：`x + y` 和 `x - y + n`，一次判断搞定
2. **`x - y + n`**：`x - y` 可能为负 → 加 `n` 偏移到正数区间
3. 数组开 `30`：`x + y` 最大 `2n = 26`，`x - y + n` 在 `1..2n-1`

> 💡 **优化**：`n = 13` 时 `13! ` 级别，回溯会慢。
> 可以用**位运算**加速冲突判断（`int` 的 32 位表示列/斜线占用情况）。

### 7.4.4　例 3：数独

**思路**：**找空格 → 试 1~9 → 检查行、列、九宫格 → 递归 → 撤销**。

**剪枝关键**：**优先填「候选数字最少」的空格**（MRV 启发式），
能极大减少搜索量。这是回溯题最重要的优化技巧。

### 7.4.5　回溯的复杂度怎么估

回溯本质是**枚举所有可能**，复杂度通常是「分支数的深度次方」：

| 问题 | 复杂度 | 可用范围 |
|---|---|---|
| 全排列 | `O(n!)` | `n ≤ 10` |
| 子集枚举 | `O(2ⁿ)` | `n ≤ 20` |
| N 皇后 | `O(n!)` 但剪枝后 ≈ `O(n!)` 的很小一部分 | `n ≤ 13` |
| 数独 | 剪枝后接近 `O(9^空格数)` | 标准 9×9 秒过 |

> 🎯 **判断能否用回溯的实用方法**：
> 估一下「最坏情况的搜索次数」，
> 如果**超过 `1e8`** 就要剪枝或换算法。

## 7.5　剪枝（回溯的灵魂）

**剪枝 = 提前发现「这条路走下去没有意义」，直接返回。**

**不剪枝的回溯 = 暴力枚举 = 必然超时。**
**剪枝的好坏直接决定这题能不能过。**

### 7.5.1 四类剪枝

**① 可行性剪枝**

「当前状态已经不可能满足条件了」→ 直接返回。

```cpp
// 例：凑数问题，目标和为 S，已经超过 S 了
if (sum > S) return;
```

**② 最优性剪枝**

「当前已经比已知最优解差了」→ 直接返回。

```cpp
// 例：求最小花费，当前花费已经 >= 目前最优
if (cost >= best) return;
```

> 🎯 **最优性剪枝的威力巨大**。配合「先搜更容易出好解的分支」
> （即**搜索顺序优化**），效果翻倍。

**③ 搜索顺序剪枝**

**先搜「最可能出好解」或「分支最少」的分支**。

- 数独：先填候选最少的格子
- 求最小花费：先搜花费小的分支（让 `best` 快速变小）
- 排序后搜索：小元素优先

**④ 记忆化（把搜索变成 DP）**

**同一个状态被重复计算时，把结果存下来。**

```cpp
int memo[N][M];
bool visited[N][M];

int dfs(int x, int y) {
    if (到达终点) return 0;
    if (visited[x][y]) return memo[x][y];       // ← 直接返回缓存

    visited[x][y] = true;
    int res = 初始值;
    for (每个转移) res = 最优(res, dfs(...));
    return memo[x][y] = res;                     // ← 存缓存
}
```

> 🎯 **记忆化搜索 = DP 的递归写法**。
> 「能写记忆化就别写递推」—— 因为记忆化**只算用得到的状态**，
> 而且**转移顺序不用自己安排**。
> 第 08 章会大量用到这个技巧。

### 7.5.2 剪枝的实战例子

**例子：从 n 个数里选若干个，使它们的和为 S，输出一个方案。**

```cpp
int n, S;
int a[25];
vector<int> chosen;
bool found = false;

// 先按从大到小排序 → 更快的逼近 S（搜索顺序剪枝）
void dfs(int idx, int sum) {
    if (found) return;                          // 已经找到，全部剪掉
    if (sum == S) { found = true; return; }     // 成功
    if (idx == n) return;                       // 选完了

    // 【可行性剪枝】已经超过 S
    if (sum > S) return;

    // 【可行性剪枝】剩下的全选也凑不够
    // （需要预处理后缀和）

    // 选 a[idx]
    chosen.push_back(a[idx]);
    dfs(idx + 1, sum + a[idx]);
    if (found) return;
    chosen.pop_back();

    // 不选 a[idx]
    dfs(idx + 1, sum);
}
```

**这段代码里有 4 种剪枝**：
1. `if (found) return;` —— 找到就停
2. `if (sum > S) return;` —— 可行性
3. 排序后从大到小搜 —— 搜索顺序
4. 后缀和判断 —— 可行性（更强）

### 7.5.3 剪枝的常见错误

| 错误 | 后果 |
|---|---|
| 剪枝条件写反 | 把正确解剪掉了 → `Wrong Answer` |
| 剪枝不足 | 照样超时 |
| 剪枝过度 | 漏解，答案偏小 |
| 忘记「撤销」 | 各分支互相污染 |

> ⚠️ **验证剪枝正确性的唯一可靠方法：对拍**。
> 写一个「不剪枝的暴力」和「剪枝版」，比较答案是否一致。

## 7.6　例题精讲

### 例题 1：迷宫最短路（BFS 模板题）

**题意**：`n × m` 的网格，`.` 可走、`#` 是墙，
从起点走到终点，求最少步数（4 方向）。

**思路**：直接套 7.3.2 的网格 BFS。

**这道题的三个易错点**：

```cpp
// ① 越界检查必须写在最前面
if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;

// ② 入队时就标记距离，不要等出队
dist[nx][ny] = dist[x][y] + 1;
q.push({nx, ny});

// ③ 起点就是终点的情况
if (sx == tx && sy == ty) return 0;   // 别忘了
```

> ⚠️ **第 ② 点非常重要**。如果写成「出队时才标记」，
> 同一个格子会被**多次入队**，队列可能膨胀到 `O(n²m²)` → 超时或 MLE。

**复杂度**：`O(nm)`（每个格子最多进出一次）。

### 例题 2：糖果（状态压缩 + BFS/DP）⭐

> 本题代码见 `z状压dp/蓝桥2019省A _糖果`（文件里带了完整题面）。

**题意**：
糖果店有 `M` 种口味的糖果，但只能**整包买**，每包 `K` 颗。
给 `N` 包糖果，每包写明里面 `K` 颗的口味。
求**最少买几包**就能尝到全部 `M` 种口味（尝不到输出 `-1`）。

**约束**：`N ≤ 100`，`M ≤ 20`，`K ≤ 20`。

**关键观察**：

> `M ≤ 20` —— 这个范围是**强烈的信号**！
> **「20 个小元素，每个选/不选」= 用 20 位二进制表示状态。**

**状态定义**：用一个整数 `mask` 表示「已经尝到了哪些口味」。
第 `i` 位为 1 ⇔ 第 `i` 种口味已经尝到。

**把每包糖果也变成掩码**：

```cpp
for (int i = 0; i < n; i++) {
    int mask = 0;
    for (int j = 0; j < k; j++) {
        int ck; cin >> ck; ck--;        // 口味编号转成 0 开始
        mask |= (1 << ck);              // 第 ck 位置 1
    }
    pack[i] = mask;
}
// 例：一包含口味 2、4、6 → 二进制 101010 → 十进制 42
```

**转移**：买第 i 包后，新状态是 `mask | pack[i]`。

```cpp
vector<int> dp(1 << m, INF);
dp[0] = 0;                                   // 什么都没尝到，买 0 包

for (int mask = 0; mask < (1 << m); mask++) {
    if (dp[mask] == INF) continue;
    for (int i = 0; i < n; i++) {
        int nxt = mask | pack[i];            // 合并口味
        dp[nxt] = min(dp[nxt], dp[mask] + 1);
    }
}

int ans = dp[(1 << m) - 1];                  // 全 1 = 所有口味都尝到
```

**完整代码结构**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;

int main() {
    int n, m, k;
    cin >> n >> m >> k;

    vector<int> cd(n, 0);
    for (int i = 0; i < n; i++) {
        int mask = 0;
        for (int j = 0; j < k; j++) {
            int ck; cin >> ck; ck--;
            mask |= (1 << ck);
        }
        cd[i] = mask;
    }

    vector<int> dp(1 << m, INF);
    dp[0] = 0;

    for (int mask = 0; mask < (1 << m); mask++) {
        if (dp[mask] == INF) continue;
        for (int c : cd) {
            int nxt = mask | c;
            dp[nxt] = min(dp[nxt], dp[mask] + 1);
        }
    }

    int ans = dp[(1 << m) - 1];
    cout << (ans == INF ? -1 : ans) << '\n';
    return 0;
}
```

**从「搜索」的角度看这题**：

把每个 `mask` 看作图上的一个**节点**，买一包糖果看作一条**边**（代价 1）。
于是问题变成「从 `mask = 0` 走到 `mask = 全1` 的最短路」。

→ 这就可以用 **BFS**（边权全是 1）：

```cpp
vector<int> dist(1 << m, -1);
queue<int> q;
dist[0] = 0;
q.push(0);

while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int c : cd) {
        int v = u | c;
        if (dist[v] == -1) {
            dist[v] = dist[u] + 1;
            q.push(v);
        }
    }
}
```

> 🎯 **这道题是最重要的「思维桥梁」**：
> **「状态」不一定是数组下标，可以是任何能表示当前位置的东西。**
> - DP 的「状态」= BFS 的「节点」
> - DP 的「转移」= BFS 的「边」
> - DP 的「转移顺序」= BFS 的「层序」
>
> **想不出 DP 转移方程时，就想想「状态空间长什么样」。**

**复杂度**：
- 状态数 `2^M = 2^20 ≈ 1e6`
- 每个状态枚举 `N = 100` 包 → `1e8` 次操作

> ⚠️ **`N = 100`、`M = 20` 时 `1e8` 次已经很紧张**（可能 1~2 秒）。
> **优化**：先把重复的 `pack` 掩码去重（很多包含的口味一样）。
> 去重后 `pack` 的种类最多 `2^M` 种，但实际上远少于 `N`。

> 💡 **如果 `m` 更大（比如 `m ≤ 60`）怎么办？**
> 那就不能状压了，需要**集合覆盖**的其它思路（贪心或随机化）。
> **「`M ≤ 20`」这个约束就是在告诉你「用状压」。**

## 7.7　本章常见坑

| # | 坑 | 说明 |
|:---:|---|---|
| 1 | BFS 出队时才标记 `visited` | 会重复入队，队列爆炸 |
| 2 | BFS 用 DFS 求最短路 | **错的**！DFS 第一次到终点不是最短路 |
| 3 | 网格 BFS 越界检查写最后 | 数组越界崩溃，**越界要先判** |
| 4 | 回溯忘记撤销 | 各分支互相污染，答案全错 |
| 5 | 回溯的 `for` 里忘了 `continue` | 非法候选被当成合法 |
| 6 | 递归太深爆栈 | 改迭代，或减小递归深度 |
| 7 | 搜索状态没去重 | 同一个状态重复搜索 → 超时（要加 `visited`） |
| 8 | 剪枝条件写反 | 把正确解剪掉了 → `Wrong Answer` |
| 9 | `1 << 20` 用了 `int` | `m ≤ 30` 时才安全，`m` 更大要用 `1LL <<` |
| 10 | 状压的 `1 << m` 数组开不下 | `m = 25` → `3.3e7` 个 `int` = 134MB ⚠️ |

> 🎯 **关于第 10 条要特别注意状态压缩的上限**：
> ```
> m = 20  →  2^20 ≈ 1e6 个状态    ✅ 随便开
> m = 24  →  2^24 ≈ 1.7e7 个状态  ⚠️ int 数组约 67MB
> m = 26  →  2^26 ≈ 6.7e7 个状态  ❌ 268MB，会 MLE
> ```
> **`m > 24` 时，状压就要非常谨慎了。**

## 本章小结

**必须掌握的四件事：**

1. **DFS 框架**（递归 + `vis` 标记）——
   所有图论/树算法的骨架。
2. **BFS 框架**（队列 + 入队即标记）——
   求「边权全为 1」的最短路。
3. **回溯模板**：**做选择 → 递归 → 撤销**。
   忘记撤销是最经典的 bug。
4. **剪枝四类**：可行性、最优性、搜索顺序、记忆化。

**最重要的一句话：**

> **状态不一定是数组下标。**
> 「DP 的状态」和「BFS 的节点」是同一件事。
> 想不出转移方程时，画一画**状态空间图**。
