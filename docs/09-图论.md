## 9.1　图的表示（存图）

### 9.1.1 三种存图方式

| 方式 | 空间 | 适用 | 缺点 |
|---|---|---|---|
| **邻接矩阵** `g[u][v]` | `O(n²)` | `n ≤ 500`、需要 `O(1)` 查边 | 点多了爆内存 |
| **邻接表** `vector<vector<>>` | `O(n + m)` | **最常用** | 查「u、v 有边吗」要遍历 |
| **链式前向星** | `O(n + m)` | 卡常、需要边编号 | 写起来麻烦 |

> 🎯 **默认用邻接表**。只有 `n ≤ 500` 且要频繁判断「两点是否相邻」时，才用邻接矩阵。

### 9.1.2 邻接矩阵

```cpp
const int MAXN = 505;
int g[MAXN][MAXN];           // g[u][v] = 边权，0 或 INF 表示无边

for (int i = 0; i < m; i++) {
    int u, v, w;
    cin >> u >> v >> w;
    g[u][v] = g[v][u] = w;   // 无向图要对称赋值
}
```

> ⚠️ `g[u][v] = 0` 表示「无边」，所以边权为 0 的边要特殊处理。

### 9.1.3 邻接表（推荐）

**无权图**：

```cpp
vector<vector<int>> g(n + 1);       // g[u] = u 的所有邻居
g[u].push_back(v);
g[v].push_back(u);                  // 无向图要加两次
```

**带权图**：

```cpp
vector<vector<pair<int,int>>> g(n + 1);   // {邻居, 边权}
g[u].push_back({v, w});
g[v].push_back({u, w});
```

**遍历所有出边**（最常用的循环）：

```cpp
for (auto [v, w] : g[u]) {
    // v 是邻居，w 是边权
}
```

### 9.1.4 链式前向星（卡常用）

```cpp
int head[MAXN], e[MAXM], w[MAXM], ne[MAXM], idx = 0;

void add(int u, int v, int weight) {
    e[idx] = v;          // 这条边通向 v
    w[idx] = weight;     // 边权
    ne[idx] = head[u];   // 它的下一条边
    head[u] = idx++;     // 头插
}

// 遍历 u 的所有出边
for (int i = head[u]; i != -1; i = ne[i]) {
    int v = e[i], weight = w[i];
}
```

> 💡 **初学阶段不用碰它**。邻接表在绝大多数题上都够快。
> 只有被卡常或被卡内存时才需要。

> 📎 本仓库参考：`newcode.cpp` 用了链式前向星 + 反向图。

### 9.1.5 两个常用常量

```cpp
const int INF = 0x3f3f3f3f;    // int 的无穷大（约 1.06e9，两个相加不溢出）
const ll  LLINF = 4e18;        // long long 的无穷大（路径长度用这个）
```

**无向图 = 「双向的有向图」**：
存边时两个方向都存，很多算法（Dijkstra、BFS、Kruskal）就通用了。

## 9.2　最短路算法

### 9.2.1 算法选择（先看这张表）

| 算法 | 适用 | 复杂度 | 能否负权 | 能否判负环 |
|---|---|:---:|:---:|:---:|
| **Dijkstra**（堆优化） | 非负权、单源 | `O(m log n)` | ❌ | ❌ |
| **Bellman-Ford** | 任意权、单源 | `O(nm)` | ✅ | ✅ |
| **SPFA** | 任意权、单源 | 平均 `O(m)`，**最坏 `O(nm)`** | ✅ | ✅ |
| **Floyd** | 多源 | `O(n³)` | ✅ | ✅（看对角元） |
| **0-1 BFS** | 边权只有 0/1 | `O(n + m)` | ❌ | ❌ |

**选型口诀**：

```
边权非负，单源最短路 → Dijkstra（堆优化）
边权有负，单源       → SPFA（或 Bellman-Ford）
要判负环             → SPFA / Bellman-Ford 多跑一轮
所有点对的距离       → Floyd（n ≤ 300）
```

> ⚠️ **SPFA 的争议**：它的最坏复杂度是 `O(nm)`，
> 出题人可以构造「网格图」把它卡成超时。
> **能不用 SPFA 就别用**（非负权一律用 Dijkstra）。

---

### 9.2.2 Dijkstra（堆优化）⭐ 必会

**核心思想（贪心）**：

> 每次从「还没确定的点」里挑一个**距离最小**的点 `u`，
> 它的距离就已经是最终答案了（因为其它路径只会更长）。
> 然后用 `u` 去**松弛**它的邻居。

**为什么不能有负权？**
因为「其它路径只会更长」这个前提会被负边破坏。

**完整模板（背下来）**：

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const ll INF = 4e18;      // 用 long long，INF 要足够大

vector<ll> dijkstra(int n, vector<vector<pair<int,int>>> &g, int s) {
    vector<ll> dist(n + 1, INF);
    vector<bool> vis(n + 1, false);
    // 小根堆：{距离, 点编号}
    priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<>> pq;

    dist[s] = 0;
    pq.push({0, s});

    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();

        if (vis[u]) continue;      // ← 已经确定过了，跳过（关键！）
        vis[u] = true;

        for (auto [v, w] : g[u]) {
            if (dist[v] > d + w) {         // 松弛
                dist[v] = d + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;      // dist[i] == INF 表示不可达
}
```

**四处关键点（每处都容易错）**：

**① `if (vis[u]) continue;`**

堆里可能有同一个点的**多个过期副本**（入堆后又被更新了）。
跳过已确定的，保证每个点只被真正处理一次 → 复杂度 `O(m log n)`。

**等价写法**（不用 `vis`，用「距离不等就跳过」）：

```cpp
if (d != dist[u]) continue;      // 过期数据，丢弃
```

两种写法都对。**第一种（`vis`）更常见。**

**② `dist` 必须用 `long long`**

路径长度可能累加到 `1e18` 量级。`INF` 也要用 `4e18` 级别。

**③ 松弛条件用 `>` 而不是 `>=`**

用 `>` 才能在「距离相等」时不重复入堆，减少堆的大小。

**④ 小根堆必须写全模板**

```cpp
priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<>>
```
`greater<>` 不能省，否则默认是**大根堆**（会得到错误结果）。

**复杂度**：`O((n + m) log n)`，通常写作 `O(m log n)`。

**变体：记录路径**

```cpp
vector<int> pre(n + 1, 0);
if (dist[v] > d + w) {
    dist[v] = d + w;
    pre[v] = u;              // ← 记录前驱
    pq.push({dist[v], v});
}
// 从终点往回跳
vector<int> path;
for (int x = t; x != 0; x = pre[x]) path.push_back(x);
reverse(path.begin(), path.end());
```

**变体：统计最短路条数**

```cpp
vector<ll> cnt(n + 1, 0);
cnt[s] = 1;
// 松弛成功
if (dist[v] > d + w) {
    dist[v] = d + w;
    cnt[v] = cnt[u];                    // 换了一条更短的路，计数重置
    pq.push({dist[v], v});
} else if (dist[v] == d + w) {
    cnt[v] = (cnt[v] + cnt[u]) % MOD;   // 同样短，累加
}
```

> ⚠️ **为什么 `dist` 要用 `long long`？**
> `n = 1e5` 个点、每条边权 `1e9`，最长路径可达 `1e14`——
> 早就超出 `int` 范围了。**路程类问题一律 `long long`。**

### 9.2.3 Bellman-Ford（能处理负权 + 判负环）

**核心思想**：

> 「最短路径最多经过 `n-1` 条边」。
> 所以做 `n-1` 轮「对所有边尝试松弛」，就一定能得到最短路。

**能处理负权**，因为它是「暴力迭代」而不是「贪心确定」。

```cpp
struct Edge { int u, v; ll w; };

// 返回 {dist, hasNegativeCycle}
pair<vector<ll>, bool> bellmanFord(int n, vector<Edge> &edges, int s) {
    vector<ll> dist(n, INF);
    dist[s] = 0;

    // n-1 轮松弛
    for (int i = 0; i < n - 1; i++) {
        bool updated = false;
        for (auto &e : edges) {
            if (dist[e.u] != INF && dist[e.v] > dist[e.u] + e.w) {
                dist[e.v] = dist[e.u] + e.w;
                updated = true;
            }
        }
        if (!updated) break;      // 提前结束（优化）
    }

    // 第 n 轮还能松弛 → 存在负环
    for (auto &e : edges) {
        if (dist[e.u] != INF && dist[e.v] > dist[e.u] + e.w) {
            return {dist, true};
        }
    }
    return {dist, false};
}
```

**复杂度 `O(nm)`**，比较慢。

> 📎 本仓库对应模板：`templates/03_graph/bellman_ford.cpp`
> （原始文件 `ban_zi/bellman_ford.cpp`，里面还带了 SPFA 的注释版本）

**⭐ 判负环的原理（重点）**：

如果**做完 `n-1` 轮后还能继续松弛**，说明某条最短路经过了 `n` 条边。
但 `n` 个点的简单路径最多 `n-1` 条边 —— 所以路径里**有重复的点**，
即**存在环**。而这个环让距离变小了，所以是**负环**。

---

### 9.2.4 SPFA（Bellman-Ford 的队列优化）

**优化点**：只有「距离被更新过」的点，才需要用它的出边去松弛别人。

```cpp
pair<vector<ll>, bool> spfa(int n, vector<vector<pair<int,ll>>> &g, int s) {
    vector<ll> dist(n, INF);
    vector<bool> inq(n, false);
    vector<int> cnt(n, 0);         // 被松弛的次数
    queue<int> q;

    dist[s] = 0;
    q.push(s);
    inq[s] = true;

    while (!q.empty()) {
        int u = q.front(); q.pop();
        inq[u] = false;

        for (auto [v, w] : g[u]) {
            if (dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                cnt[v] = cnt[u] + 1;
                if (cnt[v] >= n) return {dist, true};   // 松弛次数 ≥ n → 负环
                if (!inq[v]) {
                    q.push(v);
                    inq[v] = true;
                }
            }
        }
    }
    return {dist, false};
}
```

**判负环**：某个点的松弛次数 `>= n` → 存在负环。

> ⚠️ **SPFA 会被卡**！出题人常用「网格图 + 小负边」让它退化到 `O(nm)`。
> **能用 Dijkstra 就别用 SPFA。**

> 💡 **SPFA 的三个优化**（记得时可以用）：
> - **SLF 优化**：新点距离比队首小就插到队首（改用 `deque`）
> - **LLL 优化**：与队内平均距离比较
> - **判负环时用 `stack` 代替 `queue`**（往往更快找到负环）

### 9.2.5 Floyd（多源最短路）

**求「任意两点间」的最短距离**，代码只有 5 行，`O(n³)`。

```cpp
// dist[i][j] 初始：dist[i][i] = 0，有边则设边权，无边设 INF
for (int k = 1; k <= n; k++)            // 中转点
    for (int i = 1; i <= n; i++)        // 起点
        for (int j = 1; j <= n; j++)    // 终点
            dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
```

**理解**：`dist[i][j]` 表示「只允许经过前 `k` 个点作为中转时，i 到 j 的最短路」。
`k` 从 1 枚举到 n，最后就是允许所有点中转的答案。

> ⚠️ **三层循环的顺序不能换！**
> **`k`（中转点）必须在最外层**，否则答案错误。
>
> 原因：`dist[i][k]` 和 `dist[k][j]` 必须已经用「更小的 `k`」更新过。
> 如果 `k` 在最内层，这个前提就不成立。

**初始化写法**：

```cpp
const int MAXN = 505;
ll dist[MAXN][MAXN];

for (int i = 1; i <= n; i++)
    for (int j = 1; j <= n; j++)
        dist[i][j] = (i == j ? 0 : INF);

for (int i = 0; i < m; i++) {
    int u, v; ll w;
    cin >> u >> v >> w;
    dist[u][v] = min(dist[u][v], w);   // ⚠️ 可能有重边，要取 min！
    dist[v][u] = min(dist[v][u], w);   // 无向图
}
```

> ⚠️ **重边必须用 `min`**。直接 `= w` 会被后面的小边覆盖成错的。

**Floyd 的三个妙用**：

**① 判断负环**：跑完后如果某个 `dist[i][i] < 0` → 存在负环。

**② 传递闭包**（「能不能从 i 走到 j」）：把 `min(+)` 换成 `|(&)`

```cpp
reach[i][j] = reach[i][j] | (reach[i][k] & reach[k][j]);
```

**③ 最小环**（见 `WIDA` 模板库）。

> 📎 本仓库对应模板：`templates/03_graph/floyd.cpp`（原始文件 `ban_zi/floyd.cpp`）

> 💡 **Floyd 和 「`n ≤ 300`」是死搭档**。
> 看到多源最短路 + `n ≤ 300`，直接上 Floyd，不要犹豫。

### 9.2.6 分层图最短路（重要套路）

**题型**：允许「把 `k` 条边的权值变成 0」，或「有 `k` 次机会走特殊边」，求最短路。

**做法**：把图**复制成 `k+1` 层**，每用一次机会就从第 `i` 层走到第 `i+1` 层。

```
第 0 层：  A0 ---5---> B0
第 1 层：  A1 ---5---> B1
第 2 层：  A2 ---5---> B2

特殊边（用掉一次机会，代价变 0）：
A0 ----0----> B1        （从第 0 层直接跳到第 1 层）
A1 ----0----> B2
```

#### 实现方式一：真的开 `(k+1) × n` 个点

```cpp
int N = n * (k + 1);                 // 总点数
vector<vector<pair<int,ll>>> g(N + 1);

// 普通边：同一层内
for (int layer = 0; layer <= k; layer++) {
    int off = layer * n;
    g[u + off].push_back({v + off, w});
    g[v + off].push_back({u + off, w});
}

// 特殊边：跨层，边权 0
for (int layer = 0; layer < k; layer++) {
    int off = layer * n, nxt = (layer + 1) * n;
    g[u + off].push_back({v + nxt, 0});
    g[v + off].push_back({u + nxt, 0});
}

// 跑 Dijkstra，答案取 min(dist[t + layer*n])
```

#### 实现方式二：`dist` 多开一维（推荐，代码更短）

```cpp
// dist[u][layer] = 到 u 且已经用了 layer 次机会的最短距离
vector<vector<ll>> dist(n + 1, vector<ll>(k + 1, INF));
priority_queue<tuple<ll,int,int>, vector<tuple<ll,int,int>>, greater<>> pq;

dist[1][0] = 0;
pq.push({0, 1, 0});

while (!pq.empty()) {
    auto [d, u, layer] = pq.top(); pq.pop();
    if (d != dist[u][layer]) continue;

    for (auto [v, w] : g[u]) {
        // ① 不用机会，同层转移
        if (dist[v][layer] > d + w) {
            dist[v][layer] = d + w;
            pq.push({dist[v][layer], v, layer});
        }
        // ② 用一次机会，跨到下一层，边权变 0
        if (layer < k && dist[v][layer + 1] > d) {
            dist[v][layer + 1] = d;
            pq.push({dist[v][layer + 1], v, layer + 1});
        }
    }
}

ll ans = INF;
for (int j = 0; j <= k; j++) ans = min(ans, dist[n][j]);
```

> 🎯 **Dijkstra 的通用扩展公式**：
> **「多一个状态维度，就在 `dist` 和堆的元素里各加一维」。**
>
> | 场景 | `dist` 定义 | 堆里放 |
> |---|---|---|
> | 普通 Dijkstra | `dist[u]` | `{d, u}` |
> | 分层图（`k` 次机会） | `dist[u][layer]` | `{d, u, layer}` |
> | 网格最短路 | `dist[x][y]` | `{d, x, y}` |
> | 状压最短路 | `dist[u][mask]` | `{d, u, mask}` |
>
> **规律：`dist` 的维度 = 堆里元素的维度 − 1**（因为「距离」本身占一维）。

## 9.3　最小生成树（MST）

### 9.3.1 问题

**给一个连通无向带权图，选出一棵包含所有 n 个点、n-1 条边的树，使总边权最小。**

**用途**：修路最少花多少钱、网络布线最少用多长线。

### 9.3.2 两种算法

| 算法 | 适合 | 复杂度 | 核心 |
|---|---|---|---|
| **Kruskal** | **稀疏图**（`m` 不大） | `O(m log m)` | **排序 + 并查集** |
| **Prim**（堆优化） | 稠密图 | `O(m log n)` | 类似 Dijkstra |

> 🎯 **实战建议**：**直接用 Kruskal**。
> 它的代码只有 20 行，而且能顺便判「图是否连通」。

### 9.3.3 Kruskal（推荐，必会）

**思想（贪心 + 并查集）**：

1. 把所有边**按权值从小到大排序**
2. 依次考虑每条边：如果它连接的两个点**还没连通**，就选它
3. 选够 `n-1` 条边就结束

**为什么贪心是对的？**
（割性质）最小的那条边一定在某棵最小生成树里。
严格证明是「交换论证」：假设最优解不含最小边 `e`，
把 `e` 加进去会形成环，环上一定有一条边 `f ≥ e`，
用 `e` 换掉 `f`，总权不会变大。

**完整模板（背下来）**：

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const int MAXN = 100005;

struct Edge {
    int u, v, w;
};

int parent[MAXN], rnk[MAXN];

int find(int x) {
    return parent[x] == x ? x : parent[x] = find(parent[x]);
}

bool unite(int x, int y) {
    int rx = find(x), ry = find(y);
    if (rx == ry) return false;
    if (rnk[rx] < rnk[ry]) swap(rx, ry);
    parent[ry] = rx;
    if (rnk[rx] == rnk[ry]) rnk[rx]++;
    return true;
}

int main() {
    int n, m;
    cin >> n >> m;

    vector<Edge> edges(m);
    for (int i = 0; i < m; i++) {
        cin >> edges[i].u >> edges[i].v >> edges[i].w;
    }

    // ① 按边权升序排序
    sort(edges.begin(), edges.end(), [](const Edge &a, const Edge &b) {
        return a.w < b.w;
    });

    // ② 初始化并查集
    for (int i = 1; i <= n; i++) parent[i] = i;

    ll total = 0;              // 最小生成树总权
    int cnt = 0;               // 已选边数
    vector<Edge> mst;          // 记录选中的边（可选）

    for (auto &e : edges) {
        if (unite(e.u, e.v)) {          // 两点原来不连通 → 选这条边
            total += e.w;
            cnt++;
            mst.push_back(e);
            if (cnt == n - 1) break;    // 选够了
        }
    }

    if (cnt != n - 1) {
        cout << "图不连通，无法生成最小生成树\n";
    } else {
        cout << total << '\n';
    }
    return 0;
}
```

**复杂度 `O(m log m)`**（排序是瓶颈）。

> 📎 本仓库对应模板：`templates/03_graph/kruskal.cpp`（原始文件 `ban_zi/kruskal.cpp`）

**检查「图是否连通」的方法**：
如果循环跑完 `cnt < n - 1`，说明有些点孤立 → **图不连通**，不存在生成树。

### 9.3.4 Prim（了解即可）

**思想**：从任意一个点出发，每次选「连接已选集合和未选集合的最小边」。

```cpp
// 堆优化版，O(m log n)
priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<>> pq;
vector<bool> inMST(n + 1, false);

ll total = 0;
pq.push({0, 1});
int cnt = 0;

while (!pq.empty() && cnt < n) {
    auto [w, u] = pq.top(); pq.pop();
    if (inMST[u]) continue;

    inMST[u] = true;
    total += w;
    cnt++;

    for (auto [v, ew] : g[u]) {
        if (!inMST[v]) pq.push({ew, v});
    }
}
```

**和 Dijkstra 的唯一区别**：Prim 的堆里放的是「**边权**」，
Dijkstra 放的是「**起点到该点的距离**」。

### 9.3.5 常见变形

| 变形 | 做法 |
|---|---|
| **最大生成树** | 边权排序改成**降序** |
| **「次小生成树」** | 在 MST 上加一条边形成环，去掉环上最大的边 |
| **「最小瓶颈生成树」** | 就是 MST（使最大边权最小） |
| **「边权是 a^b」** | 先比指数 b，再比底数 a（用 `log` 或指数相同比较底数） |
| **「部分点必须连通」** | 加超级源点连向这些点（边权 0） |

## 9.4　拓扑排序

### 9.4.1 问题

**给一个有向图，求一个点的排列，使得所有边都从前往后指。**
（也就是「先做没有前置任务的事」）

**用途**：课程安排、编译依赖、任务调度、DAG 上的 DP 顺序。

**前提**：图必须是 **DAG**（有向无环图）。**有环就没有拓扑序。**

### 9.4.2 Kahn 算法（BFS 版，推荐）

**思想**：

1. 找出所有**入度为 0** 的点，入队
2. 每次取出队首 `u`，把 `u` 加入答案
3. 对 `u` 的每个邻居 `v`，把 `v` 的入度减 1
   （相当于「删掉 `u → v` 这条边」）
4. 如果 `v` 的入度变成 0，就入队
5. 重复直到队列空

**判环**：如果最后答案里的点数 `< n`，说明**有环**。

**完整模板（背下来）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

// 返回拓扑序；如果有环，返回空数组
vector<int> topoSort(int n, vector<vector<int>> &adj) {   // adj[u] = u 的邻居
    vector<int> indeg(n + 1, 0);

    // ① 统计入度
    for (int u = 1; u <= n; u++) {
        for (int v : adj[u]) indeg[v]++;
    }

    // ② 所有入度为 0 的点入队
    queue<int> q;
    for (int i = 1; i <= n; i++) {
        if (indeg[i] == 0) q.push(i);
    }

    // ③ 主循环
    vector<int> topo;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        topo.push_back(u);

        for (int v : adj[u]) {
            if (--indeg[v] == 0) q.push(v);    // 删边后入度为 0 → 入队
        }
    }

    // ④ 判环
    if ((int)topo.size() != n) return {};      // 有环
    return topo;
}
```

**复杂度 `O(n + m)`**。

> 📎 本仓库对应模板：
> - `templates/03_graph/topological_sort.cpp`（原始文件 `ban_zi/tuopu_paixu.cpp`）
> - `ban_zi/拓扑`（另一份带详细中文注释的版本，特别强调了
>   「入度统计」和「入队」必须分成两步做——这是一个很好的提醒）

### 9.4.3 三个必须注意的点

**① 入度统计和入队必须分成两步**

```cpp
// ❌ 错误：边统计边入队
for (int u = 1; u <= n; u++) {
    for (int v : adj[u]) {
        indeg[v]++;
        if (indeg[v] == 0) q.push(v);      // 这时入度还没统计完！
    }
}
```

**必须先把所有入度统计完，再统一找入度为 0 的点。**

**② 拓扑序不唯一**

同一个人度可以有很多合法的拓扑序。题目如果要求「字典序最小」，
把 `queue` 换成 **`priority_queue`（小根堆）** 即可。

**③ 拓扑排序是「DAG 上 DP」的前提**

要在 DAG 上做 DP，必须按**拓扑序**枚举状态
（保证「算到某个点时，它的所有前驱都算完了」）。

### 9.4.4 DFS 版拓扑排序

```cpp
vector<int> order;          // 后序
vector<bool> vis;

void dfs(int u, vector<vector<int>> &adj) {
    vis[u] = true;
    for (int v : adj[u]) {
        if (!vis[v]) dfs(v, adj);
    }
    order.push_back(u);     // ← 后序位置加入
}

// 调用后 order 的【逆序】就是拓扑序
reverse(order.begin(), order.end());
```

> 💡 两种版本**各有用途**：
> - **Kahn（BFS）**：能顺便**判环**、能控制字典序 → **首选**
> - **DFS 后序**：写起来短，而且能顺便处理一些递归性质（如节点分组）

### 9.4.5 应用举例

**「最长路」在 DAG 上用拓扑排序 + DP**：

```cpp
// dp[v] = 以 v 结尾的最长路
for (int u : topo) {
    for (auto [v, w] : g[u]) {
        dp[v] = max(dp[v], dp[u] + w);
    }
}
```

**这就是第 09 章开头说的「在遍历时多做一点事」**——
拓扑排序提供了 DP 的正确顺序。

## 9.5　连通性（Tarjan 算法家族）

### 9.5.1 四个概念先分清

| 概念 | 图类型 | 含义 |
|---|---|---|
| **割点** | 无向图 | 删掉它，连通块数量**增加** |
| **割边（桥）** | 无向图 | 删掉它，连通块数量**增加** |
| **强连通分量（SCC）** | 有向图 | 分量内**任意两点互相可达** |
| **双连通分量（BCC）** | 无向图 | 点双（无割点）/ 边双（无割边） |

### 9.5.2 两个关键数组：`dfn` 和 `low`

Tarjan 算法都基于这两个数组：

```cpp
int dfn[u];    // u 第一次被访问的「时间戳」（DFS 序）
int low[u];    // u 及其子树能「回溯到」的最小 dfn
```

**`low[u]` 的更新规则**：
1. 对树边 `u → v`（`v` 没访问过）：`low[u] = min(low[u], low[v])`
2. 对**已访问过**的点 `v`（回边）：`low[u] = min(low[u], dfn[v])`

### 9.5.3 求割点（无向图）

**判定**：对节点 `u`

- **不是根**：如果存在一个儿子 `v` 满足 `low[v] >= dfn[u]` → `u` 是割点
- **是根**：如果有**两个以上**的儿子 → `u` 是割点

```cpp
vector<int> dfn(n + 1, 0), low(n + 1, 0);
vector<bool> isCut(n + 1, false);
int timer = 0;

void tarjan(int u, int fa, vector<vector<int>> &g) {
    dfn[u] = low[u] = ++timer;
    int child = 0;

    for (int v : g[u]) {
        if (!dfn[v]) {
            child++;
            tarjan(v, u, g);
            low[u] = min(low[u], low[v]);

            if (fa != 0 && low[v] >= dfn[u]) isCut[u] = true;   // 割点判定
        } else if (v != fa) {
            low[u] = min(low[u], dfn[v]);
        }
    }

    if (fa == 0 && child >= 2) isCut[u] = true;                 // 根的情况
}
```

### 9.5.4 求割边（桥）

**判定**：树边 `u → v`，如果 `low[v] > dfn[u]` → `(u,v)` 是桥。

```cpp
// 注意：用「边编号」而不是「父节点」来避免走回头路
void tarjan(int u, int faEdge, vector<vector<pair<int,int>>> &g) {
    dfn[u] = low[u] = ++timer;

    for (auto [v, eid] : g[u]) {
        if (eid == faEdge) continue;         // 不走来的那条边
        if (!dfn[v]) {
            tarjan(v, eid, g);
            low[u] = min(low[u], low[v]);
            if (low[v] > dfn[u]) {
                // (u, v) 是桥
            }
        } else {
            low[u] = min(low[u], dfn[v]);
        }
    }
}
```

> ⚠️ **割边算法必须用「边编号」判回头路，不能用「父节点」**！
> 有重边时，「父节点」可能是从另一条边到达的，
> 用 `v != fa` 判断会把重边误判成桥。

### 9.5.5 强连通分量缩点（有向图）

**用途**：把「互相可达」的一堆点缩成一个点，得到一个 **DAG**，
然后就能在上面做拓扑排序 + DP。

```cpp
vector<int> dfn(n + 1, 0), low(n + 1, 0), scc(n + 1, 0);
vector<bool> inStack(n + 1, false);
stack<int> st;
int timer = 0, sccCnt = 0;

void tarjan(int u, vector<vector<int>> &g) {
    dfn[u] = low[u] = ++timer;
    st.push(u);
    inStack[u] = true;

    for (int v : g[u]) {
        if (!dfn[v]) {
            tarjan(v, g);
            low[u] = min(low[u], low[v]);
        } else if (inStack[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }

    if (low[u] == dfn[u]) {            // u 是这个 SCC 的「根」
        sccCnt++;
        while (true) {
            int v = st.top(); st.pop();
            inStack[v] = false;
            scc[v] = sccCnt;          // v 属于第 sccCnt 个分量
            if (v == u) break;
        }
    }
}
```

**缩点后重新建图**（得到 DAG）：

```cpp
for (int u = 1; u <= n; u++) {
    for (int v : g[u]) {
        if (scc[u] != scc[v]) {
            dag[scc[u]].push_back(scc[v]);      // 注意去重
        }
    }
}
```

**缩点后能做什么**：

| 问题 | 做法 |
|---|---|
| 求 DAG 最长路 | 拓扑排序 + DP |
| 「最多能经过几个点」 | 缩点后在 DAG 上 DP |
| 「能否到达所有点」 | 缩点后看入度为 0 的 SCC 是否唯一 |

> 📎 本仓库参考：`WIDA-XCPC` 的「缩点（Tarjan 算法）」章节
> 有强连通分量、割边、割点三个完整封装。

### 9.5.6 2-SAT（了解）

**问题**：有 `n` 个布尔变量，给你一堆约束（形如「`a` 为真 或 `b` 为假」），
问有没有解。

**做法**：每个变量拆成两个点（表示「取真」和「取假」），
每条约束变成两条**蕴含边**，跑 Tarjan 求 SCC。

**判定**：

```cpp
// 如果「x 为真」和「x 为假」在同一个 SCC 里 → 无解
if (scc[2*i] == scc[2*i+1]) { cout << "无解\n"; }
else {
    ans[i] = (scc[2*i] > scc[2*i+1]);
}
```

**用途**：开关问题、逻辑推理、部分博弈题。

## 9.6　二分图

### 9.6.1 什么叫二分图

**能把所有点分成两个集合，使得所有边都在两个集合之间。**

**等价判定**：图中**没有奇环**（长度为奇数的环）。

### 9.6.2 判定：染色法（DFS）

```cpp
vector<int> color(n + 1, 0);        // 0 未染色，1 / -1 两种颜色

bool isBipartite(int u, int c, vector<vector<int>> &g) {
    color[u] = c;
    for (int v : g[u]) {
        if (color[v] == 0) {
            if (!isBipartite(v, -c, g)) return false;
        } else if (color[v] == c) {
            return false;           // 相邻同色 → 不是二分图
        }
    }
    return true;
}

// 遍历所有连通块（图可能不连通）
bool check(vector<vector<int>> &g, int n) {
    for (int i = 1; i <= n; i++) {
        if (color[i] == 0 && !isBipartite(i, 1, g)) return false;
    }
    return true;
}
```

**复杂度 `O(n + m)`**。

> ⚠️ **必须遍历所有连通块**！只从 1 号点开始染色会漏掉其他分量。

### 9.6.3 二分图最大匹配（匈牙利算法）

**问题**：左边 `n` 个点、右边 `m` 个点，边表示「可以配对」。
求**最多能配成多少对**（每点最多用一次）。

**核心思想（增广路）**：

> 不断给左边的每个点找配对；
> 如果目标的右边点已被占用，就让「占用者」去试试**换一个**目标。

```cpp
const int MAXN = 505;
vector<int> g[MAXN];                  // 左部点 -> 右部点
int match[MAXN];                      // match[v] = v 匹配的左部点（0 表示未匹配）
bool vis[MAXN];

bool dfs(int u) {
    for (int v : g[u]) {
        if (vis[v]) continue;         // 这一轮已经试过了
        vis[v] = true;
        if (match[v] == 0 || dfs(match[v])) {   // v 空闲，或 v 的现任能换一个
            match[v] = u;
            return true;
        }
    }
    return false;
}

int hungarian(int n) {
    int cnt = 0;
    for (int i = 1; i <= n; i++) {
        memset(vis, 0, sizeof(vis));  // ← 每轮都要清空！
        if (dfs(i)) cnt++;
    }
    return cnt;
}
```

**复杂度 `O(n · m)`**。

> ⚠️ **`vis` 必须每次 `dfs` 前清空**（表示「这一轮尝试过哪些右部点」）。
> 忘记清空 → 结果偏小。

**重要结论（König 定理）**：

```
二分图最大匹配 = 最小点覆盖
二分图最大独立集 = n - 最大匹配
DAG 最小路径覆盖 = n - 最大匹配
```

### 9.6.4 Hopcroft-Karp（更快的匹配）

`O(m√n)`。把匈牙利算法里的「一次找一个」改成「一次找一组最短增广路」。
`n ≥ 1e4` 时用。见 `WIDA` 模板库。

## 9.7　欧拉路径

### 9.7.1 概念

| 名称 | 含义 |
|---|---|
| **欧拉路径** | 经过**每条边恰好一次**的路径（可以不是回路） |
| **欧拉回路** | 起点 = 终点的欧拉路径 |

> ⚠️ **注意是「边」不是「点」**！
> 「经过每个点恰好一次」叫**哈密顿路径**，那是 NP 问题，没有高效算法。

### 9.7.2 判定条件（必背）

**无向图**

| 条件 | 结论 |
|---|---|
| 所有点的度数都是**偶数** | 存在**欧拉回路** |
| 恰好有 **2 个**点的度数是**奇数** | 存在**欧拉路径**（这两个奇度点是起点/终点） |
| 奇数度点有 1、3 或更多 | **不存在** |
| 图不连通（忽略孤立点后） | **不存在** |

**有向图**

| 条件 | 结论 |
|---|---|
| 每个点**入度 = 出度** | 存在**欧拉回路** |
| 恰好一个点 `出度 − 入度 = 1`（起点），<br>恰好一个点 `入度 − 出度 = 1`（终点），<br>其余入度 = 出度 | 存在**欧拉路径** |
| 其他情况 | **不存在** |
| 基图不连通（忽略孤立点后） | **不存在** |

### 9.7.3 Hierholzer 算法（求欧拉路径）

**思想**：DFS + 回溯，**在回溯时把点加入答案**（后序），最后翻转。

```cpp
// 无向图（用边编号避免走重边）
vector<vector<pair<int,int>>> g;      // {邻居, 边编号}
vector<bool> used;
vector<int> circuit, stk;
vector<int> cur;                      // cur[u] = 下一条要尝试的边的下标

void euler(int start, int n) {
    stk.push_back(start);

    while (!stk.empty()) {
        int u = stk.back();
        while (cur[u] < (int)g[u].size() && used[g[u][cur[u]].second]) cur[u]++;

        if (cur[u] < (int)g[u].size()) {
            auto [v, eid] = g[u][cur[u]];
            used[eid] = true;
            cur[u]++;
            stk.push_back(v);
        } else {
            circuit.push_back(u);     // ← 后序加入答案
            stk.pop_back();
        }
    }
    reverse(circuit.begin(), circuit.end());
}
```

**为什么用「迭代 + 手写栈」而不是递归？**
因为边数多（`1e5` 以上）时**递归会爆栈**。

> 📎 本仓库对应模板：`templates/03_graph/euler_path_hierholzer.cpp`
> （原始文件 `ban_zi/Hierholzer.cpp`）
>
> 它同时提供了**有向图和无向图**两套封装，还有连通性检查函数。

> 💡 **求字典序最小的欧拉路径**：把每个点的邻接表**排序**，
> 然后按顺序尝试边即可。

## 9.8　例题精讲

### 例题 1：逛公园（拓扑排序 / 记忆化搜索 + 判零环）⭐⭐

> 本题代码见 `gp_text/newcode2.cpp`（拓扑排序版，带完整题面）
> 和 `newcode.cpp`（记忆化搜索版）。

**题意**：
给有向图，`1` 号是入口、`n` 号是出口，边权非负。
设 `1 → n` 的最短路长为 `d`，求**长度不超过 `d + K` 的路径条数**（对 `P` 取模）。
**如果有无穷多条，输出 `-1`。**

**关键观察**：

> 设 `dist[u]` = 「从起点 1 到 u 的最短路」。
> 走边 `u → v`（边权 `w`）时，会「浪费」 `delta = dist[u] + w − dist[v]`。
>
> - `delta == 0`：这条边在**最短路**上，走它不增加总长度
> - `delta > 0`：走它会多花 `delta` 的长度
>
> 题目允许的总浪费额度是 `K`，所以这题变成：
> **「在浪费额度 ≤ K 的前提下，有多少条不同的路径」。**

**状态**：`dp[u][j]` = 「从 1 走到 u，浪费了恰好 `j` 的路径条数」。

**转移**：

```cpp
// 走边 u -> v（浪费 delta）
dp[v][j + delta] += dp[u][j];
```

**⭐ 最难的部分：怎么判断「有无穷多条」？**

无穷多条 ⇔ **存在一个「浪费 0」的环**（即全由 `delta == 0` 的边构成的环）。
因为可以绕这个环任意多次，路径条数就无穷了。

**两种实现方式**：

**方式一（拓扑排序）** —— `gp_text/newcode2.cpp`

1. 先跑 Dijkstra 求出 `dist1[]`（从 1 出发）和 `dist2[]`（从 n 出发，跑**反图**）
2. 筛出「可能出现在合法路径上」的点：`dist1[u] + dist2[u] <= d + K`
3. 只保留 `delta == 0` 的边，建**零边图**，跑拓扑排序
   —— 如果**零边图有环** → 答案 `-1`
4. 按拓扑序做 DP

**方式二（记忆化搜索 + 栈标记）** —— `newcode.cpp`

```cpp
int dp(int u, int res) {
    if (res < 0 || res > k) return 0;
    if (f[u][res] != -1) return f[u][res];
    if (vis[u][res]) { flag = true; return 0; }    // ← 同一次递归里重复访问 → 有环

    vis[u][res] = true;
    ll sum = 0;
    for (每条出边 u -> v) {
        int cost = (dist[u] + w) - dist[v];
        if (cost < 0) continue;
        sum = (sum + dp(v, res - cost)) % mod;
    }
    vis[u][res] = false;                           // ← 回溯时取消标记
    if (u == n && res >= 0) sum = (sum + 1) % mod; // 到达终点，计入 1 条路径
    return f[u][res] = sum;
}
```

**为什么 `vis[u][res]` 能判环？**
如果递归过程中**又回到了同一个 `(u, res)` 状态**，
说明存在一个「净浪费为 0」的环 → 无穷多条路径。

> 🎯 **「记忆化搜索判环」是一个通用技巧**：
> 用一个「正在递归栈中」的标记数组，
> 遇到已标记的状态 → **存在环**。

**这题要学到的三件事**：

| 要点 | 说明 |
|---|---|
| **反向建图** | 从终点跑最短路，用来算「从 u 到 n 还剩多少余量」 |
| **状态里放「浪费额度」** | 把「不超过 K」变成一个维度，这是**最短路计数**的常见套路 |
| **用「零环」判无穷** | 存在浪费 0 的环 → 答案无穷 |

**复杂度**：`O((n + m) log n + n·K)`。

### 例题 2：分层图最短路（重修道路）

> 本题代码见 `图/分层图最短路/Revamping Trails (重修道路)`。

**题意**：`n` 个点 `m` 条无向边，可以把**最多 `k` 条边**的长度变成 `0`，
求从 `1` 到 `n` 的最短路。

**解法**：直接套 9.2.6 的**分层图**模板。

这份代码里最有价值的是**注释**，它把「Dijkstra 的通用扩展方式」讲透了：

```cpp
// 在 tuple 里放的一般是（代价，点集，状态）
// 点集可以是坐标 -> <d, x, y, layer>，也可以是单独的点编号 -> <d, u, layer>
// dist 的定义永远比 pq 的定义少一维，因为 dist[][].. 本身就是一个维度
// 状态是多样的，也可以是有因果关系的，自行寻找怎么确立关系
// 可以思考状压 1 << i 位运算等往往是求关系的重要点
```

**翻译成操作步骤**：

1. 想清楚「多出来的是哪个状态」（这里是「已经用了几次机会」）
2. 在 `dist` 上加一维 → `dist[u][layer]`
3. 在堆的元素里也加一维 → `{d, u, layer}`
4. 转移时分两种走法：**不消耗状态** 和 **消耗状态**
5. 答案在终点的**所有状态里取 min**

**对照 9.2.6 的代码**，你会发现这个套路可以套用到几乎所有「带状态的最短路」题上。

## 9.9　本章常见坑

| # | 坑 | 说明 |
|:---:|---|---|
| 1 | 无向图只加了一条边 | `g[u].push_back(v)` 后别忘了 `g[v].push_back(u)` |
| 2 | Dijkstra 用了 `int` | 路径长度爆 `int`，`dist` 和 `INF` 都要 `long long` |
| 3 | Dijkstra 忘了 `if (vis[u]) continue` | 复杂度退化，可能超时 |
| 4 | 小根堆漏了 `greater<>` | 默认大根堆，结果全错 |
| 5 | Floyd 的 `k` 没放最外层 | 答案错误（这个错误很隐蔽） |
| 6 | Floyd 重边没用 `min` | 被后面的大边覆盖 |
| 7 | 用了 SPFA 被卡 | 非负权一律用 Dijkstra |
| 8 | 负权用了 Dijkstra | 答案错（不报错，很致命） |
| 9 | 判负环时忘了判起点可达 | 要加 `dist[u] != INF` 的判断 |
| 10 | 拓扑排序边统计边入队 | 必须**先统计完**再入队 |
| 11 | 割边用父节点判回头路 | 有重边时错，必须用**边编号** |
| 12 | 二分图只从一个点染色 | 图不连通时漏掉其他分量 |
| 13 | 匈牙利算法 `vis` 没每轮清空 | 匹配数偏小 |
| 14 | 欧拉路径忘了判连通 | 条件满足但图不连通 → 无解 |
| 15 | 无向图欧拉回路没判「全为偶数」 | 条件不完整 |

**三个「不报错但答案错」的致命坑：**

1. **负权边用 Dijkstra** —— 结果偏小，样例可能还过
2. **Floyd 的 `k` 放错位置** —— 完全随机错误
3. **拓扑排序先入队再统计入度** —— 漏掉一些点

> 🎯 **图论题的调试建议**：
> **手画一个小图（3~5 个点），一步步模拟你的代码。**
> 图论 bug 90% 能靠一个 5 个点的小例子抓出来。

## 本章小结

**五个必背模板：**

| 模板 | 复杂度 | 关键点 |
|---|:---:|---|
| **Dijkstra（堆优化）** | `O(m log n)` | `vis` 判重、`long long`、`greater<>` |
| **Floyd** | `O(n³)` | `k` 必须在最外层 |
| **Kruskal** | `O(m log m)` | 排序 + 并查集 |
| **拓扑排序** | `O(n + m)` | 先统计入度，再入队；判环看数量 |
| **匈牙利匹配** | `O(nm)` | 每轮清空 `vis` |

**三个思想：**

1. **多一个状态维度 → `dist` 和堆各加一维**（分层图、状压最短路）
2. **`dfn` / `low` 是 Tarjan 家族的通用工具**（割点、割边、SCC）
3. **图论的骨架就是 DFS / BFS**，算法只是「在遍历时多做一点事」
