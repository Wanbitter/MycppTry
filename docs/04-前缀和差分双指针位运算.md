> **本章目标**：掌握「用空间换时间」的第一个套路——
> **预处理一次，查询 `O(1)`**。这是竞赛里出现频率最高的优化手段。

## 4.1　前缀和

### 4.1.1　问题：为什么需要它

**题目**：给 n 个数，做 m 次询问，每次问「区间 `[l, r]` 的和是多少」。
`n, m ≤ 1e5`。

**暴力做法**：每次询问循环累加 `[l, r]`。
单次最坏 `O(n)`，总复杂度 `O(n·m) = 1e10` → **超时**。

**前缀和做法**：预处理 `O(n)`，每次询问 `O(1)`，总共 `O(n + m)`。

### 4.1.2　一维前缀和

**定义**：`pre[i]` 表示 `a[0] + a[1] + ... + a[i-1]`（前 i 个元素的和）。

```
下标:    0    1    2    3    4
a:       3    1    4    1    5
pre:  0  3    4    8    9   14
      ↑ pre[0] = 0（空区间）
```

**递推**：`pre[i] = pre[i-1] + a[i-1]`

**区间和公式**（最核心）：

```
sum(a[l..r]) = pre[r+1] - pre[l]
```

**为什么？** `pre[r+1]` 是前 `r+1` 个（即 `a[0..r]`）的和，
`pre[l]` 是 `a[0..l-1]` 的和，两者相减正好剩 `a[l..r]`。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    int n, m;
    cin >> n >> m;

    vector<int> a(n);
    vector<ll> pre(n + 1, 0);        // ← 必须用 ll！和可能超 int

    for (int i = 0; i < n; i++) {
        cin >> a[i];
        pre[i + 1] = pre[i] + a[i];  // 递推
    }

    while (m--) {
        int l, r;
        cin >> l >> r;
        l--; r--;                    // 如果题目下标从 1 开始，去掉这两行
        cout << pre[r + 1] - pre[l] << '\n';
    }
    return 0;
}
```

> 🎯 **两个必须记住的点**：
> 1. `pre` 数组**长度是 `n+1`**，`pre[0] = 0`。有了这个「哨兵」，
>    `l = 0` 的情况才不用特判。
> 2. **`pre` 的类型必须是 `long long`**。
>    `n = 1e5` 个 `1e9` 加起来是 `1e14`，`int` 装不下。

### 4.1.3　下标从 0 还是 1 开始？

前缀和有两种常见写法，**选一种，全程统一**：

```cpp
// 写法 A：a 从 0 开始（上面的例子）
// pre[i] = a[0..i-1] 的和，区间 [l,r] → pre[r+1] - pre[l]

// 写法 B：a 从 1 开始（推荐给新手，不容易搞混）
int a[N];
ll pre[N];
for (int i = 1; i <= n; i++) {
    cin >> a[i];
    pre[i] = pre[i - 1] + a[i];
}
// 区间 [l, r] → pre[r] - pre[l - 1]
```

**写法 B 更直观**：`pre[r] - pre[l-1]` 直接对应「前 r 个减前 l-1 个」。
**本仓库后续的图论、DP 章节都采用「从 1 开始」**。

### 4.1.4　二维前缀和

**问题**：给一个 n×m 矩阵，多次询问子矩阵 `(x1,y1)` 到 `(x2,y2)` 的和。

**一维前缀和的「面积版」**：

```
pre[i][j] = 从 (1,1) 到 (i,j) 这个矩形内所有元素的和
```

**递推公式（容斥原理）**：

```cpp
pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i][j];
```

**为什么减 `pre[i-1][j-1]`？**
`pre[i-1][j]` 和 `pre[i][j-1]` 都把左上角那块**算了两次**，所以要减掉一次。

**查询公式（同样容斥）**：

```cpp
// 子矩阵 (x1,y1) ~ (x2,y2) 的和
ll sum = pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1];
```

**画个图理解**：
```
      y1      y2
       ┌───────┐
   x1  │ 目标区 │
       │        │
   x2  └───────┘

pre[x2][y2]         = 大矩形全部
- pre[x1-1][y2]     = 去掉上边一条
- pre[x2][y1-1]     = 去掉左边一列
+ pre[x1-1][y1-1]   = 左上角被多减了一次，加回来
```

**完整代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const int N = 1005;
ll pre[N][N];            // 全局，自动初始化为 0

int main() {
    int n, m, q;
    cin >> n >> m >> q;

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            int x;
            cin >> x;
            pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + x;
        }
    }

    while (q--) {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        ll ans = pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1];
        cout << ans << '\n';
    }
    return 0;
}
```

> ⚠️ **二维前缀和的数组大小**：`pre[1005][1005]` 的 `long long` 版
> 占 `1005 × 1005 × 8 ≈ 8MB`，安全。
> 但 `pre[5005][5005]` 就是 `200MB` → **MLE**。超过 `3000` 边长要小心。

### 4.1.5　前缀和的其他变体

前缀和的思想可以推广到**任何满足结合律的运算**：

| 类型 | 递推 | 区间查询 | 注意 |
|---|---|---|---|
| 前缀和 | `pre[i] = pre[i-1] + a[i]` | `pre[r] - pre[l-1]` | **不能有减法就完蛋** |
| 前缀积 | `pre[i] = pre[i-1] * a[i]` | `pre[r] * inv(pre[l-1])` | 需要**逆元**，不能有 0 |
| 前缀异或 | `pre[i] = pre[i-1] ^ a[i]` | `pre[r] ^ pre[l-1]` | **异或的逆运算是它自己** |
| 前缀最大值 | ❌ | ❌ | **不能用减法撤销**，要用 ST 表/线段树 |

**前缀异或特别好用**：

```cpp
// 区间异或和 = pre[r] ^ pre[l-1]
// 因为 x ^ x == 0，所以 pre[r] ^ pre[l-1] 正好把前面的抵消掉
```

**前缀异或的应用**：「求异或和为 0 的最长区间」
→ 找两个相同的 `pre` 值，最远的距离。

## 4.2　差分

### 4.2.1　问题：前缀和的「逆运算」

**题目**：给一个长度 n 的数组（初始全 0），做 m 次操作，
每次把区间 `[l, r]` 内**所有元素加上 v**。
最后输出整个数组。`n, m ≤ 1e5`。

**暴力做法**：每次操作循环 `[l, r]`，最坏 `O(n)`，总 `O(n·m)` → 超时。

**差分做法**：每次操作 `O(1)`，最后 `O(n)` 还原，总 `O(n + m)`。

### 4.2.2　一维差分

**定义**：`d[i] = a[i] - a[i-1]`（**相邻两项之差**）

**核心技巧**：给区间 `[l, r]` 全体加 `v`，
只需要在差分数组上做**两次单点修改**：

```cpp
d[l]     += v;      // 从 l 开始，差值多了 v
d[r + 1] -= v;      // 从 r+1 开始，差值还回去
```

**为什么？**
- `d[l] += v` 会让「从 l 往后的所有前缀和」都多 v
- `d[r+1] -= v` 把「从 r+1 往后的」抵消掉
- 只有 `[l, r]` 被净影响

**最后用前缀和还原原数组**：

```cpp
a[i] = a[i-1] + d[i]      // 即 a 是 d 的前缀和
```

**完整例子**：

```
初始 a = [0, 0, 0, 0, 0]（下标 1..5），d 全 0
操作：a[2..4] += 3
  d[2] += 3  →  d = [_,0,3,0,0,0]
  d[5] -= 3  →  d = [_,0,3,0,0,-3]

还原（前缀和）：
  a[1] = 0
  a[2] = 0 + 3 = 3
  a[3] = 3 + 0 = 3
  a[4] = 3 + 0 = 3
  a[5] = 3 + (-3) = 0
→ a = [0, 3, 3, 3, 0]   ✅ 正确
```

**完整代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const int N = 100005;
ll d[N];        // 差分数组

int main() {
    int n, m;
    cin >> n >> m;

    vector<ll> a(n + 1);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        d[i] = a[i] - a[i - 1];        // 用原数组初始化差分
    }

    while (m--) {
        int l, r; ll v;
        cin >> l >> r >> v;
        d[l]     += v;
        d[r + 1] -= v;                 // ⚠️ 注意是 r+1，所以 d 要开到 n+2
    }

    ll cur = 0;
    for (int i = 1; i <= n; i++) {
        cur += d[i];                   // 前缀和还原
        cout << cur << " \n"[i == n];
    }
    return 0;
}
```

> ⚠️ **两个必须注意的点**：
> 1. `d[r+1] -= v` 中 `r+1` 可能是 `n+1`，
>    所以 **`d` 数组要开到 `n + 2`**（这也是「全局数组多开 5 个」的原因）。
> 2. **如果原数组初值非 0**，可以用 `d[i] = a[i] - a[i-1]` 初始化，
>    或者干脆把 `a[i]` 当成一次 `[i, i] += a[i]` 操作。

### 4.2.3　二维差分

二维区间（子矩阵）加同一个值，思路完全一样，只是**四个角**：

```cpp
// 给子矩阵 (x1,y1) ~ (x2,y2) 全体加 v
d[x1][y1]         += v;
d[x1][y2 + 1]     -= v;
d[x2 + 1][y1]     -= v;
d[x2 + 1][y2 + 1] += v;     // ← 右下角加回来（被减了两次）
```

**还原**：做二维前缀和

```cpp
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        d[i][j] += d[i-1][j] + d[i][j-1] - d[i-1][j-1];
// 此时 d[i][j] 就是原矩阵对应位置的值
```

**记忆技巧**：二维差分的四个操作，正好是二维前缀和查询公式的**四项照抄**，
只是把「减」和「加」的位置对应到四个角。

### 4.2.4　差分的常见应用场景

| 场景 | 做法 |
|---|---|
| 区间加、最后统一查询 | 差分 + 前缀和 |
| 区间加、**随时**查询单点 | 差分 + 树状数组（第 06 章） |
| 区间加、**随时**查询区间和 | 差分两次 + 树状数组（第 06 章） |
| 统计每个位置被覆盖了几次 | 差分，最后前缀和 |
| 树上路径加、最后查点权 | **树上差分**（第 12 章） |

## 4.3　双指针 / 滑动窗口

### 4.3.1　核心思想

用两个指针 `l` 和 `r` 表示一个**区间**，
`r` 向右扩展（加入元素），`l` 向右收缩（移除元素）。

**关键**：两个指针**各自只往右走**，总共移动 `O(n)` 次 → 总复杂度 `O(n)`。

**使用条件**：区间具有**单调性**——
「如果 `[l, r]` 不满足条件，那么任何包含它的更大区间也不满足」。

### 4.3.2　题型一：最长/最短满足条件的子数组

**题目**：给一个正整数数组和 `S`，求**和 ≥ S 的最短子数组长度**。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n; long long S;
    cin >> n >> S;
    vector<int> a(n);
    for (int &x : a) cin >> x;

    int ans = n + 1;         // 很大的初值，表示「无解」
    long long sum = 0;
    int l = 0;

    for (int r = 0; r < n; r++) {
        sum += a[r];                     // ① 右指针扩张

        while (sum >= S) {               // ② 满足条件了，尝试收缩左指针
            ans = min(ans, r - l + 1);
            sum -= a[l];
            l++;
        }
    }

    cout << (ans == n + 1 ? -1 : ans) << '\n';
    return 0;
}
```

**注意**：
- 因为 `a[i] > 0`，`sum` 随 `r` 单调增、随 `l` 单调减 → **单调性成立**
- **如果有负数，滑动窗口就失效了**（要用前缀和 + 数据结构）

### 4.3.3　题型二：固定长度的窗口

**题目**：求长度恰好为 `k` 的子数组的最大和。

```cpp
long long sum = 0;
for (int i = 0; i < n; i++) {
    sum += a[i];                        // 加入右端
    if (i >= k) sum -= a[i - k];        // 移除左端
    if (i >= k - 1) ans = max(ans, sum);
}
```

### 4.3.4　题型三：两数之和（有序数组）

**题目**：升序数组里找两个数，和恰好为 `target`。

```cpp
int l = 0, r = n - 1;
while (l < r) {
    int s = a[l] + a[r];
    if (s == target) { /* 找到了 */ break; }
    else if (s < target) l++;      // 和太小 → 左指针右移（增大）
    else                 r--;      // 和太大 → 右指针左移（减小）
}
```

**这就是「左右指针相向移动」**，也属于双指针。

### 4.3.5　单调队列（滑动窗口求最值）

**题目**：长度 n 的数组，窗口大小 k，求每个窗口的最大值。

滑动窗口 + 单调队列可以把 `O(nk)` 优化到 `O(n)`：

```cpp
deque<int> dq;              // 存下标，对应值单调递减

for (int i = 0; i < n; i++) {
    // ① 队尾弹出所有比 a[i] 小的（它们永远不可能是最大值了）
    while (!dq.empty() && a[dq.back()] <= a[i]) dq.pop_back();
    dq.push_back(i);

    // ② 队首过期（滑出窗口）就弹出
    if (dq.front() <= i - k) dq.pop_front();

    // ③ 窗口形成后，队首就是最大值
    if (i >= k - 1) cout << a[dq.front()] << ' ';
}
```

> 🎯 **单调队列的直觉**：新来的元素如果比队尾大，
> 那队尾那个人**永远没机会当最大值了**，直接踢掉。
> 于是队列**单调递减**，队首永远是最大值。

**单调栈**同理，常用于「找左右两边第一个比自己大/小的元素」。

## 4.4　位运算进阶

第 02 章讲了位运算的语法，这里讲**在算法里怎么用**。

### 4.4.1　用二进制位表示「集合」

一个 `int` 有 32 位，可以表示一个「元素编号 0~31 的集合」：
**第 k 位为 1 ⇔ 集合里包含第 k 个元素**。

```cpp
int S = 0;                    // 空集
S |= (1 << 3);                // 加入元素 3    → S = 1000₂
S |= (1 << 5);                // 加入元素 5    → S = 101000₂
S &= ~(1 << 3);               // 删除元素 3
bool has = (S >> 5) & 1;      // 判断元素 5 在不在
int sz = __builtin_popcount(S);// 集合大小
```

**三种最基本的位运算含义：**

| 运算 | 集合含义 |
|---|---|
| `A \| B` | 并集 |
| `A & B` | 交集 |
| `A ^ B` | 对称差（只在一个里出现的） |
| `A & ~B` | 差集（A 去掉 B 的元素） |
| `A & B == A` | A 是 B 的子集 |
| `~A`（配合掩码） | 补集 |

> ⚠️ **注意优先级**：`A & B == A` 会被解析成 `A & (B == A)`！
> 必须写 `((A & B) == A)`。

### 4.4.2　枚举所有子集

```cpp
int n = 5;
// 枚举 {0,1,...,n-1} 的全部 2^n 个子集
for (int mask = 0; mask < (1 << n); mask++) {
    // mask 就是一个子集
    for (int i = 0; i < n; i++) {
        if (mask & (1 << i)) {
            // 元素 i 在这个子集里
        }
    }
}
```

复杂度 `O(2ⁿ · n)`。**`n ≤ 20` 时可用**（`2^20 ≈ 1e6`）。
`n = 25` 就是 `3e7`，勉强；`n = 30` 必超时。

### 4.4.3　枚举「某个集合的所有子集」（超高频）

**问题**：给定一个掩码 `S`，枚举它的**所有子集** `sub`。

```cpp
// 枚举 S 的所有非空子集（不含 S 本身会多一次，注意边界）
for (int sub = S; sub; sub = (sub - 1) & S) {
    // sub 依次为 S, ... 一路减到最小
}

// 枚举 S 的所有子集（包含空集）
for (int sub = S; ; sub = (sub - 1) & S) {
    // 处理 sub
    if (sub == 0) break;
}
```

**核心是 `sub = (sub - 1) & S` 这一句**：
它实现了「在 `S` 的位上做二进制减一」。

**总复杂度**：`O(3ⁿ)`（因为每个元素有「不在 S、在 S 不在 sub、在 sub」三种状态）。
`n ≤ 15` 可以用。

### 4.4.4　按位独立考虑（非常重要的思维方式）

**很多位运算题的核心思路是：每一位互不干扰，所以拆开每一位单独算，最后合并。**

以「异或」为例：
- 异或**不产生进位**！第 k 位的结果只取决于操作数第 k 位
- 所以「求异或的最值」类问题，可以**一位一位地贪心**

**贪心构造最大异或和（从高位往低位）**：

```cpp
// 在已选的数集上，尽量让高位为 1
int ans = 0;
for (int i = 30; i >= 0; i--) {
    if ((ans | (1 << i)) 可以被凑出来) {
        ans |= (1 << i);
    }
}
```

**另一种写法（线性基的第 k 小/最大，见第 10 章）**：

```cpp
int ans = 0;
for (int i = 30; i >= 0; i--) {
    if ((ans ^ base[i]) > ans) ans ^= base[i];
}
```

### 4.4.5　异或的四个实战性质

**性质 1：`x ^ x = 0`，异或可以「抵消」**

经典题：数组里除了一个数出现一次，其他都出现两次，找出那个数。

```cpp
int ans = 0;
for (int x : a) ans ^= x;      // 成对的都抵消了，剩下单个的
```

**性质 2：`a ^ b ^ b = a`** → 用于「撤销」

**性质 3：前缀异或**
`pre[i] = a[1] ^ a[2] ^ ... ^ a[i]`，
则区间异或和 `= pre[r] ^ pre[l-1]`。

**性质 4：异或和与「配对」的关系**

在一串数里，如果某一位的「前缀异或」出现过偶数次 0 状态和奇数次数 1 状态，
就可以通过配对来消除这一位的影响。**这正是 4.4.4「按位拆分统计」的用法。**

### 4.4.6　两个高频小技巧

**技巧 1：`x & (-x)` 取最低位的 1**

```cpp
x = 12 = 1100₂
-x = ...11110100₂（补码）
x & (-x) = 0100₂ = 4
```

**用途**：树状数组的 `lowbit`（第 06 章）、枚举一个数的所有二进制位。

```cpp
// 枚举 x 的所有为 1 的位
while (x) {
    int low = x & (-x);        // 最低位的 1
    int bit = __builtin_ctz(x); // 它是第几位
    // ... 处理 bit
    x -= low;                   // 消掉它
}
```

**技巧 2：`x & (x - 1)` 消掉最低位的 1**

```cpp
x = 12 = 1100₂
x - 1 = 1011₂
x & (x - 1) = 1000₂ = 8
```

**用途 1**：判断是不是 2 的幂
```cpp
bool isPow2 = (x > 0) && ((x & (x - 1)) == 0);
```

**用途 2**：统计 1 的个数
```cpp
int cnt = 0;
while (x) { x &= (x - 1); cnt++; }
```

**用途 3**：枚举子集（4.4.3 的核心）

### 4.4.7　`__int128`（防溢出神器）

当答案可能超过 `long long`（约 `9.2e18`）时，GCC 提供 128 位整数：

```cpp
using i128 = __int128_t;

i128 x = (i128)a * b;        // 不会溢出
cout << (long long)(x % MOD) << '\n';   // ⚠️ 不能直接 cout i128！
```

> ⚠️ **`__int128` 不支持 `cin`/`cout`**，必须自己写输入输出函数
> （见第 13 章「int128 输入输出」）。
> 竞赛中最常见用法：**在乘法里面用一下，马上取模变回 `long long`**。

### 例题 2：联合权值（前缀思想的经典变形）⭐

> 本题完整代码见 `gp_text/newcode1.cpp`。

**题意**：
给一棵 n 个点的树（n 个点、n-1 条边），点 `i` 有权值 `W_i`，每条边长 1。
对于**距离恰好为 2** 的点对 `(u, v)`，会产生联合权值 `W_u × W_v`。
求：

1. 所有**有序**点对中，联合权值的**最大值**
2. 所有**有序**点对的联合权值**之和**（对 10007 取模）

**关键观察**：

> 在树上，「距离恰好为 2」的两点，**必然有唯一一个共同的中间点**。
>
> ```
>   u ——— i ——— v
>      距离1   距离1    → dist(u,v) = 2
> ```
>
> 所以：**所有距离为 2 的点对，就是「每个点 i 的邻居之间两两配对」**。

于是问题变成：**对每个点 i，考虑它所有邻居的权值集合，处理其中的两两组合。**

**先解决「最大值」**：
在两两乘积中，最大值一定来自**最大的两个数**。
所以对每个点，只需维护「邻居中最大的两个权值」。

```cpp
int max1 = 0, max2 = 0;          // 最大的两个（降序）
for (int v : g[i]) {
    int val = w[v];
    if (val > max1) { max2 = max1; max1 = val; }
    else if (val > max2) { max2 = val; }
}
max_prod = max(max_prod, max1 * max2);
```

**再解决「乘积之和」——这是本题的精髓**：

对点 `i` 的邻居权值 `v1, v2, ..., vk`，
所有**有序对**的乘积和是：

```
Σ(i≠j) vi × vj  =  (v1 + v2 + ... + vk)²  -  (v1² + v2² + ... + vk²)
```

**为什么？**
完全平方公式 `(Σv)² = Σv² + 2·Σ(i<j) vi·vj`。
而「有序对之和」`Σ(i≠j) vi·vj = 2·Σ(i<j) vi·vj`。
所以 `(Σv)² - Σv²` 正好等于有序对之和。

**这就是「前缀和思想」的变形**：
不是逐对枚举 `O(k²)`，而是预先算好 `Σv` 和 `Σv²`，`O(k)` 就得到答案。

```cpp
int sum1 = 0;      // Σ v
int sum2 = 0;      // Σ v²
for (int v : g[i]) {
    int val = w[v];
    sum1 = (sum1 + val) % MOD;
    sum2 = (sum2 + val * val) % MOD;
}
int cur = (sum1 * sum1 % MOD - sum2 + MOD) % MOD;   // ← 注意 +MOD 防负数
sum_prod = (sum_prod + cur) % MOD;
```

**完整代码**（节选，完整版见 `gp_text/newcode1.cpp`）：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MOD = 10007;
const int N = 200005;

vector<int> g[N];
int w[N];

void solve() {
    int n;
    cin >> n;
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    for (int i = 1; i <= n; i++) cin >> w[i];

    int max_prod = 0, sum_prod = 0;

    for (int i = 1; i <= n; i++) {
        int max1 = 0, max2 = 0;
        int sum1 = 0, sum2 = 0;

        for (int v : g[i]) {
            int val = w[v];
            if (val > max1) { max2 = max1; max1 = val; }
            else if (val > max2) { max2 = val; }

            sum1 = (sum1 + val) % MOD;
            sum2 = (sum2 + val * val) % MOD;
        }
        max_prod = max(max_prod, max1 * max2);
        int cur = (sum1 * sum1 % MOD - sum2 + MOD) % MOD;
        sum_prod = (sum_prod + cur) % MOD;
    }
    cout << max_prod << ' ' << sum_prod << '\n';
}
```

**本题要点总结**：

| 学到什么 | 说明 |
|---|---|
| 树上「距离为 2」的转化 | 变成「共同邻居的配对」 |
| 求最大值 | 维护**最大的两个**，而不是全部枚举 |
| 求乘积之和的化简 | `(Σv)² - Σv²`，把 `O(k²)` 变成 `O(k)` |
| 减法取模 | `(a - b + MOD) % MOD` |

**复杂度**：每个点处理一遍邻居，总共遍历所有边两次 → **`O(n)`**。

> 💡 如果暴力枚举所有距离为 2 的点对，最坏是**菊花图**（一个中心连所有点），
> 单点就有 `O(n²)` 对 → 总 `O(n²)`，`n = 2e5` 直接超时。
> **「预先统计」永远是暴力的第一优化方向。**

### 例题 3（进阶）：按位拆分 + 前缀异或计数

> 本题完整代码见 `nk_zhou_sai_148/E`，这里只讲其中用到的技巧。

**技巧**：当问题涉及「异或」和「配对/操作次数」时，可以：

1. **先判全局可行性**（例如「总异或和必须为 0」）
2. **枚举每一个二进制位 k**（`0..29`，因为值 `≤ 1e9 < 2^30`）
3. **只看第 k 位**，把原数组变成一串 0/1
4. 在这串 0/1 上，**统计「前缀异或」的状态分布**：

```cpp
for (int k = 0; k < 30; k++) {
    int pref = 0;              // 前缀异或的「奇偶状态」：0 或 1
    int cnt0 = 0, cnt1 = 0;
    for (int i = 0; i < n; i++) {
        if (pref == 0) cnt0++;
        else           cnt1++;
        pref ^= ((a[i] >> k) & 1);      // 只看第 k 位
    }
    ans += min(cnt0, cnt1);    // 取较小的一侧配对
}
```

**为什么可以拆位？**
因为**异或不产生进位**，第 k 位的结果只和操作数的第 k 位有关。
所以「每一位独立算完再相加」是正确的。

**复杂度**：`O(30n)` = `O(n log V)`，`n = 2e5` 完全够用。

> 🎯 **「拆位独立处理」是位运算题的万能钥匙**。
> 看到「异或 + 最值 / 计数」先想：**能不能一位一位看？**

## 4.6　本章常见坑

| # | 坑 | 说明 |
|:---:|---|---|
| 1 | 前缀和用 `int` | `1e5` 个 `1e9` 加起来爆 `int`，必须 `long long` |
| 2 | 前缀和数组没开 `n+1` | `pre[0]` 这个哨兵没了，`l=0` 要特判 |
| 3 | 差分忘了 `r+1` 的开销 | `d` 数组要开到 `n+2` |
| 4 | 差分 `r = n` 时越界 | `d[n+1]` 写进去了 —— 所以要多开 |
| 5 | 滑动窗口用在有负数的数组 | 单调性破坏，答案会错 |
| 6 | 单调队列忘了「队首过期」判断 | 窗口外的最值被当成答案 |
| 7 | 位运算不加括号 | `x & 1 == 0` 是错的，要 `(x & 1) == 0` |
| 8 | `1 << 31` | `int` 溢出（最高位是符号位），要用 `1LL << 31` |
| 9 | 子集枚举忘了边界 | `sub = (sub-1) & S` 在 `sub = 0` 时会死循环 |
| 10 | `cout << __int128` | 编译报错，必须转成 `long long` |

**关于第 8 条要特别注意**：

```cpp
int x = 1 << 31;         // ❌ 溢出，x = -2147483648（负数！）
long long y = 1LL << 31; // ✅ 2147483648
long long z = 1LL << 62; // ✅ 4.6e18
```

**规则**：位移运算左操作数可能很大时，**一律用 `1LL << k`**。

## 本章小结

**必须掌握的四个套路：**

| 套路 | 什么时候用 | 复杂度 |
|---|---|---|
| **前缀和** | 静态数组、多次**区间查询** | 预处理 `O(n)`，查询 `O(1)` |
| **差分** | 多次**区间修改**、最后统一查询 | 修改 `O(1)`，还原 `O(n)` |
| **双指针/滑动窗口** | 找满足条件的**连续子数组**，且**有单调性** | `O(n)` |
| **按位独立** | 位运算相关的最值/计数 | `O(n log V)` |

**两个必备的数学化简：**

- `Σ(i≠j) vi·vj = (Σv)² - Σv²` —— 把两两配对从 `O(k²)` 降到 `O(k)`
- `1LL << k` —— 位移运算防溢出
