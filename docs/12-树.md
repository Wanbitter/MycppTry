## 12.1　树的基本概念

### 12.1.1 定义与性质

**树**：`n` 个点、`n-1` 条边、**连通且无环**的无向图。

**四个等价说法**（判断一棵树时都可能用到）：
1. 连通且无环
2. 连通且恰好 `n-1` 条边
3. 任意两点之间有**唯一**路径
4. 无环且恰好 `n-1` 条边

**常用术语**：

| 术语 | 含义 |
|---|---|
| **根** | 指定的起始点（有根树） |
| **父节点 / 子节点** | 相邻且更靠近根的 / 更远离根的 |
| **叶子** | 没有子节点的节点（`n = 1` 时根也是叶子） |
| **深度** | 到根的距离（根的深度为 0 或 1，**按题目约定**） |
| **子树大小** | 以该点为根的子树包含的节点数 |
| **祖先 / 后代** | 路径上的关系 |

### 12.1.2 存树

**树也是图**，所以直接用**邻接表**：

```cpp
vector<vector<int>> g(n + 1);

for (int i = 0; i < n - 1; i++) {
    int u, v;
    cin >> u >> v;
    g[u].push_back(v);
    g[v].push_back(u);        // 无向，加两次
}
```

**有根树的父子关系**：题目通常给 `p_2, p_3, ..., p_n`（`p_i` 是 `i` 的父亲）。
这时可以只存单向边：

```cpp
vector<vector<int>> children(n + 1);

for (int i = 2; i <= n; i++) {
    int p; cin >> p;
    children[p].push_back(i);     // 只存「父亲 → 儿子」
}
```

> 💡 **只存单向边的好处**：
> DFS 时**不用传 `fa` 参数**（不会走回去），代码更简洁。
> 但要求「输入保证 `p_i < i`」或能确定根。

**找根**：如果输入给的是无向边，根就是「任意指定」的；
如果要求「找到唯一的根」，用 `hasParent[]` 数组标记：

```cpp
int root = 1;
while (hasParent[root]) root++;
```

## 12.2　树的遍历与子树信息

### 12.2.1 DFS 遍历（最常用）

```cpp
vector<vector<int>> g;
vector<int> siz, dep;        // 子树大小、深度

void dfs(int u, int fa) {
    siz[u] = 1;                                  // ① 先算自己
    dep[u] = dep[fa] + 1;

    for (int v : g[u]) {
        if (v == fa) continue;                   // 不走回父亲
        dfs(v, u);                               // ② 递归儿子
        siz[u] += siz[v];                        // ③ 把儿子的信息合并上来
    }
}
```

**这个三层结构（初始化 → 递归 → 合并）是树形 DP 的标准骨架。**

### 12.2.2 求每个点的深度和子树大小

```cpp
dfs(root, 0);
// 之后 siz[u] 就是 u 的子树大小，dep[u] 是深度（根的 dep = 1）
```

**复杂度 `O(n)`**。

> ⚠️ **递归深度 = 树的深度**。
> 如果是「链状」的树（`1-2-3-...-n`），深度是 `n`，
> **`n = 1e6` 时会爆栈**！这时必须改成**迭代版**（用显式栈）或
> 用「按拓扑序 / 逆序处理」的方式。

**链状树的迭代写法**（先求 DFS 序，再逆序合并）：

```cpp
vector<int> order;
stack<int> st;
vector<bool> vis(n + 1, false);

st.push(root);
vis[root] = true;
while (!st.empty()) {
    int u = st.top(); st.pop();
    order.push_back(u);
    for (int v : g[u]) {
        if (!vis[v]) { vis[v] = true; st.push(v); }
    }
}
// 此时 order 是「先序」，逆序处理就能保证「儿子先于父亲」
for (int i = 0; i < n; i++) siz[order[i]] = 1;
for (int i = n - 1; i >= 0; i--) {
    int u = order[i];
    for (int v : g[u]) {
        if (v != par[u]) siz[u] += siz[v];
    }
}
```

> 📎 参考 `text_dp.cpp` 里的树形 DP 写法（用 `siz[]` + `dp[]`）。

### 12.2.3 树的 BFS 遍历（按层）

```cpp
vector<int> dep(n + 1, -1);
queue<int> q;
dep[root] = 1;
q.push(root);

while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : g[u]) {
        if (dep[v] == -1) {
            dep[v] = dep[u] + 1;
            q.push(v);
        }
    }
}
```

**用途**：求「距离某点最远的点」、按层处理、避免递归爆栈。

## 12.3　树的直径

### 12.3.1 定义

**树的直径 = 树上最远两点之间的路径**（长度或边数）。

### 12.3.2 求法一：两次 DFS / BFS（简单，推荐）

**算法（一个重要结论）**：

> 1. 从**任意点** `u` 出发，找到距离它最远的点 `a`
> 2. 从 `a` 出发，找到距离它最远的点 `b`
> 3. **`a` 到 `b` 就是直径**

**为什么对？**
（结论）树上离任意点最远的点，一定是某条直径的端点。

```cpp
// 求「从 start 出发最远的点和距离」
pair<int,ll> bfs(int start, vector<vector<pair<int,ll>>> &g, int n) {
    vector<ll> dist(n + 1, -1);
    queue<int> q;
    dist[start] = 0;
    q.push(start);

    int farNode = start;
    ll farDist = 0;

    while (!q.empty()) {
        int u = q.front(); q.pop();
        if (dist[u] > farDist) { farDist = dist[u]; farNode = u; }

        for (auto [v, w] : g[u]) {
            if (dist[v] == -1) {
                dist[v] = dist[u] + w;
                q.push(v);
            }
        }
    }
    return {farNode, farDist};
}

// 求直径
auto [a, _] = bfs(1, g, n);            // 第一次
auto [b, diameter] = bfs(a, g, n);     // 第二次
cout << diameter << '\n';
```

**复杂度 `O(n)`**。

> ⚠️ **这个「两次 DFS」的方法要求边权非负**。
> 有负权边时结论不成立，要用「树形 DP」的方法。

### 12.3.3 求法二：树形 DP（能处理负权）

`dp[u]` = 「以 `u` 为根的子树中，从 `u` 往下走的最长路径长度」。

```cpp
ll ans = 0;

void dfs(int u, int fa, vector<vector<pair<int,ll>>> &g) {
    ll mx1 = 0, mx2 = 0;               // 最长的两条向下路径

    for (auto [v, w] : g[u]) {
        if (v == fa) continue;
        dfs(v, u, g);

        ll len = dp[v] + w;            // 经过 v 这条边往下走
        if (len > mx1) { mx2 = mx1; mx1 = len; }
        else if (len > mx2) mx2 = len;
    }

    dp[u] = mx1;                       // u 向下走的最长路
    ans = max(ans, mx1 + mx2);         // 经过 u 的最长路径 = 两条最长向下路拼起来
}
```

**理解**：直径一定在某个点 `u` 处「拐弯」——
它由 `u` 出发的**两条最长向下路径**拼成。

### 12.3.4 直径的常用性质（很重要）

设直径长度为 `D`，中点（或中间边）为 `c`，则：

1. **所有直径的交集非空**，且一定经过「中心」
2. **从任意点出发的最远点，一定是直径的某个端点**
3. 若把直径中点作为根，则**每个点到根的深度 ≤ ⌈D/2⌉**
4. **直径上的点**满足「到两端距离之和 = D」

**用途**：很多「树上最远距离」「覆盖半径」类问题都靠这些性质转化。

> 📎 本仓库的 `WIDA-XCPC` 有「树论大封装（直径+重心+中心）」，一次性求这三样。

## 12.4　树的重心

### 12.4.1 定义

**重心**：删掉它之后，**最大的连通块最小**的那个点。

**等价定义**：以重心为根时，**每个儿子的子树大小 ≤ n/2**。

### 12.4.2 求法

```cpp
vector<int> siz, centroid;
int n;

void dfs(int u, int fa) {
    siz[u] = 1;
    int mx = 0;                        // u 的所有子树中最大的那个

    for (int v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        siz[u] += siz[v];
        mx = max(mx, siz[v]);
    }

    mx = max(mx, n - siz[u]);          // ★ 别忘了「父亲那一侧」也是一个连通块
    centroid[u] = mx;                   // 删掉 u 后的最大连通块大小
}

// 重心 = 使 centroid[u] 最小的 u
```

> ⚠️ **最容易漏的一步：`n - siz[u]`**。
> 删掉 `u` 之后，「父亲方向」也是一个连通块，大小是 `n - siz[u]`。
> **漏了它算出来的就不是重心。**

### 12.4.3 性质

1. **重心最多有两个**（`n` 为偶数时可能有两个，且它们相邻）
2. 以重心为根，**所有子树大小 ≤ n/2**
3. 「所有点到重心的距离之和」最小
4. 两个树合并后，新重心在「原来两个重心的路径上」

**用途**：点分治（第 13 章）、树的重心分解、最小化最大子树。

## 12.5　LCA（最近公共祖先）

### 12.5.1 问题

**LCA(u, v)** = `u` 和 `v` 的所有公共祖先中，**深度最大**的那个。

```
               1
             /   \
            2     3
           / \     \
          4   5     6
         /
        7

LCA(7, 5) = 2
LCA(4, 6) = 1
LCA(7, 4) = 4      （4 自己也是自己的祖先）
```

**用途**：
- 求树上两点距离：`dist(u,v) = dep[u] + dep[v] − 2 × dep[LCA(u,v)]`
- 判断祖先关系
- 树上路径操作（配合差分 / 树链剖分）

### 12.5.2 树上倍增法（推荐，必会）

**预处理** `up[k][u]` = 「从 `u` 往上跳 `2^k` 步到达的点」。

```cpp
const int MAXN = 100005;
const int LOG = 18;              // 2^18 = 262144 > 1e5

int up[LOG][MAXN];
int dep[MAXN];
vector<vector<int>> g;
int n;

// 预处理：dfs 求深度 + 倍增表
void dfs(int u, int fa) {
    up[0][u] = fa;                        // 跳 1 步就是父亲
    dep[u] = dep[fa] + 1;

    for (int k = 1; k < LOG; k++) {
        up[k][u] = up[k-1][ up[k-1][u] ]; // 跳 2^k 步 = 跳两次 2^(k-1) 步
    }

    for (int v : g[u]) {
        if (v != fa) dfs(v, u);
    }
}

// 求 LCA
int lca(int u, int v) {
    // ① 让 u 成为更深的那个
    if (dep[u] < dep[v]) swap(u, v);

    // ② 把 u 提到和 v 同一深度
    int diff = dep[u] - dep[v];
    for (int k = 0; k < LOG; k++) {
        if (diff >> k & 1) u = up[k][u];
    }

    if (u == v) return u;                 // v 就是 u 的祖先

    // ③ 一起往上跳（从高层往低层贪心）
    for (int k = LOG - 1; k >= 0; k--) {
        if (up[k][u] != up[k][v]) {       // 跳过去还不相等 → 可以跳
            u = up[k][u];
            v = up[k][v];
        }
    }
    return up[0][u];                      // 再跳一步就是 LCA
}
```

**复杂度**：预处理 `O(n log n)`，每次查询 `O(log n)`。

> ⚠️ **四个易错点**：
> 1. **根的父亲设成 0（哨兵）**，数组下标从 1 开始，且 `up[k][0] = 0`
> 2. **第 ③ 步从 `LOG-1` 往 `0` 枚举**（从大往小贪心）
> 3. **第 ③ 步判断是 `!=` 而不是 `==`**（跳到「刚好不相等的下面一层」）
> 4. **最后返回 `up[0][u]`** 而不是 `u`

**求两点距离**：

```cpp
long long distance(int u, int v) {
    return dep[u] + dep[v] - 2LL * dep[lca(u, v)];
}
```

> ⚠️ **`dep` 一般是 `int`，但距离要用 `long long`**，
> 所以写成 `2LL * dep[...]`。这是 `int` 溢出的常见坑。

### 12.5.3 树链剖分求 LCA（更快、常数小）

```cpp
// 两遍 dfs：第一遍求 siz/heavy son/dep/fa，第二遍求 top
int lca(int u, int v) {
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        u = fa[top[u]];                  // 跳到链顶的父亲
    }
    return dep[u] < dep[v] ? u : v;
}
```

**复杂度**：预处理 `O(n)`，查询 `O(log n)`（**常数比倍增小**）。

> 🎯 **选哪个？**
> - 只想求 LCA → **树链剖分**（预处理 `O(n)`，更快）
> - 还要做树上路径的**区间操作**（路径加、路径求和）→ **必须树链剖分** + 线段树

> 📎 `WIDA-XCPC` 模板库的「最近公共祖先 LCA」章节**两种都给了**。

### 12.5.4 其他求 LCA 的方法

| 方法 | 预处理 | 查询 | 特点 |
|---|---|---|---|
| **暴力向上跳** | `O(n)` | `O(n)` | 只适合很小的树 |
| **树上倍增** | `O(n log n)` | `O(log n)` | 最好理解 |
| **树链剖分** | `O(n)` | `O(log n)` | 常数最小 |
| **欧拉序 + ST 表** | `O(n log n)` | **`O(1)`** | 查询极快，但预处理占空间 |
| **Tarjan 离线** | `O(n α(n))` | `O(1)` 均摊 | 必须离线处理所有询问 |

## 12.6　树上差分

### 12.6.1 问题

**给树上的 `m` 条路径，每条路径上所有点的权值 `+1`，最后求每个点的权值。**

**暴力**：每条路径走一遍，`O(mn)` → 超时。
**树上差分**：每条路径 `O(1)`，最后一遍 DFS 汇总，`O(n + m)`。

### 12.6.2 点差分（路径上的点 +val）

```cpp
diff[u] += val;
diff[v] += val;
diff[lca(u, v)] -= val;
diff[fa[lca(u, v)]] -= val;        // ★ 注意这一行
```

**最后一遍 DFS 汇总**：

```cpp
void accumulate(int u, int fa) {
    for (int v : g[u]) {
        if (v == fa) continue;
        accumulate(v, u);
        diff[u] += diff[v];         // 儿子的差分累加到父亲
    }
    // 此时 diff[u] 就是 u 点被覆盖的次数（或权值和）
}
```

**为什么是这四项？（理解）**

设 `l = lca(u,v)`。
- `u` 到根、`v` 到根各 `+val`，这样 `l` 到根的路径被**加了两次**
- 在 `l` 处 `-val`：把重复的**减掉一次**
- 在 `fa[l]` 处 `-val`：把「`l` 到根」那部分**完全抵消**

结果正好只剩「`u` 到 `v`」这一段。

### 12.6.3 边差分（路径上的边 +val）

**注意**：边差分要把「边」映射到「儿子节点」上
（即「`u` 到它父亲的边」记在 `u` 身上）。

```cpp
diff[u] += val;
diff[v] += val;
diff[lca(u, v)] -= 2 * val;        // ★ 这里是 -2，不是两次 -1
```

**理解**：`l` 对应的那条「到父亲的边」**不在路径上**，所以要减掉两条。

**汇总和点差分一样**（累加到父亲），但**根的 `diff` 永远是 0**（根没有父亲边）。

### 12.6.4 点差分 vs 边差分（对比表）

| | 点差分 | 边差分 |
|---|---|---|
| 目标 | 路径上的**点** | 路径上的**边** |
| `u` | `+val` | `+val` |
| `v` | `+val` | `+val` |
| `lca` | `−val` | **`−2×val`** |
| `fa[lca]` | `−val` | 无 |
| 汇总 | 儿子累加到父亲 | 儿子累加到父亲 |
| 根的最终值 | 可能非 0 | **一定为 0** |

> 🎯 **一句话记忆**：
> **点差分在 `lca` 和 `fa[lca]` 各减一次；边差分在 `lca` 减两次。**

### 12.6.5 树上差分的经典应用

| 题型 | 做法 |
|---|---|
| 「每条路径上的点权 +1，求最终权值」 | 点差分 |
| 「每条路径上的边权 +1，求最终边权」 | 边差分 |
| 「求每个点被多少条路径经过」 | 点差分 |
| 「求每条边被多少条路径经过」 | 边差分 |
| 「树上路径覆盖问题」 | 配合 LCA |

## 12.7　树上启发式合并（DSU on tree）

**问题**：对每个点 `u`，求「以 `u` 为根的子树」里满足某条件的元素个数。
对每个点都暴力统计 → `O(n²)`，超时。

**做法（DSU on tree）**：

1. 求出每个点的**重儿子**（子树最大的那个儿子）
2. DFS 时：
   - 先递归处理**轻儿子**，处理完**清空**它们的影响
   - 再递归处理**重儿子**，**保留**它的影响
   - 最后把轻儿子的影响**暴力加回来**
3. 此时集合里正好是「`u` 的整棵子树」，可以直接回答 `u` 的询问

**复杂度**：每个点被「清空 + 重加」的次数不超过 `O(log n)` → **总 `O(n log n)`**。

**原理**：一个点只会在「祖先里轻儿子」的分支上被重复计算，
而轻儿子的子树大小每次至少翻倍 → 最多 `log n` 层。

**适用信号**：
- 每个点要问「子树内某种统计」
- 不强制在线
- 暴力统计子树是 `O(子树大小)`，但信息不好用「简单累加」合并

> 📎 `WIDA-XCPC` 模板库有「树上启发式合并 (DSU on tree)」的完整封装。

## 12.8　例题精讲

### 例题 1：树上传贡献（两次 DFS / 换根）⭐⭐

> 本题代码见 `gp_text/newcode3.cpp`。

**题型**：树上每个节点有权值，每个节点有一个「访问顺序」，
求每个节点被访问时的「累计贡献」。

**核心技巧：一次 DFS 求子树信息 + 一次 DFS 传「来自祖先方向的贡献」**

```cpp
vector<ll> v, sub, ans;

// 第一遍：求子树和
void dfs_sub(int u, vector<vector<pair<int,int>>> &g, vector<ll> &v, vector<ll> &sub) {
    sub[u] = v[u];
    for (auto &[_, child] : g[u]) {
        dfs_sub(child, g, v, sub);
        sub[u] += sub[child];                 // 合并儿子
    }
}

// 第二遍：把「来自祖先方向」的贡献 cur 传下去
void dfs_ans(int u, ll cur, vector<vector<pair<int,int>>> &g, vector<ll> &sub, vector<ll> &ans) {
    ans[u] = sub[u] + cur;                    // 自己的子树 + 祖先方向的贡献

    ll prefix = 0;                            // 前面兄弟的总贡献
    for (auto &[w, child] : g[u]) {           // 已按 w 排序
        dfs_ans(child, cur + w + prefix, g, sub, ans);
        prefix += sub[child];                 // ★ 累加前面兄弟的子树和
    }
}
```

**两个关键点**：

| 要点 | 说明 |
|---|---|
| **两次 DFS** | 第一次「自底向上」求子树信息；第二次「自顶向下」传祖先信息 |
| **`prefix` 累加** | 按顺序访问子女时，前面的兄弟会「先被访问完」，所以要累加它们的子树和 |

> 🎯 **这个「两次 DFS」的套路叫「换根 DP / 二次扫描法」**：
> **第一次 DFS 求子树信息，第二次 DFS 用父亲的信息推出儿子的答案。**
> 适用于「要对每个点都求答案，但答案之间有递推关系」的题。

### 例题 2：树上配对（自底向上贪心）

> 本题代码见 `nk_zhou_sai_144/F`。

**题型**：树上每个点有个 0/1 状态，可以做操作翻转某些点，
求最终最少剩余多少个 1。

**核心思路**：

```cpp
void dfs(int u, int fa) {
    if (ch[u].size() == 1 && u != 1) return;      // 叶子，直接返回
    for (int v : ch[u]) {
        if (v == fa) continue;
        dfs(v, u);
        if (qz[v] == 0 && u != 1) {               // 儿子是 0，需要调整
            qz[v] ^= 1;
            qz[u] ^= 1;
            qz[fa] ^= 1;                          // ★ 三个点一起翻转
        }
    }
}
```

**这道题的价值**：
- 展示**自底向上的贪心**：先处理儿子，儿子处理不掉再让父亲帮忙
- 展示「**三点翻转**」这种操作模式
- 最后还要单独处理根节点（`qz[1]`）的边界情况

> 💡 **自底向上贪心是树题的重要套路**：
> **「先把所有儿子都处理好，再决定父亲做什么。」**
> 因为儿子的选择余地比父亲小，所以儿子应该优先被满足。

### 例题 3：联合权值（距离为 2 的点对）

**已在 [第 04 章 4.5 节](04-前缀和差分双指针位运算.md) 详细讲过**
（原始代码 `gp_text/newcode1.cpp`），只回忆要点：

> **树上距离为 2 的点对 = 「共同邻居的配对」**
> 对每个点 `u`，处理它所有邻居的权值：
> - **最大值**：取邻居里最大的两个相乘
> - **和**：`(Σv)² − Σv²`（有序对之和，`O(k)` 而不是 `O(k²)`）

### 例题 4：求每点到「离它最远的点」的距离

**思路**（用直径的性质）：

1. 先求出一条直径的两个端点 `a`、`b`（12.3 节的方法）
2. **结论**：对任意点 `u`，离它最远的点**一定是 `a` 或 `b`**
3. 所以答案是 `max(dist(u,a), dist(u,b))`

**做法**：以 `a` 为根跑一次 DFS 求所有 `dist(u,a)`，
以 `b` 为根再跑一次求 `dist(u,b)`，最后取 max。

**复杂度 `O(n)`**。

> 🎯 **这个结论非常有用**，很多「树上最远距离」的题都靠它一票通过。

## 12.9　本章常见坑

| # | 坑 | 说明 |
|:---:|---|---|
| 1 | DFS 没传 `fa` 或没判 `v == fa` | 在树上来回死循环 |
| 2 | `n = 1e6` 用递归 DFS | **链状树会爆栈**，改迭代 |
| 3 | 求重心忘了 `n - siz[u]` | 漏掉「父亲那一侧」的连通块 |
| 4 | 树的直径用两次 DFS 但边权为负 | 结论失效，必须用树形 DP |
| 5 | 「两次 DFS 求直径」从 1 号点开始 | 正确（任意点都行），但**要确保图连通** |
| 6 | LCA 倍增表 `LOG` 开小 | `LOG` 要满足 `2^LOG > n` |
| 7 | LCA 第 ③ 步从 `0` 往 `LOG-1` 枚举 | **必须从大到小** |
| 8 | LCA 第 ③ 步用 `==` 判断 | 必须用 `!=` |
| 9 | `up[0][root]` 没设成 0 | 越界访问 |
| 10 | `dist = dep[u] + dep[v] - 2*dep[lca]` 用 `int` | 溢出，用 `2LL *` |
| 11 | 点差分写成边差分的四项 | `fa[lca]` 那一项不能少 |
| 12 | 边差分在 `lca` 只减了 1 次 | 必须减 `2 * val` |
| 13 | 树上差分汇总时忘了区分父亲 | `if (v == fa) continue;` |
| 14 | 多组数据没清空 `g` 和各个数组 | 上一组数据污染这一组 |
| 15 | 树是「链」时递归太深 | 同上第 2 条 |

> 🎯 **树题的调试建议**：
> **拿一棵 5~7 个点的小树手画一遍，把每个数组的值都算出来。**
> 树的 bug 90% 能用这种方式抓出来。

## 本章小结

**五个必背模板：**

| 模板 | 复杂度 | 关键点 |
|---|:---:|---|
| **DFS 求子树信息** | `O(n)` | 初始化 → 递归儿子 → 合并 |
| **树的直径** | `O(n)` | 两次 BFS；**边权非负才行** |
| **树的重心** | `O(n)` | 别忘了 `n - siz[u]` |
| **LCA（倍增）** | 预处理 `O(n log n)`，查询 `O(log n)` | 从大到小跳；判断用 `!=` |
| **树上差分** | `O(n + m)` | 点差分 4 项；边差分 3 项（`-2`） |

**三个结论：**

1. **离任意点最远的点，一定是某条直径的端点**
2. **以重心为根，所有子树大小 ≤ n/2**
3. **`dist(u,v) = dep[u] + dep[v] − 2 × dep[LCA(u,v)]`**

**一个套路：**

> **「两次 DFS」= 换根 DP**：
> 第一次自底向上求子树信息，第二次自顶向下传父亲方向的贡献。
