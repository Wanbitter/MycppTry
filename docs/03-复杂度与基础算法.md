## 3.1　为什么必须先学复杂度

先看一个真实的例子。

**题目**：给 n 个数，求它们的和。`n ≤ 1e9`。

写法 A：
```cpp
long long sum = 0;
for (int i = 0; i < n; i++) sum += a[i];   // 循环 1e9 次
```

写法 B：
```cpp
// 直接读入时就累加，或者用公式/前缀和
```

如果 `n = 1e9`，写法 A 要循环十亿次。
**普通评测机每秒大约只能跑 `1e8 ~ 3e8` 次简单运算**，
所以 A 要跑 **3~10 秒**。

而绝大多数题的**时间限制是 1 秒**。
→ **A 会超时（TLE, Time Limit Exceeded）**。

**复杂度分析就是用来提前预判这件事的**：
在写代码之前，先算算「我这算法要跑多少次运算」。

## 3.2　大 O 记号与常见复杂度

### 什么叫 `O(f(n))`

`O(f(n))` 读作「f(n) 的数量级」，意思是：
**当 n 很大时，运算次数和 f(n) 成正比**（忽略常数系数和低阶项）。

例如：
- `3n² + 100n + 5000` → 记作 `O(n²)`（n 大时 `n²` 主导）
- `2n + 7` → 记作 `O(n)`
- `100` → 记作 `O(1)`

**为什么忽略常数？** 因为 `n` 足够大时，`n²` 一定压过 `100n`。

### 常见复杂度从快到慢

| 复杂度 | 名称 | `n = 1000` | `n = 1e5` | `n = 1e6` | 典型算法 |
|---|---|---|---|---|---|
| `O(1)` | 常数 | 1 | 1 | 1 | 数组下标访问、哈希 |
| `O(log n)` | 对数 | ~10 | ~17 | ~20 | **二分查找** |
| `O(n)` | 线性 | 1e3 | 1e5 | 1e6 | 遍历、前缀和 |
| `O(n log n)` | 线性对数 | ~1e4 | ~1.7e6 | ~2e7 | **排序**、堆、树状数组 |
| `O(n√n)` | — | ~3e4 | ~3e7 | — | 分块、数论分块 |
| `O(n²)` | 平方 | 1e6 | **1e10 ❌** | — | 双重循环、Floyd |
| `O(n³)` | 立方 | 1e9 ❌ | — | — | 三重循环、矩阵乘法 |
| `O(2ⁿ)` | 指数 | ❌ | ❌ | — | 暴力枚举子集（`n ≤ 20`） |
| `O(n!)` | 阶乘 | ❌ | — | — | 全排列（`n ≤ 9`） |

### 👉 最实用的一张表：按数据范围反推算法

**这是本章最该记住的东西。** 看题先看数据范围，直接锁定算法：

| 看到 `n` 的范围 | 允许的复杂度 | 该想到的算法 |
|---|---|---|
| `n ≤ 10` | `O(n!)`、`O(2ⁿ·n)` | 全排列、暴力搜索 |
| `n ≤ 20` | `O(2ⁿ)` | **状压 DP**、子集枚举 |
| `n ≤ 100` | `O(n³)`、`O(n⁴)` | Floyd、区间 DP |
| `n ≤ 500` | `O(n³)` | 矩阵乘法、Floyd |
| `n ≤ 5000` | `O(n²)` | 二维 DP、暴力枚举 |
| `n ≤ 1e5` | `O(n log n)` | **排序、二分、树状数组、线段树** |
| `n ≤ 1e6` | `O(n)`、`O(n log n)`（常数小） | 线性筛、双指针、单调队列 |
| `n ≤ 1e7` | `O(n)`（常数极小） | 前缀和、简单扫描 |
| `n ≤ 1e18` | `O(log n)`、`O(√n)` | **快速幂、二分答案、矩阵快速幂** |

> 🎯 **「`n ≤ 1e9` 却让你求答案」的题**，几乎一定是
> **二分答案** 或 **数学公式** 或 **矩阵快速幂**。
> 因为 `O(n)` 都过不了，必须是 `O(log n)`。

## 3.3　怎么自己数运算次数

**方法**：数嵌套循环的总执行次数。

```cpp
// O(1)：没有循环
int x = a + b;

// O(n)：一层循环
for (int i = 0; i < n; i++) { ... }

// O(n²)：两层循环，各跑 n 次
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++) { ... }

// O(n log n)：外层 n 次，内层 log n 次
for (int i = 0; i < n; i++)
    for (int j = 1; j < n; j *= 2) { ... }   // j 每次翻倍 → log n 次

// O(n + m)：两个独立的循环
for (int i = 0; i < n; i++) { ... }
for (int j = 0; j < m; j++) { ... }

// ⚠️ O(n²) 的变体：内层从 i 开始
for (int i = 0; i < n; i++)
    for (int j = i; j < n; j++) { ... }
// 次数 = n + (n-1) + ... + 1 = n(n+1)/2 → 仍是 O(n²)
```

**判据**：
- 循环变量**每次加 1** → 循环 `O(n)`
- 循环变量**每次乘 2 或除 2** → 循环 `O(log n)`
- 嵌套循环 → **相乘**

## 3.4　空间复杂度

**竞赛内存限制通常 256MB 或 512MB。**

估算方法：

| 类型 | 每个占 | 开 `1e7` 个占 |
|---|---|---|
| `int` | 4 字节 | 40 MB |
| `long long` | 8 字节 | 80 MB |
| `double` | 8 字节 | 80 MB |
| `char` / `bool` | 1 字节 | 10 MB |

**常见危险开法：**

```cpp
int dp[1005][1005];         // ≈ 4 MB     ✅ 安全
int dp[5005][5005];         // ≈ 100 MB   ⚠️ 危险
long long dp[5005][5005];   // ≈ 200 MB   ❌ 可能 MLE
int dp[10005][10005];       // ≈ 400 MB   ❌ 必 MLE
```

> ⚠️ **`int` 类型的 2 维数组，边长上限大约 5000**（5000²×4 = 100MB）。
> 超过就要考虑**滚动数组**、**降维**或换算法。

> 🎯 一招救命：**`vector` 比数组省地方且不会爆栈**，
> 但 `vector` 的元素仍在堆上，占的内存是一样的。

## 3.5　二分查找（本章重点）

### 3.5.1　思想

把 `[1, 100]` 里的一个数让我猜，每猜一次我告诉你「大了 / 小了」。
最优策略显然是**每次猜中间值**：

```
猜 50 → 大了 → 答案在 [1, 49]
猜 25 → 小了 → 答案在 [26, 49]
猜 37 → ...
```

每次排除一半，最多猜 `log₂(100) ≈ 7` 次。
**这就是二分：`O(n)` 的查找变成 `O(log n)`。**

前提条件（**非常重要**）：
> **答案是单调的**——「如果 x 可行，那么比 x 大（或小）的也都可行」。

也就是存在一个**分界点**，左边一种情况，右边另一种情况。

### 3.5.2　最经典的：有序数组找数

**任务**：在升序数组 `a` 中，找**第一个 ≥ x** 的位置。

```cpp
// a 已升序排列，找第一个 >= x 的下标；不存在返回 n
int lowerBound(const vector<int> &a, int x) {
    int l = 0, r = (int)a.size();      // 注意：r 是「越界位置」，不是 n-1
    while (l < r) {
        int mid = l + (r - l) / 2;     // 防溢出写法，等价 (l+r)/2
        if (a[mid] >= x) {
            r = mid;                   // mid 可能就是答案，不能 mid-1
        } else {
            l = mid + 1;               // mid 一定不是答案
        }
    }
    return l;                          // l == r，就是答案位置
}

// 找第一个 > x 的下标
int upperBound(const vector<int> &a, int x) {
    int l = 0, r = (int)a.size();
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] > x) r = mid;
        else l = mid + 1;
    }
    return l;
}
```

**实测：**
```cpp
vector<int> a = {1, 3, 5, 7, 9};
lowerBound(a, 5);   // 2（a[2] = 5）
lowerBound(a, 6);   // 3（a[3] = 7，第一个 >= 6）
upperBound(a, 5);   // 3（a[3] = 7，第一个 > 5）
lowerBound(a, 100); // 5（等于 n，表示不存在）
```

> **这两件事 STL 已经做好了**，直接调用 `std::lower_bound` / `std::upper_bound` 即可
> （见第 02 章 2.8）。但**你仍然必须会手写**，因为「二分答案」需要自己写判断。

### 3.5.3 ⚠️ 死循环陷阱（新手第一大坑）

二分有**两种取法**，用错了会**死循环**。记住下面的规律：

```cpp
// 模板 ①  ——  找「第一个满足条件的位置」（求后继 / 左边界）
// 特征：mid = (l + r) / 2 ，满足时 r = mid
int l = 0, r = n;
while (l < r) {
    int mid = l + (r - l) / 2;      // 向下取整
    if (check(mid)) r = mid;        // 满足 → 答案在左边（含 mid）
    else            l = mid + 1;
}
// 结束时 l 就是答案
```

```cpp
// 模板 ②  ——  找「最后一个满足条件的位置」（求前驱 / 右边界）
// 特征：mid = (l + r + 1) / 2 ，满足时 l = mid
int l = 0, r = n - 1;
while (l < r) {
    int mid = l + (r - l + 1) / 2;  // ← 向上取整！这是关键
    if (check(mid)) l = mid;        // 满足 → 答案在右边（含 mid）
    else            r = mid - 1;
}
// 结束时 l 就是答案
```

**为什么要 `+1`？** 试想 `l = 0, r = 1`：
- 模板 ② 若写成 `mid = (l+r)/2 = 0`，且 `check(0)` 为真 → `l = mid = 0`。
  `l` 和 `r` 都没变 → **无限循环**。
- 改成 `mid = (l+r+1)/2 = 1` → `l = 1 = r` → 循环结束。

> 🎯 **一句话口诀**：
> **「`r = mid` 配 `(l+r)/2`；`l = mid` 配 `(l+r+1)/2`」**
> 记不住就去看「`l = mid` 时一定 `+1`」。

**再一个安全做法**：不用 `while (l < r)`，改成**固定二分次数**
（比如 60 次），保证一定结束：

```cpp
for (int iter = 0; iter < 60; iter++) {
    int mid = (l + r) / 2;
    if (check(mid)) r = mid;
    else            l = mid + 1;
}
// 对于 l,r <= 1e18，60 次足够精确
```

**还有一个「懒得动脑」的写法**（`ans` 记录法，强烈推荐新手用）：

```cpp
int l = 0, r = 1e9, ans = -1;
while (l <= r) {                    // 注意是 <=
    int mid = l + (r - l) / 2;
    if (check(mid)) {
        ans = mid;                  // 记下这个可行解
        r = mid - 1;                // 求最小的可行解 → 往左试
    } else {
        l = mid + 1;
    }
}
// ans 就是最小的可行解；若 ans == -1 说明无解
```
**这个写法不可能死循环**（因为 `l` 和 `r` 每次一定有一个在动），
代价是**多一个变量**。**新手无脑用这个。**

## 3.6　二分答案（真正的杀手级应用）

### 什么时候用？

题目里出现这些字眼：

- **「最大值最小」** / **「最小值最大」**
- **「至少 / 最多 需要多少 …」**
- **「能否在 X 之内完成」**
- 数据范围 `n ≤ 1e5` 甚至 `1e9`，但让你**输出一个数值答案**

→ **「把答案二分掉」**。

### 思路模板

```
1. 确定答案的取值范围 [L, R]。
2. 写一个 check(x)：判断「答案能不能 ≤ x（或 ≥ x）」。
   （通常是一个 O(n) 的贪心/模拟）
3. 用二分找到满足 check 的最小/最大 x。
```

**注意**：`check(x)` **不需要算出最优解**，只需要回答「x 可行吗」——
这通常比原问题**简单得多**。

### 完整例子：分割数组求「最小的最大段和」

**题目**：给一个非负整数数组 `nums` 和整数 `k`，
把它分成 `k` 个连续子数组，使**各段和的最大值最小**，输出这个最小值。

**分析**：
- 问的是「**最大值最小**」→ 二分答案！
- 二分对象是「段和的上限 X」，`check(X)` = 「能否在每段和 ≤ X 的前提下分成 ≤ k 段」

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int n, k;
vector<int> a;

// 判断：每段和不超过 X 时，最少需要几段；能否 ≤ k 段
bool check(ll X) {
    ll cur = 0;
    int cnt = 1;                  // 至少 1 段
    for (int i = 0; i < n; i++) {
        if (a[i] > X) return false;      // 单个元素就超过 X，不可能
        if (cur + a[i] > X) {            // 装不下了，开新段
            cnt++;
            cur = a[i];
        } else {
            cur += a[i];                 // 贪心地往当前段塞
        }
    }
    return cnt <= k;
}

int main() {
    cin >> n >> k;
    a.resize(n);
    ll sum = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        sum += a[i];
    }

    ll l = 0, r = sum, ans = sum;
    while (l <= r) {
        ll mid = l + (r - l) / 2;
        if (check(mid)) {
            ans = mid;          // 可行，记下来
            r = mid - 1;        // 试试更小的
        } else {
            l = mid + 1;        // 不可行，必须放大
        }
    }
    cout << ans << '\n';
    return 0;
}
```

**复杂度**：`check` 是 `O(n)`，二分 `O(log(sum))`，
总共 **`O(n log(sum))`** —— `n = 1e5` 完全够用。

> 🎯 **第一步永远是「确定二分范围」**：
> - 下界 `l`：**最小可能**的答案（比如 `0`、或数组最大值）
> - 上界 `r`：**一定可行**的答案（比如 `sum`）
>
> 范围开错 → 答案错。**宁可开大一点，也不要开小。**

### 二分答案的辨识练习

| 题目描述 | 二分对象 | check 内容 |
|---|---|---|
| 最小化「分割后的最大段和」 | 最大段和 X | 能否分成 ≤ k 段 |
| 最大化「最短的那块木板」 | 最短长度 X | 能否切出 ≥ k 段 |
| 「k 天后能否开花」 | 天数 X | 模拟 k 天 |
| 「跳石头，最少移走几块使最短跳跃距离最大」 | 最短距离 X | 移走数量 ≤ M 吗 |
| 「求 √n 的整数部分」 | 答案 X | X² ≤ n |

## 3.7　实数域二分

当答案是**小数**时（比如求方程的根、几何问题），二分实数：

```cpp
// 求 sqrt(x) 的高精度近似（示例）
double l = 0, r = x;
for (int iter = 0; iter < 100; iter++) {      // 固定迭代 100 次
    double mid = (l + r) / 2;
    if (mid * mid >= x) r = mid;
    else                l = mid;
}
cout << fixed << setprecision(10) << l << '\n';
```

**为什么不用 `while (r - l > 1e-9)`？**
- 如果 `l`、`r` 特别大（比如 `1e18`），`r - l` 可能因为**浮点精度**永远大于 `1e-9` → **死循环**
- 固定迭代次数**保证一定结束**，而且 100 次能到 `double` 的极限精度

> 🎯 **实数二分的两个坑：**
> 1. **迭代次数不够** → 精度不够 → 答案错（用 100 次，别用 30 次）
> 2. **输出格式**：题目要求 `1e-6` 误差，你就输出 **10 位小数**，别只输出 3 位

## 3.8　三分（求单峰函数的极值）

### 3.8.1　什么时候用

当函数在区间上**先下降后上升**（单谷，求最小值）
或者**先上升后下降**（单峰，求最大值）时，用**三分**。

**判别信号**：
- 题目问「最小的最大距离 / 最大的最小值」且**不是单调**的
- 平面上求「到若干点距离之和最小」的点
- 概率 / 期望相关的最优化

### 3.8.2　整数域三分

```cpp
// 求单谷函数 f 在 [l, r] 上的最小值位置（整数域）
int l = 0, r = n - 1;
while (r - l > 2) {                  // 留 3 个点就停，避免死循环
    int m1 = l + (r - l) / 3;
    int m2 = r - (r - l) / 3;
    if (f(m1) < f(m2)) {
        r = m2 - 1;                  // 最小值在左边
    } else {
        l = m1 + 1;                  // 最小值在右边
    }
}
// 最后在剩下的 3 个点里暴力找
int ans = l;
for (int i = l; i <= r; i++) {
    if (f(i) < f(ans)) ans = i;
}
```

### 3.8.3　实数域三分

```cpp
double l = 0, r = 1e9;
for (int iter = 0; iter < 100; iter++) {
    double m1 = l + (r - l) / 3;
    double m2 = r - (r - l) / 3;
    if (f(m1) < f(m2)) r = m2;       // 最小值在左边
    else               l = m1;
}
cout << fixed << setprecision(10) << f(l) << '\n';
```

> ⚠️ **三分的两个坑：**
> 1. **函数必须严格单峰**。有多处极值 → 三分会掉进局部最优。
> 2. **整数域三分必须留够区间**（`r - l > 2` 就停），否则
>    `m1 == m2` 会导致区间不缩小 → **死循环**。

> 💡 **实战经验**：能用二分就**别用三分**。
> 很多三分题可以把函数求导后二分，或者答案本身就是单调的。

## 3.9　`gcd` 与 `lcm`

### 3.9.1　最大公约数（辗转相除法）

**原理**：`gcd(a, b) == gcd(b, a % b)`
（因为「能同时整除 a 和 b 的数」和「能同时整除 b 和 a%b 的数」是同一批）

```cpp
// 递归版（最简洁，背它）
int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}

// 迭代版（递归深度大时用）
int gcd2(int a, int b) {
    while (b) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}
```

**复杂度 `O(log(a + b))`**——非常快，别怕调用。

### 3.9.2　STL 版本

```cpp
#include <numeric>
int g = gcd(12, 18);            // 6    C++17 起
int g2 = __gcd(12, 18);         // 6    GCC 老扩展，仍可用
```

> ⚠️ `gcd(a, b)` 的**参数必须非负**（传负数行为未定义）。
> 需要的话先取绝对值。

### 3.9.3　最小公倍数

**关键**：`lcm(a, b) = a / gcd(a, b) * b`

```cpp
int lcm(int a, int b) {
    return a / gcd(a, b) * b;      // ✅ 先除后乘，防止溢出
}
```

> ⚠️ **写成 `a * b / gcd(a, b)` 会溢出**！
> 例如 `a = b = 1e9`，`a * b = 1e18` 超出 `int` 直接炸。
> **先除后乘是必须的。**

### 3.9.4　常用小函数

```cpp
// 整数平方根（避免 sqrt 的浮点误差）
long long mysqrt(long long n) {
    long long ans = sqrt(n);
    while ((ans + 1) * (ans + 1) <= n) ans++;    // 往上补
    while (ans * ans > n) ans--;                 // 往下修
    return ans;
}

// 向下取整的 log2（避免 log2 的精度问题）
int log2floor(int x) {
    return 31 - __builtin_clz(x);        // x > 0
}

// 向上取整的 log2
int log2ceil(int x) {
    return log2floor(x) + (__builtin_popcount(x) != 1);
}

// 符号函数
template <class T> T sign(const T &a) {
    return a == 0 ? 0 : (a < 0 ? -1 : 1);
}
```

**为什么不用 `log2()`？**
浮点函数在 `1e18` 附近**存在精度误差**，
`log2(8)` 可能返回 `2.9999999`，取整后就变成 `2` 了。**竞赛里别用。**

## 本章小结

**必须记住的三件事：**

1. **数据范围 → 算法** 的对照表（3.2 节）：
   `n ≤ 1e5` 想 `O(n log n)`；`n ≤ 1e18` 想 `O(log n)`。
2. **二分模板的口诀**：
   「`r = mid` 配 `(l+r)/2`；`l = mid` 配 `(l+r+1)/2`」。
   不确定就用 `ans` 记录法。
3. **`lcm` 要先除后乘**，`sqrt`/`log2` 求整数结果必须手动修正。
