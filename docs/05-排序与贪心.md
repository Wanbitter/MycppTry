## 5.1　排序

### 5.1.1　`sort` 回顾

```cpp
sort(a.begin(), a.end());                    // 升序
sort(a.begin(), a.end(), greater<int>());    // 降序
sort(a.begin(), a.end(), cmp);               // 自定义
```

**复杂度 `O(n log n)`**，内部是内省排序（快排 + 堆排 + 插入排序）。

### 5.1.2　多关键字排序

```cpp
struct Node { int x, y, z; };

// 规则：x 升序 → y 降序 → z 升序
sort(v.begin(), v.end(), [](const Node &a, const Node &b) {
    if (a.x != b.x) return a.x < b.x;
    if (a.y != b.y) return a.y > b.y;
    return a.z < b.z;
});
```

**更简洁的写法——打包成 `tuple`**（`tuple`/`pair` 自带字典序比较）：

```cpp
// 想按 (x 升序, y 降序, z 升序) 排序
sort(v.begin(), v.end(), [](const Node &a, const Node &b) {
    return make_tuple(a.x, -a.y, a.z) < make_tuple(b.x, -b.y, b.z);
});
```

> ⚠️ **取负的写法只对整数有效**。`double`、`string` 等不能取负，
> 那就老老实实写三段 `if`。

### 5.1.3　结构体自带比较（`operator<`）

```cpp
struct Edge {
    int u, v, w;
    // 定义「小于」，之后直接 sort(v.begin(), v.end()) 就行
    bool operator<(const Edge &other) const {
        return w < other.w;
    }
};
sort(edges.begin(), edges.end());       // 自动按 w 升序
```

**好处**：`priority_queue<Edge>`、`set<Edge>`、`map<Edge, ...>` 都能直接用。
**注意**：`operator<` 也必须满足**严格弱序**（不能用 `<=`）。

### 5.1.4　逆序对（归并排序的应用）

**问题**：数组里有多少对 `(i, j)` 满足 `i < j` 且 `a[i] > a[j]`？

**暴力** `O(n²)`。**归并排序**可以在排序的同时 `O(n log n)` 统计：

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll cnt = 0;                  // 逆序对数量

void mergeSort(vector<int> &a, int l, int r) {
    if (l >= r) return;
    int mid = (l + r) / 2;
    mergeSort(a, l, mid);
    mergeSort(a, mid + 1, r);

    // 合并两个有序段
    vector<int> tmp;
    int i = l, j = mid + 1;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) {
            tmp.push_back(a[i++]);
        } else {
            // a[j] 比 a[i..mid] 都小 → 产生 (mid - i + 1) 个逆序对
            cnt += mid - i + 1;
            tmp.push_back(a[j++]);
        }
    }
    while (i <= mid) tmp.push_back(a[i++]);
    while (j <= r)   tmp.push_back(a[j++]);

    for (int k = 0; k < (int)tmp.size(); k++) a[l + k] = tmp[k];
}
```

**关键点**：在「右边元素先入队」时，说明 `a[j]` 比左段剩余的**所有**元素都小，
所以一次产生 `mid - i + 1` 个逆序对。

> 💡 **逆序对的另一个求法**：树状数组（第 06 章）或
> 直接 `for` 循环 + `lower_bound` 插入到有序表里。**归并排序最经典。**

**逆序对有什么用？**
- 「最少交换几次能让数组有序」= **逆序对数量**
- 「冒泡排序的交换次数」= 逆序对数量
- 判断排列的奇偶性

### 5.1.5　离散化

**问题**：数组的值可能到 `1e9`，但只关心**相对大小**；
或者要用「值作为下标」开数组（但值太大了开不下）。

**做法**：把值换成「它在所有数里排第几」。

```cpp
vector<int> a = {1000000000, 5, 999, 5, 42};

vector<int> b = a;                       // ① 拷贝一份
sort(b.begin(), b.end());                // ② 排序
b.erase(unique(b.begin(), b.end()), b.end());   // ③ 去重

// ④ 把原数组的每个值换成它的排名（从 1 开始）
for (int &x : a) {
    x = lower_bound(b.begin(), b.end(), x) - b.begin() + 1;
}
// a 变成 {4, 1, 3, 1, 2}
```

**复杂度 `O(n log n)`**。

**用途**：树状数组 / 线段树处理大值域、坐标压缩（几何题）、
「值域 1e9 但只有 1e5 个数」的题。

> 🎯 **离散化的本质**：把「值」换成「排名」，
> **大小关系不变**，但**值域缩小到 `O(n)`**。

### 5.1.6　计数排序与桶排序

当值域很小（比如 `0 ≤ a[i] ≤ 1000`）时：

```cpp
int cnt[1005] = {0};
for (int x : a) cnt[x]++;                      // 计数
int idx = 0;
for (int v = 0; v <= 1000; v++)
    while (cnt[v]--) a[idx++] = v;             // 还原
```

**复杂度 `O(n + V)`**，比 `sort` 快，但只适合**值域小**的情况。

## 5.2　贪心：思想与证明

### 5.2.1　贪心是什么

**贪心**：每一步都选「当前看起来最优」的那个选项，**绝不回头**。

**例子**：找零钱。要凑出 36 元，面额有 `20, 10, 5, 1`。
贪心策略：**每次尽量用最大的面额**。

```
36 → 用 20 → 剩 16
16 → 用 10 → 剩 6
6  → 用 5  → 剩 1
1  → 用 1  → 剩 0
共 4 张
```

4 张就是最优解。

**但是**：如果面额是 `1, 3, 4`，要凑 6 元呢？
- 贪心：先拿 4 → 剩 2 → 拿 1、1 → 共 **3 张**
- 最优：拿 3、3 → 共 **2 张**

→ **贪心失败了！** 这种题必须用 DP。

> 🎯 **关键结论**：
> **贪心不是万能的，用之前必须想清楚「为什么这样选一定对」。**
> 想不清楚就别贪心，去写 DP。

### 5.2.2　怎么证明贪心是对的

**两个常用方法：**

**方法一：交换论证（Exchange Argument）**

步骤：
1. 假设**最优解**在某一步选了 `b`，而贪心选了 `a`
2. 证明「把 `b` 换成 `a`，答案不会变差」
3. 于是可以一步步把最优解变成贪心解，说明贪心解也是最优的

**典型应用**：区间调度、排序不等式、Huffman 编码。

**方法二：归纳法 / 反证法**

假设某一步贪心选 `a` 是错的，推出矛盾。

### 5.2.3　⚠️ 一个血泪教训

**不要「感觉差不多就贪」**。

竞赛里最常见的扣分方式就是：
> 想了个贪心，过了样例，交了 → `Wrong Answer`
> （因为样例太弱，没覆盖到反例）

**验证贪心的方法**：
1. **对拍**：写一个暴力 DP，随机造数据对比（第 13 章）
2. **手造反例**：尝试构造让贪心失败的输入
3. **想清楚证明**

> 🎯 **决策流程**：
> ```
> 想贪心 → 能证明吗？
>            ├── 能 → 写贪心
>            └── 不能 → 写 DP（稳）
> ```

## 5.3　五个经典贪心模型（背下来）

### 模型 1：区间调度（活动选择问题）

**题目**：有 n 个活动，第 i 个占用时间 `[l_i, r_i)`，
同一时间只能做一件事，问**最多能做几个活动**。

**贪心策略**：**按结束时间 `r_i` 升序排序，能选就选**。

```cpp
struct Act { int l, r; };

sort(v.begin(), v.end(), [](const Act &a, const Act &b) {
    return a.r < b.r;              // ← 按「结束时间」升序
});

int cnt = 0, lastEnd = -1;
for (auto &a : v) {
    if (a.l >= lastEnd) {          // 与上一个不冲突
        cnt++;
        lastEnd = a.r;
    }
}
```

**为什么按结束时间排？**
（交换论证）结束越早 → 给后面留的时间越多 → 一定不会比别的选择差。

> ⚠️ **常见的错误贪心**：按「开始时间」排序、按「持续时间」排序 → **都会错**。
> 记住：**区间调度按右端点排**。

**变体**：
- 求「最少用几个会议室安排所有活动」→ 按开始时间排 + **小根堆**存结束时间
- 求「最多选几个互不重叠区间」→ 同上

### 模型 2：合并果子 / Huffman 编码

**题目**：n 堆果子，每次合并**相邻**两堆（或任意两堆），
代价是两堆之和，求合并成 1 堆的**最小总代价**。

**贪心策略**：**每次合并最小的两堆**。用小根堆维护。

```cpp
priority_queue<ll, vector<ll>, greater<ll>> pq;   // 小根堆
for (int x : a) pq.push(x);

ll cost = 0;
while (pq.size() > 1) {
    ll x = pq.top(); pq.pop();
    ll y = pq.top(); pq.pop();
    cost += x + y;
    pq.push(x + y);
}
cout << cost << '\n';
```

**复杂度 `O(n log n)`**。

**为什么对？** 每次合并后的和会成为后续的「底层」，被计入多次。
让**小的先合并**（少计几次）、**大的后合并**（多计几次但值大）——
这是「让大的数尽量少参与累加」的直觉。严格证明是 Huffman 树的最优性。

> 💡 **注意「相邻」两个字**：
> - 「任意两堆」→ 上面的堆做法（贪心）
> - **「相邻两堆」→ 是区间 DP，不是贪心**（见第 08 章）⚠️

### 模型 3：排序不等式（两数组配对）

**题目**：给两个数组 `a`、`b`，把它们**配对相乘再求和**，
求**最大**和**最小**的值。

**结论**：
- **最大和**：`a` 升序、`b` 升序，**同序相乘**（大的配大的）
- **最小和**：`a` 升序、`b` 降序，**逆序相乘**（大的配小的）

```cpp
sort(a.begin(), a.end());
sort(b.begin(), b.end());

ll mx = 0;
for (int i = 0; i < n; i++) mx += 1LL * a[i] * b[i];          // 同序 → 最大

sort(b.begin(), b.end(), greater<int>());
ll mn = 0;
for (int i = 0; i < n; i++) mn += 1LL * a[i] * b[i];          // 逆序 → 最小
```

**证明**：交换论证。若 `a1 ≤ a2` 且 `b1 ≤ b2`，
则 `a1·b1 + a2·b2 ≥ a1·b2 + a2·b1`（可以展开验证），
说明「大的配大的」更优。

### 模型 4：区间覆盖 / 区间选点

**题目**：用最少的点，让每个区间 `[l_i, r_i]` 内**至少有一个点**。

**贪心策略**：按**右端点升序**排；每次选「当前区间的右端点」作为点，
然后跳过所有被这个点覆盖的区间。

```cpp
sort(v.begin(), v.end(), [](const Act &a, const Act &b) {
    return a.r < b.r;
});

int cnt = 0;
ll lastPoint = LLONG_MIN;
for (auto &a : v) {
    if (a.l > lastPoint) {          // 这个区间还没被覆盖
        cnt++;
        lastPoint = a.r;            // 在它的右端点放一个点
    }
}
```

**为什么选右端点？** 右端点能覆盖到「所有以这个点之后的区间」的最大范围——
**越靠右，能覆盖的范围越大**。

### 模型 5：邻项交换（排队接水）

**题目**：n 个人排队接水，第 i 个人需要 `t_i` 时间。
求一种排队顺序，使**所有人的等待时间总和**最小。

**贪心策略**：**按 `t_i` 升序排**（快的先接）。

```cpp
sort(t.begin(), t.end());

ll wait = 0, sum = 0;
for (int x : t) {
    sum += wait;          // 这个人前面的总时间就是他的等待时间
    wait += x;
}
```

**证明（邻项交换）**：
考虑相邻两人 `i`、`j`。
- 若 `i` 在前：贡献 `t_i`（第 j 个人等 t_i）
- 若 `j` 在前：贡献 `t_j`
为了让总等待最小，应该让小的时间先算 → `t_i ≤ t_j` 时 `i` 在前。

> 🎯 **「邻项交换」是一个通用套路**：
> 假设最优解里两个相邻元素是 `i, j`，
> 交换它们不会变差 → 推出排序规则。

## 5.4　例题精讲

### 例题 1：合并果子（堆贪心入门）

**题意**：n 堆果子，每次合并**任意**两堆，代价为两堆之和，
求合并成一堆的最小总代价。

**思路**：上面模型 2，小根堆。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    int n;
    cin >> n;

    priority_queue<ll, vector<ll>, greater<ll>> pq;
    for (int i = 0; i < n; i++) {
        int x; cin >> x;
        pq.push(x);
    }

    ll cost = 0;
    while (pq.size() > 1) {
        ll a = pq.top(); pq.pop();
        ll b = pq.top(); pq.pop();
        cost += a + b;
        pq.push(a + b);
    }
    cout << cost << '\n';
    return 0;
}
```

**考点**：
- `priority_queue` 小根堆的完整写法
- **`ll`**：合并代价会累加到 `1e5 × 1e5 = 1e10`，必须 `long long`
- 循环条件是 `size() > 1`（剩一堆就停，不要再合并）

**复杂度**：每次操作 `O(log n)`，共 `n-1` 次 → `O(n log n)`。

### 例题 2：会议室安排（区间调度变体）

**题意**：n 个活动 `[l, r)`，求**最少需要几间会议室**。

**思路**：这是「区间重叠度」问题。

- **不要**用「按右端点排序」的模型 1（那求的是「最多参加几个」）
- 正确做法：**按开始时间排序 + 小根堆维护当前所有会议室的「空闲时间」**

```cpp
sort(v.begin(), v.end(), [](const Act &a, const Act &b) {
    return a.l < b.l;                   // 按开始时间升序
});

priority_queue<int, vector<int>, greater<int>> endTimes;   // 各房间的结束时间

for (auto &a : v) {
    if (!endTimes.empty() && endTimes.top() <= a.l) {
        endTimes.pop();                 // 有空房间了，复用它
    }
    endTimes.push(a.r);                 // 占用一个房间
}
cout << endTimes.size() << '\n';        // 堆的大小 = 需要的房间数
```

**为什么复用「最早结束」的房间？**
因为它**最不可能和后面的活动冲突**——这是贪心的正确性所在。

> 🎯 **区分这两类问题**：
> | 问法 | 排序依据 | 数据结构 |
> |---|---|---|
> | 最多能参加几个活动 | **右端点**升序 | 一个变量记 `lastEnd` |
> | 最少需要几个房间 | **左端点**升序 | 小根堆 |
| | 最多选几个互不重叠 | 右端点升序 | 变量 |

### 例题 3：括号序列贪心 ⭐

> 本题代码见 `cf_text/div1/A/d1_cf1097_A`。
> 下面复述的是**该文件开头的思路注释**，属于题解级说明。

**题意**：
给两个长度相同的括号串 `a`、`b`。
在两个串**字符不同**的位置上，可以决定谁拿 `'('`、谁拿 `')'`
（即把 `'('` 分配给它俩中的一个）。
问能否让**两个串都变成合法的括号序列**。

**括号序列合法的充要条件（必须背）**：

1. **任意前缀**满足：`'('` 的数量 ≥ `')'` 的数量
2. **整个串**满足：`'('` 的数量 == `')'` 的数量

**贪心策略**：

对两个串各维护一个「前缀值」（`'('` 记 `+1`，`')'` 记 `-1`）：

- 遇到**相同**的字符：两边照原样累加
- 遇到**不同**的位置：把 `'('` 分给**当前前缀值较小**的那个串
  （因为它更"需要"`'('` 来撑住前缀）

**判无解的两个条件**：

1. **过程中**任意一个串的前缀值 < 0 → `NO`
2. **结束时**任意一个串的前缀值 != 0 → `NO`

否则 `YES`。

**核心代码框架**：

```cpp
const ll INF = 1e18;
int n;
string a, b;
cin >> n >> a >> b;

vector<int> pre_a(n, 0), pre_b(n, 0);

// 第 0 位单独处理
pre_a[0] = (a[0] == '(') ? 1 : -1;
pre_b[0] = (b[0] == '(') ? 1 : -1;
if (pre_a[0] < 0 || pre_b[0] < 0) { cout << "NO\n"; return; }

for (int i = 1; i < n; i++) {
    // ① 先按原字符算前缀
    pre_a[i] = pre_a[i - 1] + (a[i] == '(' ? 1 : -1);
    pre_b[i] = pre_b[i - 1] + (b[i] == '(' ? 1 : -1);

    // ② 不同的位置：把 '(' 分给前缀值小的那一个
    if (a[i] != b[i]) {
        if (pre_a[i] > pre_b[i]) { a[i] = ')'; b[i] = '('; }
        if (pre_a[i] < pre_b[i]) { a[i] = '('; b[i] = ')'; }
        if (pre_a[i] == pre_b[i]) continue;      // 相等时怎么分都行
        // ③ 改动后要重算前缀
        pre_a[i] = pre_a[i - 1] + (a[i] == '(' ? 1 : -1);
        pre_b[i] = pre_b[i - 1] + (b[i] == '(' ? 1 : -1);
    }

    if (pre_a[i] < 0 || pre_b[i] < 0) { cout << "NO\n"; return; }
}

if (pre_a[n - 1] != 0 || pre_b[n - 1] != 0) { cout << "NO\n"; return; }
cout << "YES\n";
```

**这道题要学到什么？**

| 要点 | 说明 |
|---|---|
| 括号问题的通用工具 | **前缀和**（`+1 / -1`）+ 两个条件 |
| 贪心方向 | 把「资源」给**最紧缺**的那一方 |
| 一个实现细节 | 改变字符后**必须重算前缀**（原代码就是算了两遍） |

> 🔍 **想验证这个贪心？** 用 `n ≤ 10` 的所有情况暴力枚举，
> 和贪心结果对比（对拍，见第 13 章）。
> **"能证明或能对拍"才敢交**——这是本章最想教你的态度。

## 5.5　本章常见坑

| # | 坑 | 说明 |
|:---:|---|---|
| 1 | 贪心没证明就交 | 过样例 ≠ 正确，样例通常很弱 |
| 2 | 区间调度按左端点排 | **必须按右端点** |
| 3 | 把「相邻合并」当成「任意合并」 | 前者是**区间 DP**，贪心会错 |
| 4 | `cmp` 用了 `<=` | `sort` 会崩（见第 02 章） |
| 5 | `sort` 比较函数带状态 | `cmp` 里不能依赖外部变化的变量 |
| 6 | 合并果子的代价用 `int` | 会溢出，用 `long long` |
| 7 | 优先级队列忘了 `greater<>` | 默认是**大**根堆，要小根堆必须写全 |
| 8 | 逆序对用 `int` 统计 | 逆序对最多 `n(n-1)/2 ≈ 5e9`，必须 `long long` |
| 9 | 离散化忘了去重 | 有重复值时排名会跳号，`unique` 不能漏 |
| 10 | `greater<int>` 要 `#include <functional>` | 用 `bits/stdc++.h` 就没这问题 |

## 5.6　本章练习

**排序**
1. 给 n 个 `{姓名, 语文, 数学, 总分}`，按总分降序；总分相同按语文降序；再相同按姓名升序。
2. 求数组的逆序对数量（归并排序），`n ≤ 1e5`。答案用 `long long`。
3. 给 1e5 个 `≤ 1e9` 的数，求「第 k 小」（离散化 + 排序 / `nth_element`）。
4. 值域 `0..1e6` 的 1e6 个数，用计数排序 `O(n + V)` 排好。

**贪心**
5. 区间调度：最多参加几个活动。
6. 会议室安排：最少需要几间会议室。
7. 合并果子（任意两堆）：最小总代价。
8. 区间选点：最少放几个点覆盖所有区间。
9. 排队接水：最小总等待时间。
10. 两数组配对：求乘积和的**最大值**和**最小值**。

**进阶**
11. 有一个背包容量 C 和 n 件**可分割**的物品（每件可拿走一部分），
    求最大价值。（提示：按**单位价值**降序贪心——这是分数背包，贪心是对的）
12. 同样是背包，但物品**不可分割**。（这题贪心会错，必须 DP——对比 11 和 12，
    体会「为什么贪心会失效」）

## 本章小结

**排序不只是排个序：**

- `sort` + 自定义 `cmp` / Lambda / `operator<`
- **离散化**：把值换成排名，值域从 `1e9` 压到 `O(n)`
- **归并排序求逆序对**：`O(n log n)`
- **计数排序**：值域小时 `O(n + V)`

**贪心的五个模型（建议背下来）：**

| 模型 | 排序依据 | 数据结构 |
|---|---|---|
| 区间调度（最多选几个） | **右端点**升序 | 一个变量 |
| 会议室（最少几个房间） | **左端点**升序 | 小根堆 |
| 合并果子（任意合并） | — | 小根堆（每次取最小两个） |
| 排序不等式（配对） | 同序/逆序 | — |
| 区间选点 | **右端点**升序 | 一个变量 |
| 邻项交换（排队） | 按权值升序 | — |

**最重要的一句话：**

> **贪心必须能证明（或能对拍），否则就写 DP。**
