## 11.1　字符串基础

### 11.1.1 `std::string` 基本操作

```cpp
string s = "hello";
s.size();                 // 5（⚠️ 返回无符号数）
s.empty();                // false
s[0];                     // 'h'（不检查越界）
s.substr(1, 3);           // "ell"（从下标 1 开始取 3 个）

s += " world";            // 追加
s.push_back('!');         // 追加单字符
s.pop_back();             // 删除末尾
s.compare("hello");       // 字典序比较（0 相等）
s.c_str();                // 转成 char*（C 风格函数要用）
```

### 11.1.2 读入（竞赛常见坑）

```cpp
string s;
cin >> s;                 // ❌ 遇到空格/换行就停
getline(cin, s);          // ✅ 读一整行（含空格）
```

> ```cpp
> int n; cin >> n;
> cin.ignore();            // ★ 吃掉缓冲区里的换行符
> string s; getline(cin, s);
> ```

## 11.2　字符串哈希

### 11.2.1 它解决什么问题

**问题**：给一个字符串，多次询问「两个子串是否相等」。

**暴力做法**：逐字符比较，`O(长度)`。多次询问最坏 `O(nm)` → 超时。
**哈希做法**：预处理 `O(n)`，每次比较 `O(1)`。

### 11.2.2 原理：把字符串变成一个数

把字符串看成 **`base` 进制数**：

```
"abc" → 'a' × base² + 'b' × base¹ + 'c' × base⁰
```

用 `pre[i]` 表示前 `i` 个字符的哈希值：

```cpp
pre[i] = (pre[i-1] * base + s[i-1]) % MOD
```

**求子串 `s[l..r]` 的哈希**：

```cpp
hash(l, r) = pre[r] - pre[l-1] × pow_base[r-l+1]     （模意义下）
```

**理解**：把 `pre[r]` 里「`pre[l-1]` 那部分乘以 `base` 的若干次幂」减掉。

### 11.2.3 模板（单哈希）

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const ll MOD = 1'000'000'007;
const ll BASE = 131;              // 常用基数：131 或 233

const int MAXN = 1000005;
ll pre[MAXN], pw[MAXN];           // pre[] 哈希前缀，pw[] base 的幂

void initHash(const string &s) {
    int n = (int)s.size();
    pw[0] = 1;
    for (int i = 1; i <= n; i++) pw[i] = pw[i-1] * BASE % MOD;

    pre[0] = 0;
    for (int i = 1; i <= n; i++) {
        pre[i] = (pre[i-1] * BASE + s[i-1]) % MOD;
    }
}

// 子串 s[l..r] 的哈希（下标从 1 开始）
ll getHash(int l, int r) {
    return ((pre[r] - pre[l-1] * pw[r-l+1]) % MOD + MOD) % MOD;
}
```

### 11.2.4 双哈希（防碰撞）

单哈希有**被卡**的风险（出题人可以构造碰撞）。
**双哈希**用两个不同的模数，只有两个哈希都相等才算相等：

```cpp
const ll MOD1 = 1'000'000'007, BASE1 = 131;
const ll MOD2 = 998'244'353,   BASE2 = 233;

pair<ll,ll> getHash2(int l, int r) {
    ll h1 = ((pre1[r] - pre1[l-1] * pw1[r-l+1]) % MOD1 + MOD1) % MOD1;
    ll h2 = ((pre2[r] - pre2[l-1] * pw2[r-l+1]) % MOD2 + MOD2) % MOD2;
    return {h1, h2};
}
```

### 11.2.5 哈希的应用

| 题型 | 做法 |
|---|---|
| 判断子串相等 | `getHash(l1,r1) == getHash(l2,r2)` |
| 求最长公共前缀 | **二分长度** + 哈希比较，`O(log n)` |
| 求最长回文子串 | 正串 + 反串哈希，枚举中心二分 |
| 判断字符串是否由某子串重复构成 | 枚举周期长度，哈希验证 |
| 求不同子串个数 | `set` 存所有子串哈希，`O(n²)`（`n ≤ 3000`） |
| 字符串匹配 | 哈希滚动比较，`O(n)` |

> ⚠️ **哈希的三个坑**：
> 1. **减法后要 `+MOD` 再取模**（否则得负数）
> 2. **`base` 要大于字符集大小**（小写字母 26，`base` 用 131 够）
> 3. **单哈希可能被卡**，重要题目用**双哈希**或随机 `base`

> 🎯 **哈希 vs KMP**：
> 哈希**更通用**（能比较任意子串），但**有碰撞风险**；
> KMP **绝对正确**，但只能做「模式匹配」这一件事。
> **能哈希就哈希**（写起来快），除非题目刻意卡哈希。

## 11.3　KMP

### 11.3.1 它解决什么问题

**问题**：在文本串 `T` 中找模式串 `P` 出现的所有位置。
朴素做法 `O(nm)`；**KMP 做到 `O(n + m)`**。

### 11.3.2 核心：`next` 数组（失配指针）

`next[i]` 表示「`P[0..i]` 这个前缀的**最长 border 长度**」。

> **border（边界）**：既是前缀、又是后缀、且**不等于整个串本身**的部分。
>
> 例：`"ababa"` 的 border 是 `"aba"`（长度 3）和 `"a"`（长度 1），最长是 3。

**`next` 数组的作用**：
匹配失败时，**不用回到起点重来**，而是跳到「次优的可能位置」。

```
T: a b a b a b c
P: a b a b c
             ✗ 失配

P 的前 4 个字符 "abab" 的 border 是 "ab"（长度 2）
→ 直接从 P[2] 继续比，而不是从 P[0] 重来
```

### 11.3.3 求 `next` 数组（模板）

```cpp
// 下标从 0 开始；nxt[i] = P[0..i] 的最长 border 长度
vector<int> buildNext(const string &p) {
    int m = (int)p.size();
    vector<int> nxt(m, 0);
    for (int i = 1, j = 0; i < m; i++) {
        while (j > 0 && p[i] != p[j]) j = nxt[j - 1];   // ★ 回退
        if (p[i] == p[j]) j++;
        nxt[i] = j;
    }
    return nxt;
}
```

**⭐ 理解 `j = nxt[j-1]` 这一行（KMP 的灵魂）**：

当前比较的是 `p[i]` 和 `p[j]`。
如果它们不相等，说明「长度 `j+1` 的前后缀匹配不上」。
那就退一步，试试「长度 `nxt[j-1]` 的匹配」——
因为 `nxt[j-1]` 是 `p[0..j-1]` 的最长 border，
它同时也是 `p[0..i-1]` 某个后缀的匹配长度。

**不断回退，直到匹配上或 `j == 0`。**

### 11.3.4 匹配（模板）

```cpp
void kmp(const string &t, const string &p) {
    int n = (int)t.size(), m = (int)p.size();
    vector<int> nxt = buildNext(p);

    for (int i = 0, j = 0; i < n; i++) {
        while (j > 0 && t[i] != p[j]) j = nxt[j - 1];   // 失配 → 回退
        if (t[i] == p[j]) j++;
        if (j == m) {
            cout << i - m + 1 + 1 << '\n';              // 匹配位置（1 为基）
            j = nxt[j - 1];                             // ★ 继续找下一次
        }
    }
}
```

> ⚠️ **匹配成功后要 `j = nxt[j-1]`**，否则重叠的匹配会被漏掉。

### 11.3.5 KMP 的其他用途

| 用途 | 做法 |
|---|---|
| **求最小循环节** | `cycle = m - nxt[m-1]`；若 `m % cycle == 0` 则 `cycle` 是循环节 |
| **求所有 border** | 从 `m-1` 开始不断 `j = nxt[j-1]` |
| **每个前缀的最长 border** | 直接就是 `nxt[]` 数组 |
| **统计每个前缀出现次数** | 建 `nxt` 树，DFS 统计子树大小 |

**求最小循环节（很常用）**：

```cpp
int m = (int)s.size();
vector<int> nxt = buildNext(s);
int cycle = m - nxt[m - 1];
if (m % cycle == 0) cout << cycle << '\n';      // 循环节长度
else               cout << m << '\n';           // 不是完整循环
// 若要补成循环，需要补 m - nxt[m-1] 个字符
```

**验证**：`s = "abcabcabc"`，`m = 9`
- `nxt[8] = 6`（`"abcabc"`）
- `cycle = 9 - 6 = 3` ✅
- `9 % 3 == 0` → 循环节 `"abc"`，正确。

## 11.4　Z 函数（扩展 KMP）

### 11.4.1 定义

`z[i]` = 「`s` 和 `s[i..]`（后缀）的**最长公共前缀**长度」，`z[0] = n`。

**例**：`s = "aabcaab"`

```
i:     0  1  2  3  4  5  6
s:     a  a  b  c  a  a  b
z:     7  1  0  0  3  1  0
       ↑              ↑
       整体            s[4..]="aab"，公共前缀 "aab" → z[4]=3
```

### 11.4.2 模板

```cpp
vector<int> zFunction(const string &s) {
    int n = (int)s.size();
    vector<int> z(n, 0);
    z[0] = n;

    for (int i = 1, l = 0, r = 0; i < n; i++) {
        // 利用之前算过的区间 [l, r]
        if (i <= r) z[i] = min(r - i + 1, z[i - l]);

        // 暴力扩展
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) z[i]++;

        // 更新最靠右的区间
        if (i + z[i] - 1 > r) {
            l = i;
            r = i + z[i] - 1;
        }
    }
    return z;
}
```

**复杂度 `O(n)`**（内部 `while` 总执行 `O(n)` 次）。

### 11.4.3 用途

| 用途 | 做法 |
|---|---|
| 字符串匹配 | `P + "#" + T` 跑 Z 函数，`z[i] == m` 就是匹配 |
| 求每个后缀与整个串的 LCP | 直接就是 `z[]` |
| 求字符串的所有 border | 满足 `i + z[i] == n` 的 `z[i]` |
| 比较两个后缀的大小 | 用 `z` 求 LCP，再比下一位 |

> 🎯 **`z` 和 `next` 的区别**：
> - **`z[i]`**：`s` 与 **`s[i..]`（后缀）** 的 LCP
> - **`next[i]`**：`s[0..i]`（前缀）的 **border**（自己与自己的后缀的 LCP）
>
> 两者可以**互相转换**，功能高度重叠。**会一个就够用了。**

## 11.5　Manacher（最长回文子串）

### 11.5.1 问题

求字符串的**最长回文子串**（连续），`n ≤ 1e6`。

- 暴力枚举中心向两边扩：`O(n²)` → 超时
- **Manacher：`O(n)`**

### 11.5.2 核心技巧一：插入分隔符

回文分**奇长度**（中心是一个字符）和**偶长度**（中心是两个字符之间）。
为了让两种情况统一处理，**在每个字符间插入 `#`**：

```
原串:   a b b a
处理后: # a # b # b # a #        （长度 2n+1，一定是奇数长度回文）
```

这样「偶长度回文」在插入后也变成了「以 `#` 为中心的奇长度回文」。

### 11.5.3 核心技巧二：利用对称性

维护「当前回文能覆盖到的最右边界 `r`」和「对应的中心 `c`」。
如果 `i` 在 `[c, r]` 内，可以用 `i` 关于 `c` 的对称点 `2c - i` 的答案**跳过**一部分。

### 11.5.4 模板

```cpp
string preprocess(const string &s) {
    string t = "^#";
    for (char c : s) {
        t += c;
        t += '#';
    }
    t += '$';
    return t;
}

vector<int> manacher(const string &s) {
    string t = preprocess(s);
    int n = t.size();
    vector<int> p(n, 0);           // p[i] = 以 i 为中心的回文半径

    int c = 0, r = 0;
    for (int i = 1; i < n - 1; i++) {
        if (i < r) p[i] = min(r - i, p[2 * c - i]);   // 利用对称性

        // 向两边扩展
        while (t[i + p[i] + 1] == t[i - p[i] - 1]) p[i]++;

        // 更新最右边界
        if (i + p[i] > r) {
            c = i;
            r = i + p[i];
        }
    }
    return p;
}
```

**结果解读**：

- `p[i]` 是「以 `t[i]` 为中心的回文半径」
- **原串中最长回文子串的长度 = `max(p[i])`**
  （因为 `t` 里的半径正好等于原串中的长度）
- **起始位置**：设最大半径在 `i`，起始下标为 `(i - p[i]) / 2`

> ⚠️ **`t` 两端要加哨兵 `^` 和 `$`**，这样可以省掉「扩展时检查越界」的判断
> （因为哨兵一定不等于任何字符，`while` 会自动停）。

### 11.5.5 用途

| 用途 | 做法 |
|---|---|
| 最长回文子串 | `max(p[i])` |
| 回文子串个数 | `Σ (p[i] / 2)`（对插入串遍历） |
| 判断某前缀/后缀是否是回文 | 看对应的 `p[i]` 是否覆盖到边界 |

## 11.6　Trie 与 AC 自动机

### 11.6.1 Trie 字典树

**Trie 已经在 [第 06 章 6.6 节](06-数据结构.md) 详细讲过**，这里只列要点：

- **结构**：每个节点 26 个儿子，按字符逐层走
- **用途**：字符串集合的插入 / 查询 / 前缀统计
- **复杂度**：`O(L)`（L 是字符串长度）
- **内存**：`节点数 × 26 × 4` 字节，**总长度 `1e6` 时约 104MB，要小心**

> 📎 本仓库对应模板：`templates/06_string/trie.cpp`（原始文件 `ban_zi/Tire`）

**01 Trie 特别重要**：把数的二进制插进 Trie，可以求「与 `x` 异或最大的数」：

```cpp
int p = 0, ans = 0;
for (int b = 30; b >= 0; b--) {
    int u = (x >> b) & 1;
    if (son[p][u ^ 1]) {          // 优先走相反的分支（异或得 1）
        ans |= (1 << b);
        p = son[p][u ^ 1];
    } else {
        p = son[p][u];
    }
}
```

> 🎯 **「最大异或对」有两条路**：
> **01 Trie**（`O(n log V)`，能处理带修改的）或 **线性基**（`O(n log V)`，只求整体最值）。
> 看题目问「一对数」还是「一个子集」来选。

### 11.6.2 AC 自动机（多模式串匹配）

**问题**：给 `k` 个模式串和一个文本串 `T`，求每个模式串在 `T` 中出现几次。

**做法**：**Trie + KMP 的 fail 指针**。

1. 把所有模式串建进 Trie
2. 在 Trie 上求 `fail` 指针（类似 KMP 的 `next`，用 BFS 求）
3. 拿文本串在 Trie 上走，走到哪就沿 `fail` 链统计

```
fail[u] = 「从根到 u 的字符串」的「最长真后缀」在 Trie 中对应的节点
```

**用途**：敏感词过滤、多关键词匹配、字符串计数。

进阶内容，见 `WIDA-XCPC` 模板库「AC 自动机」章节。

### 11.6.3 其他高级字符串结构（了解即可）

| 结构 | 解决的问题 | 复杂度 |
|---|---|---|
| **后缀数组 SA** | 所有后缀的排序、LCP | `O(n log n)` |
| **后缀自动机 SAM** | 所有子串的信息（本质不同子串数等） | `O(n)` |
| **回文自动机 PAM** | 所有回文子串的信息 | `O(n)` |
| **子序列自动机** | 判断某串是否为子序列、字典序最小 | `O(n·Σ)` |

这些都在 `WIDA-XCPC` 模板库的「串」章节里有完整封装。

## 11.7　例题精讲

### 例题：古戈尔交换（DSU + 多重集排列）⭐⭐

> 本题完整题解（含中英双语题面）见 `ABC/abc470/f.md`。

**题意**：
给字符串 `S` 和 `M` 对下标 `(A_i, B_i)`，每次操作可以交换 `S[A_i]` 和 `S[B_i]`。
求**恰好操作 `10^100` 次**后，`S` 可能变成的**不同字符串的个数**（对 998244353 取模）。

**关键观察**：

`10^100` 是一个**足够大的偶数**。所以：

> **只要两个位置在同一个连通块里，字符就可以任意换到块内任何位置。**

因为「大偶数」意味着你可以用多余的步数做无效往返，
从而**不受步数奇偶性的限制**。

**做法（三步）**：

**① 用并查集把位置按可交换关系分组**

```cpp
for (int i = 0; i < M; i++) {
    int a, b; cin >> a >> b;
    unite(a - 1, b - 1);
}
```

**② 每个连通块内，字符可以任意排列**

设某连通块大小为 `sz`，块内各字符出现次数为 `cnt[c]`。
那么块内可形成的**不同字符串数量**是**多重集排列数**：

```
sz! / Π(cnt[c]!)
```

用「阶乘 + 逆元」计算（见 [第 10 章 10.6](10-数论与组合数学.md)）：

```cpp
ll ways = fact[sz];
for (int i = 0; i < 26; ++i) {
    ways = ways * invfact[cnt[i]] % MOD;
}
total = total * ways % MOD;
```

**③ 处理「全局反转」导致的重复计数**

> ⚠️ **这是本题最精妙的地方。**
>
> 为什么会有重复？因为并查集分块是「**按位置**」分的，
> 而如果所有连通块的字符都是**互不相同**的（没有任何块内有重复字符），
> 那么「块 A 的字符挪到块 B」和「块 B 的挪到块 A」可能产生**同一个字符串**——
> 也就是**整体置换的对称性**导致的重复。
>
> 代码里的处理：如果**所有块内都没有重复字符**，就把答案**除以 2**
> （乘 `inv2 = (MOD + 1) / 2`）。

```cpp
bool has_dup = false;
for (auto &comp : comps) {
    // 统计块内各字符出现次数
    for (int i = 0; i < 26; ++i) if (cnt[i] >= 2) dup_in_comp = true;
    if (dup_in_comp) has_dup = true;
    // ... 累乘 ways
}

const ll inv2 = (MOD + 1) / 2;
if (!has_dup) total = total * inv2 % MOD;
```

**这道题要学到的四件事**：

| 要点 | 说明 |
|---|---|
| **「大偶数次操作」的含义** | 步数足够多 ⇒ 只受**连通性**限制，不受奇偶性限制 |
| **并查集分连通块** | 换位置问题先想并查集 |
| **多重集排列数** | `n! / Π(cnt!)`，是字符串计数的基本公式 |
| **对称性去重** | 全局置换对称时要除以 2（用乘 `inv2` 实现） |

**复杂度**：`O(N α(N) + 26N)`。

## 本章小结

**四个必背模板：**

| 模板 | 复杂度 | 关键点 |
|---|:---:|---|
| **字符串哈希** | 预处理 `O(n)`，比较 `O(1)` | 减法 `+MOD`；重要题目用双哈希 |
| **KMP** | `O(n + m)` | `j = nxt[j-1]` 是灵魂 |
| **Z 函数** | `O(n)` | 利用 `[l, r]` 区间跳过 |
| **Manacher** | `O(n)` | 插 `#` + 哨兵 |

**两个选型建议：**

1. **求「子串相等 / LCP」→ 哈希**（最通用，写起来最快）
2. **求「模式匹配 / 循环节 / border」→ KMP**（绝对正确）

**一个思维桥梁：**

> **「换位置」类问题 → 并查集分出连通块 → 块内字符可任意排列 → 多重集排列数。**
